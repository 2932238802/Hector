# Hector

蚁群殖民肉鸽：经营一个蜂巢式的蚂蚁巢穴，用生产单位供养军队，
在一个季节的事件组里做取舍，扛过四季。

**当前状态：M6 春季垂直切片 v0（2026-11-09）**。设计文档是唯一事实来源，
代码只实现了其中一部分；范围与偏离见 [`tech-notes/architecture.md`](tech-notes/architecture.md)。

## 运行

需要 **Godot 4.7.x 标准版**（GDScript，不需要 .NET）。

```powershell
# 启动游戏
.\tools\run.ps1

# 无头冒烟测试
.\tools\run.ps1 -Mode test
```

如果本机执行策略禁止运行 `.ps1`，改用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\run.ps1 -Mode test
```

Godot 不在 PATH 时，用 `GODOT_BIN` 指向 `Godot_v*_console.exe`，或改 `tools/run.ps1` 里的路径。

## 现在能玩到什么

- **春季垂直切片 v0：6 回合**；撑到春季第 6 回合结束且巢穴完整度 > 0 即胜利，并输出本季统计。
- **只有食物一种资源**；所有成本、补给、恢复都用食物。
- **L2 开局**：7 格、3 个肥沃格、**15 食物、100 完整度、1 颗已种下的基础谷种、无固定阵容**。
- **开局 2 次免费招募**：每次从一阶池 3 选 1，免费、不占行动；跳过则第 1 场战斗只能谈判 / 回避。
- **每回合维持** `1 + ceil(人口/5)`（人口 = 工蚁 + 军队），食物不足只扣到 0。
- 每回合：**天气（季初生成 6 个）→ 维持 → 蚁后产工蚁 → 工蚁被动恢复 → 三选一
  （冒险 / 巢穴恢复 / 巢穴扩建）→ 选事件组 → A→B→C→D 结算**。
- **种子 = 生产单位**：肥沃格播种，每 N 个事件收获一次；春季食物型种子每次 +1 食物。
- 3 组事件选 1：**6 种模板**按春季权重抽取，每组 4 格、至少 1 个敌对、最多 1 个危机组和 1 个遗迹组。
- **事件选项**：每条春季事件有 2–3 个选项（迎战 / 谈判 / 回避、深入 / 浅探 / 放弃等），
  代价与结果按 `doc/04-slice/spring-v0.md` 数值落地；事件、兵种、敌人、奖励都在 `data/*.json`。
- **春季敌人 4 组**：盾甲 / 锹甲 / 结网蛛 / 掠食雀，带护盾、削弱、越排攻击签名，敌人 HP / 攻击 +10%。
- **战斗**：布阵（前 4 / 后 3）→ 逐单位付补给 → 每单位 1 AP、伤害 ±10%、护盾先于 HP、
  前排全灭前不可打后排、第 6 轮裁决；战后 HP 回满，失败只扣完整度。
- 战斗奖励：普通 2–4 食物 + 50% 战果；强敌 4–6 食物 + 1 战果 + 50% 虫珀。
- **招募 v2**：育婴室事件 3 选 1；池子 24 = 共享 12 + 廪实专属 12，按巢穴阶级开放；
  只出付得起的候选；升阶后第一次招募保底 1 个新阶级；可花食物刷新一次。

**没做**：热更 / 调参工具、战果使用、战斗植物、虫珀效果、天赋、存档；
事件内容量目前 13 条（春季最小集），96 格预算的完整池未做。
