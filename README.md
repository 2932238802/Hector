# Hector

蚁群殖民肉鸽：经营一个蜂巢式的蚂蚁巢穴，用生产单位供养军队，
在一个季节的事件组里做取舍，扛过四季。

**当前状态：M4 招募 v2（2026-11-09）**。设计文档是唯一事实来源，
代码只实现了其中一部分；范围与偏离见 [`tech-notes/architecture.md`](tech-notes/architecture.md)。

## 运行

需要 **Godot 4.7.x 标准版**（GDScript，不需要 .NET）。

```powershell
# 启动游戏
.\tools\run.ps1

# 无头冒烟测试
.\tools\run.ps1 -Mode test
```

如果本机执行策略禁止运行 `.ps1`，改用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\run.ps1 -Mode test
```

Godot 不在 PATH 时，用 `GODOT_BIN` 指向 `Godot_v*_console.exe`，或改 `tools/run.ps1` 里的路径。

## 现在能玩到什么

- **24 回合 = 4 季 × 6 回合**；撑过第 24 回合且巢穴完整度 > 0 即胜利。
- **只有食物一种资源**；所有成本、补给、恢复都用食物。
- **L2 开局**：7 格（1 中心 + 6 外圈）、6 个可用格（河边阻断 1 格）、3 个肥沃格、15 食物、1 颗已种下的基础谷种。
- **种子 = 生产单位**：肥沃格播种，每 N 个事件收获一次（基础谷种 3 事件 → 2 食物；
  丰产块根 5 → 4；树脂 / 毒液 3 → 1 战果；愈合菌圃 5 → 6 巢穴恢复）。
  事件结算时推进计数，收获进日志。
- 每回合：**天气（季初生成 6 个）→ 蚁后产工蚁 → 工蚁被动恢复 → 三选一
  （冒险 / 巢穴恢复 / 巢穴扩建）→ 选事件组 → A→B→C→D 结算**。
- **巢穴扩建走经验线**：1 食物 = 1 经验，阈值 L2→L3 = 25、L3→L4 = 35；
  每升一级 +3 个肥沃格（位置阻断的方向会顺延）。
- 3 组事件选 1；每组 4 个事件、4 个不同类别、至少 1 个压力事件。
- **战斗 v2**：敌方事件 → **布阵**（前 4 / 后 3，可撤下单位省补给）→ 开战；
  按实际出战单位逐个付补给，伤害 = 攻击 × 0.90–1.10（保留 1 位小数），
  护盾先于 HP、前排全灭前不可打后排、每单位 1 AP、第 6 轮僵局触发最终裁决（防守方胜、掉落减半），
  战后 HP 下场回满。
- **招募 v2**：育婴室事件 3 选 1；池子 24 = 共享 12 + 廪实专属 12，
  按巢穴阶级开放（L2 一阶 / L3 二阶 / L4 三阶），出现率 100% / 60:40 / 45:35:20；
  只出付得起的候选；升阶后第一次招募保底 1 个新阶级；可花食物刷新一次。
- 事件、数值、兵种、种子、敌军全部在 `data/*.json`，可直接调。

**没做**：兵种签名 / 关键词 / 护盾来源、事件 6 类模板与 96 格预算、
战果 / 虫珀 / 战斗植物 / 天赋 / 存档。
