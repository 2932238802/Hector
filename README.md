# Hector

蚁群殖民肉鸽：经营一个蜂巢式的蚂蚁巢穴，用生产单位供养军队，
在一个季节的事件组里做取舍，扛过四季。

**当前状态：M8 热更接收（2026-11-09）**。设计文档是唯一事实来源，
代码只实现了其中一部分；范围与偏离见 [`tech-notes/architecture.md`](tech-notes/architecture.md)。

## 运行

需要 **Godot 4.7.x 标准版**（GDScript，不需要 .NET）。

```powershell
# 启动游戏
.\tools\run.ps1

# 无头冒烟测试
.\tools\run.ps1 -Mode test
```

如果本机执行策略禁止运行 `.ps1`，改用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\run.ps1 -Mode test
```

Godot 不在 PATH 时，用 `GODOT_BIN` 指向 `Godot_v*_console.exe`，或改 `tools/run.ps1` 里的路径。

## 现在能玩到什么

- **春季垂直切片 v0：6 回合**；撑到春季第 6 回合结束且巢穴完整度 > 0 即胜利，并输出本季统计。
- **只有食物一种资源**；招募、恢复、探索都用食物。
- **L1 开局**：7 格、3 个肥沃格、**15 食物、100 完整度、1 颗已种下的基础谷种、无固定阵容**；
  一局可扩建 2 次（L1 → L2 → L3，肥沃格 3 → 6 → 9）。
- **开局 2 次免费招募**：每次从一阶池 3 选 1，免费、不占行动；可跳过（少两个兵，不影响后续流程）。
- **没有工蚁 / 人口 / 维持费**：回合开始只做收入汇报；巢穴恢复只能靠三选一「巢穴恢复」。
- 每回合：**天气（季初生成 6 个）→ 收入汇报 → 三选一（冒险 / 巢穴恢复 / 巢穴扩建）→ 选事件组 → A→B→C→D 结算**。
- **种子 = 生产单位**：肥沃格播种，每 N 个事件收获一次；春季食物型种子每次 +1 食物。
- 3 组事件选 1：**6 种模板**按春季权重抽取，每组 4 格、至少 1 个敌对、最多 1 个危机组和 1 个遗迹组。
- **春季事件 12 条 + 选项**：迎战 / 谈判 / 回避、深入 / 浅探 / 放弃等；探索代价改为食物
  （春季与雨天各 +1），数值按 `doc/04-slice/spring-v0.md` 落地。
- **春季敌人 4 组**：盾甲 / 锹甲 / 结网蛛 / 掠食雀，带护盾、削弱、越排攻击签名，敌人 HP / 攻击 +10%。
- **战斗**：布阵（前 4 / 后 3）→ **出战不扣食物**（Q-052）→ 每单位 1 AP、伤害 ±10%、
  护盾先于 HP、前排全灭前不可打后排、第 6 轮裁决；战后 HP 回满，失败只扣完整度。
- 战斗奖励：普通 2–4 食物 + 50% 战果；强敌 4–6 食物 + 1 战果 + 50% 虫珀。
- **招募**：育婴室 / 流浪蚁群 3 选 1；池子 24 = 共享 12 + 廪实专属 12，阶级 一阶=L1 / 二阶=L2 / 三阶=L3；
  只出付得起的候选；升 L2 保底二阶、升 L3 保底三阶；可花食物刷新一次。
- 所有 `data/*.json` 顶层都带 `schema_version: 1`，加载时校验。
- **热更接收**：`DataStore` 是唯一读盘入口，0.25 秒轮询 `data/`；保存后 1 秒内发
  `data_reloaded`，UI 立即刷新文本与数值；战斗数值保持开战快照，下一场才用新值；
  非法 JSON 保留旧数据、界面显示警告。调参工具由外部实现，本仓库只负责接收。

**没做**：战果使用、战斗植物、虫珀效果、天赋、存档；
事件内容量目前 12 条（春季最小集），96 格预算的完整池未做。
