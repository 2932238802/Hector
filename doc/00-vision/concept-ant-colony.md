# 《蚁战》概念草案 —— 蚁群战争肉鸽（已废弃）

> **2026-11-08 标记为 deprecated。**
> 本文是最早的概念草案，时间、巢穴、事件、资源等设定已被后续文档取代。
> 当前以 `02-systems/` 与 `03-content/` 为准。

> 回答"能不能把蚂蚁的世界肉鸽化"。
> 核心：不是养蚂蚁模拟器，而是**一窝蚂蚁在 20–30 分钟里从弱小到称霸、或全灭**。

## 一句话

你是一窝蚂蚁的"意志"。每一局，你从一只蚁后、几只工蚁开始，在有限的食物、人口、空间和季节里，发展出一个能打败竞争蚁群的超级有机体；失败后，下一代继承一点基因。

## 为什么蚂蚁天然适合

| 蚂蚁的真实特性 | 转成玩法 |
|---|---|
| 蚁后、工蚁、兵蚁、特化蚁 | 可成长的兵种/职业，天然 combo |
| 信息素路径 | 间接控制、效率系统、可被切断 |
| 挖洞筑巢 | 空间构筑，房间相邻产生协同 |
| 巢与觅食地的距离 | 补给线、风险与收益 |
| 与其他蚁群/天敌的战争 | 持续压力与对抗 |
| 洪水和冬季 | 时限压力 |
| 婚飞、新蚁后 | 局外传承（meta） |

## 双层结构

```
地表（俯视）                        地下（剖面）
┌──────────────────┐            ┌──────────────────┐
│  食物源 ●         │            │   ▓▓ 蚁后室 ▓▓    │
│      ╲            │            │      │            │
│       ╲  敌巢 ●   │            │   ▓▓ 育婴室 ▓▓    │
│        ●──●       │            │      │            │
│   我方巢 ●        │            │   ▓▓ 粮仓 ▓▓      │
└──────────────────┘            └──────────────────┘
```

- **地表**：觅食、侦察、突袭、领地争夺。
- **地下**：挖洞、造房间、育幼、进化兵种、保护蚁后。
- 两层共用同一批蚂蚁：派去地表的多，地下就少。

## 一回合（一天）

1. **分配**：把有限的人口分到地表 / 地下。
2. **地表行动**：移动觅食队、侦察、袭击敌巢、布置信息素。
3. **地下行动**：挖一格、造/升级房间、孵化幼虫、选择变异。
4. **结算**：食物收支、幼虫成长、季节推进。
5. **敌方回合**：竞争蚁群扩张/突袭、天敌出现、天气事件。

## 资源与约束

| 资源 | 来源 | 消耗 | 紧张点 |
|---|---|---|---|
| 食物 | 觅食、切叶蚁农场、蜜罐蚁储存 | 人口维持、孵化 | 人口越多越吃紧 |
| 人口 | 蚁后产卵 + 幼虫成长 | 战斗损失、天敌 | 工蚁/兵蚁比例 |
| 空间 | 挖掘 | 挖掘耗时 | 房间位置不可逆 |
| 时间 | 每回合推进 | 冬季/洪水倒计时 | 逼你冒险 |
| 命令点 | 每回合固定 | 每个行动 | 一回合做不完所有事 |

## Combo 系统（核心卖点）

**兵种 combo**
- 行军蚁：突袭强，但吃得多。
- 织叶蚁：搭桥跨过缺口/水流，打开新路线。
- 蜜罐蚁：储存食物，撑过冬天。
- 爆炸蚁：自杀式范围伤害，守巢底牌。
- 切叶蚁：把叶子转化为食物，慢但稳定。

**巢穴 combo**
- 育婴室贴着粮仓 → 幼虫成长 +20%。
- 兵营贴着入口 → 防御加成。
- 蚁后室越深越安全，但补给线越长。

**信息素 combo**
- 从食物源到巢的路径越短、越安全，觅食效率越高。
- 敌人可以切断信息素/道路，让你断粮。

## 压力来源

- 竞争蚁群会扩张、抢食物、袭击你的巢。
- 天敌（蜘蛛、食蚁兽）会攻击巢穴。
- 冬季倒计时：必须在食物耗尽前储备够。
- 洪水事件：低洼房间被淹，逼你重建。

## 胜负

- **胜利**：消灭所有竞争蚁后 / 撑到婚飞 / 完成本局目标。
- **失败**：蚁后死亡 / 食物归零 / 巢穴被毁。
- **单局**：20–30 分钟，约 20–30 回合。

## 肉鸽结构

- **局内**：随机地图、随机事件、变异三选一、永久损失。
- **局外**：用"基因"解锁新兵种、蚁后特性、生态（森林/沙漠/雨林）、难度层级。
- **死亡**：本局清空，下一代继承一点基因。

## 和参考作品的差别

| 参考 | 它的核心 | 《蚁战》的核心 |
|---|---|---|
| 杀戮尖塔 | 牌组构筑 | 蚁群构筑：兵种比例 + 巢穴布局 + 信息素 |
| 背包英雄 | 物品塞格子 | 房间相邻协同，但空间是巢穴不是库存 |
| 王之凝视 | 视野覆盖生产 | 人口分配与补给线 |
| 欧陆战争3 | 固定战役 | 小地图、20–30 分钟、每局随机 |

## 风险

- 双层结构增加理解成本，需要极清晰的 UI。
- 蚁群数量大，单个蚂蚁不可读 → 用"队伍/图标"抽象，而不是模拟每只蚂蚁。
- 与"菌毯"有相似的血缘（网络 + 断链），必须靠兵种 combo 和双层结构拉开差异。
- 竞争蚁群 AI 是主要技术难点。
