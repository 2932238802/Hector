# 玩家画像与设计含义

> 来源：2026-11-08 讨论中原话整理。确认后升级为 `approved`，作为所有系统的验收基准。

## 原始描述

- 「在限制中找最优解」
- 「情绪抗压与复盘能力」
- 「精妙的 combo」
- 「反复重开」
- 「我虽然没有那么有耐心，但是特别喜欢这种游戏」

## 核心快感（按优先级）

1. **约束下的最优解**：资源永远不够，必须取舍。
2. **高压决策**：每一步都有代价，失败有痛感。
3. **精妙 combo**：不同系统咬合，产生 1+1>2 的解法。
4. **快速复盘**：输了能清楚知道"哪一步错了"。
5. **重开的冲动**：下一局想试另一种解法。

## 对设计的要求

| 画像 | 设计要求 | 反模式 |
|---|---|---|
| 限制中找最优解 | 资源稀缺、无万能解、每个选择都有机会成本 | 数值碾压、单一最优解 |
| 情绪抗压 | 压力来自时限、稀缺、不可逆损失 | 无脑刷、纯数值膨胀 |
| 复盘能力 | 结算清晰、因果可追溯、提供战后统计 | 黑箱随机、死得不明不白 |
| 精妙 combo | 系统之间有交叉、组合空间大、有"啊哈"时刻 | 各系统互不相干、加法堆叠 |
| 反复重开 | 单局 15–40 分钟、重启快、局外有解锁 | 长局、慢节奏、强制重复劳动 |
| 耐心有限 | 前期 5 分钟内给到第一个有趣决策 | 长教程、慢热 |

## 一局节奏（暂定）

- 单局 15–40 分钟。
- 前 5 分钟必须出现第一个"资源不够，只能选一个"的决策。
- 失败后可立即重开；局外解锁只增加可能性，不加数值。
- 结算页必须回答：我为什么输？哪一步是关键？

## 待确认

- [ ] 15–40 分钟是否作为硬约束
- [ ] 是否接受"永久死亡 + 局外解锁"的标准肉鸽结构
- [ ] 压力来源偏好：时限 / 资源枯竭 / 敌人进攻 / 三者混合
