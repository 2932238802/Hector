# 设计现状总览（2026-11-09 更新）

> 用途：一页看清「目前已经定了什么、为什么这么定、还剩什么没定」。
> 本文件是**汇总视图**，规则细节以各系统文档为准；两者冲突时以系统文档为准，并回来修正本文件。
> 未决项全部登记在 `../OPEN-QUESTIONS.md`，本文只引用编号。
> **术语：巢穴（同义：虫穴 / 基地 / 营地 / 玩家自己的家）。文档统一用「巢穴」。**
> **术语：虫种（同义：英雄 / 种族 / 蚁种）。文档统一用「虫种」。**

---

## 1. 一句话

**蚁群殖民肉鸽**：经营一个蜂巢式的蚂蚁巢穴，用生产单位供养军队，
在一个季节的事件组里做取舍，扛过四季。

- 借鉴的是**机制骨架**（尖塔的取舍压力、背包英雄的局内构筑、王之凝视的农场循环），
  所有表达（名称、文案、美术、代码、音乐）原创。
- 明确**不做**：卡牌/抽牌战斗、背包空间网格、战棋走位。

## 2. 设计支柱

| 支柱 | 含义 | 落地方式 |
|---|---|---|
| 限制中找最优解 | 每回合资源不够做所有事 | 三选一主观行动 + 食物单一硬通货 |
| 情绪抗压 | 损失要有痛感，但不能让人弃游 | 士兵不消失、不饿死；代价转到食物与巢穴健康 |
| 复盘 | 一局结束后能说清"我哪儿错了" | 双时钟（事件/回合）让因果清晰、可追溯 |
| 精妙 combo | 单位、种子、虫珀之间有乘数 | 共生昆虫、种子羁绊、虫种被动、战果 |
| 反复重开 | **45–60 分钟**一局，信息量撑得住重玩 | 4 季 × 6 回合；事件组随机组合 |

## 3. 时间结构

```
1 局 = 4 季节 = 24 回合
1 季节 = 6 回合
1 回合 = 1 个事件组 = A → B → C → D（4 个事件）
1 局 = 96 次事件结算
```

- **1 回合不等于 1 天**，是抽象决策单位。
- **默认胜利 = 撑过冬天**（第 24 回合结束、巢穴完整度 > 0）；失败 = 完整度归零；胜利后可选**无尽模式**。
- 层级：季节（大回合）→ 小回合（事件组，带进度条）→ 事件（最小进度单元）。
- 点击「准备就绪」= 结算当前事件 → 推进进度条；**战斗轮次不占进度条**。
- 天气默认三种：晴天（正向）/ 多云（中性）/ 下雨（负向）；**每回合 1 个天气状态，1 季 6 个**，同回合 A→D 共享；**季初生成整段 + 部分预报**（Q-090）。

## 4. 双时钟（核心节奏设计）

| 时钟 | 单位 | 驱动什么 |
|---|---|---|
| 生产时钟 | **事件** | 生产单位（收获型种子）按事件计周期，周期由种子类型决定 |
| 恢复 | **主动行动** | 主要靠三选一的「巢穴恢复」付费修复，没有每回合被动恢复；战斗内另有守廪（25%）/ 堞垒蚁（迅捷 +2）的少量回复 |

- 目的：让"生产"和"经营决策"节奏不同，避免所有系统挤在同一拍上。
- 「巢穴恢复」是唯一的修复手段（2026-11-09 删除工蚁系统）。

## 5. 一回合流程

```
回合开始
  → 收入汇报（生产单位产出）
  → 主观行动（三选一）：冒险 / 巢穴恢复 / 巢穴扩建 / 等
  → 选择事件组（N 选 1，默认 3）
  → 事件 A → B → C → D（准备 → 准备就绪 → 结算）
  → 回合奖励
```

- **工蚁 / 人口**：**已删除**（2026-11-09）：不生成工蚁、没有维持费，探索代价直接用食物结算。
- **士兵**：持久资产，不消失、不饿死；战斗失败 = 扣巢穴健康 + 返场。
- **招募**：回合开始的固定窗口 + 事件触发（不占三选一）；每个窗口 3 选 1，**可反复招募到「结束招募」**，食物为主，刷新 1 食物。

## 6. 经济

- 资源：**只有食物**（2026-11-09 定，Q-061）；石头 / 纤维 / 材料层全部取消，所有成本以食物表达。
- 资源与物品**默认无上限**（战果道具栏是可能的例外，Q-072）。
- **种子产出分三类**（2026-11-09 定）：**食物 / 战果 / 工具**；主要取舍是“这块田种什么”，不是“产多快”。
- 工具种子包含恢复巢穴、增益其它种子、羁绊、战斗植物等（Q-092 ~ Q-096）。
- **食物是硬通货**：招募、修复、扩建、播种都吃食物（没有维持费，2026-11-09）。
- 收入来自**生产单位 = 播种后的收获型种子**（2026-11-09 定，Q-044 / Q-069）；周期以事件为单位（Q-064）。
- **不做独立建筑系统**；三选一中的“建筑升级”改为“巢穴扩建”，只负责开放肥沃格。
- **战果**：战果型种子的产出，存道具栏。定位接近**法术卡**（2026-11-09 用户定位）：可以直接给士兵加属性，也可以挂 buff（成长、攻击附带毒性、死亡触发等）。**部分持续本场、部分本局永久；使用后消耗；属性型每次使用按牌面累加，同名特性可叠层**（Q-094）。准备阶段与战斗中（我方未失败）随时可用，不占 行动点、无次数上限，只受持有量限制；部分可对敌对势力使用（Q-073）。
  目的是“用经济系统替代士兵死亡惩罚”，同时给手动 行动点 战斗加一层战术选择。
- **战斗不额外扣食物**（2026-11-09 取消战斗补给）；食物不能扣到 0 以下。

## 7. 巢穴与种子

- 抽象蜂巢，中心六边形 = 蚁后室，升级向外加圈；L1–L3 共 3 级，理论 7 / 19 / 37 格（L1 即开局，含第 1 圈）。
- **美术图形语言以六边形 / 八边形为主**（2026-11-09）：符合蜂巢与昆虫甲壳美学；巢穴网格仍是六边形，UI 面板、图标、边框可考虑八边形（待美术确认）。
- **开局即 L1**：7 格、3 个肥沃格、1 颗基础食物种子、15 食物（Q-075）。
- **一局只扩建两次**：L1 → L2 → L3，肥沃格 3 → 6 → 9。
- **巢穴升级单线**（2026-11-09）：升级只看**巢穴经验**，经验达到阈值即可升级；**食物可兑换经验**，是经验的来源之一，不是第二条升级线。升级后获得额外基地空间，并解锁植物携带数（L1 = 2 / L2 = 3 / L3 = 4）。经验只服务植物成长线（Q-098 / Q-100）。
- **全部格子都在蚁穴内部**，没有地表地图。
- 巢穴位置（河边 / 人类房屋边 / 沙漠）影响事件池、资源、种子、敌人，并可**阻断某一侧扩展**。
- **种子系统取代地势系统**（2026-11-08）：
  - 冒险带回种子 → 巢穴扩建后在外圈**肥沃格**播种；
  - **播种位累计 3 / 6 / 9**（L1 / L2 / L3），一局最多同时照料 9 颗种子；
  - **收获型 = 唯一生产单位**：每 N 个事件产出一次；按产出大类分食物 / 战果 / 工具；
  - 工具种子负责恢复巢穴、增益其它种子、羁绊、战斗植物；
  - **首批 3 种战斗植物**（荆棘防线 / 毒刺藤 / 庇护苔）已确认，见 `03-content/seeds.md` 3.3（Q-095）；羁绊首批被动方案暂停，Q-096 暂缓，需结合植物 / 兵种 / 虫种特性重议；
  - **羁绊 = 指定种子组合在外圈相邻肥沃格激活**（共边即相邻，含跨圈）；一颗种子可按邻居数参与多个羁绊，六边形最多 6 向；**羁绊不是纯被动经济加成**，要结合植物本身特性、兵种特性、虫种特性，具体待讨论（Q-096）；
  - **共生昆虫**提供战斗 buff 或给其它种子增益。
- 外圈其余格子为结构格，v1 不承载玩法内容（Q-070）。
- 播种的消耗、行动占用、移除 / 替换未定（Q-065）。

## 8. 战斗

- 在蚁穴外进行；**前 4 + 后 3 = 7 格上限**，早期可以不满、允许空位。
- **每单位独立 行动点，所有兵种基础 1 点**（技能 / 虫珀 / 特性可提高）：玩家阶段（顺序自选）→ 敌方阶段；攻击单向。
- **前排全灭前后排不可被攻击**；不补位；双方对称 4/3；开战后阵型锁定。
- **出战不扣食物**：2026-11-09 取消「战斗补给」与维持费；食物压力来自招募、修复与扩建（Q-052）。
- **战斗植物**：由防守型工具种子生成，**不占前 4 / 后 3 的单位格**；玩家可选择植物站前排或后排，**后排植物受前排单位保护（前排植物不算保护者）**；携带数量随巢穴等级：**L1 = 2 / L2 = 3 / L3 = 4**；在玩家阶段开始或结束时行动，部分可指定攻击 / 防守目标；**可被攻击，独立耐久**，被摧毁后本场失效、种子保留、下一场满耐久重生；部分植物带嘲讽，**嘲讽不设每轮上限**；**属性明显低于兵种（HP 4–6、攻击 1–2）**，不能替代兵种部署；首批 3 种见 `03-content/seeds.md` 3.3（Q-092 / Q-095）。
- 正常打到一方死光；僵局触发**最终裁决**：防守方胜、掉落减少（轮数待测试）。
- **战斗结算奖励按敌人类型**（2026-11-09 定）：**普通敌对昆虫 → 食物 + 战果**；**强大敌对昆虫 → 可获得虫珀**（概率 / 数量待定，Q-084）。
- 植物没有**通用存活奖励**；只有条目自带“存活收获”特性时才结算（Q-099）。
- 失败 → 巢穴完整性受损，士兵返场，不损失单位。
- 关键词（已改名，规避原作表达）：**迅捷 / 角质化 / 点卯 / 营巢 / 不甘 / 号令 / 余勇 / 猎杀 / 反噬 / 狂热 / 引导 / 扼守**（2026-11-09 定；2026-11-11 删除迟滞 / 寄生 / 不灭 / 护卫 / 偷袭，新增号令，共 12 个）。
  - **迅捷** = 战斗开始时触发一次绑定效果；**角质化** = 攻击命中后触发一次绑定效果（攻击特效）；**点卯** = 每轮玩家阶段开始时触发一次绑定效果；**营巢** = 战斗外（巢穴 / 探索阶段）触发一次绑定效果；**不甘** = 阵亡时触发一次绑定效果；两者无加成时每场各 1 次，buff 可增加。
  - **余勇** = 受伤时触发绑定效果（效果不限加攻）；**猎杀** = 击杀后触发绑定效果（默认本场攻击 +1）；**反噬** = 被单体攻击命中后反击（攻击力 ×50%）；**号令** = 友方触发签名绑定的关键词时额外结算 1 次（二星 2 次）。
  - **狂热** = 额外 +1 行动点（基础 1 点）；**引导** = 若干回合内强制献祭行动点，之后释放效果；**扼守** = 成为敌方单体攻击的对象。刺穿 / 偷袭同日删除，不再单独存在。
  - 「候望蚁」的绑定：迅捷 → 战果【迅捷】（延长天气预报）；不甘 → 战果【不甘】（使用时随机 −1 食物 / +1 食物 / +1 巢穴经验）（Q-108）。
- 季节与天气是战斗的乘数层：春（敌人更强）、夏（双方伤害↑、敌人更少）、
  秋（额外掉落）、冬（双方伤害↓、巢穴更脆）。
- 外圈环境布置取消；战斗变量来自单位 / 天气 / 季节 / 战果 / 战斗植物。
- 具体 行动点、技能、AI 数值仍待定（Q-028 / Q-032 / Q-057）。
- **战斗数学 v0**（`02-systems/combat-math.md`，2026-11-09）：战斗只有**数值与状态两层**——数值 = HP / 攻击 / 行动点 / **护盾**，状态只改数值（已确认**削弱 = 造成的攻击 ×50%**），**没有减伤概念**；**删除防御与速度**；伤害 = 攻击值 × 技能倍率 × 0.9–1.1（每目标独立）；敌人三阶分档；目标 3–4 轮、第 6 轮最终裁决；**战后 HP 一律回满，包括阵亡单位**（Q-115 / Q-116 / Q-117）。
