# 设计现状总览（2026-11-08 快照）

> 用途：一页看清「目前已经定了什么、为什么这么定、还剩什么没定」。
> 本文件是**汇总视图**，规则细节以各系统文档为准；两者冲突时以系统文档为准，并回来修正本文件。
> 未决项全部登记在 `../OPEN-QUESTIONS.md`，本文只引用编号。

---

## 1. 一句话

**蚁群殖民肉鸽**：经营一个蜂巢式的蚂蚁巢穴，用生产单位供养军队，
在一个季节的事件组里做取舍，扛过四季。

- 借鉴的是**机制骨架**（尖塔的取舍压力、背包英雄的局内构筑、王之凝视的农场循环），
  所有表达（名称、文案、美术、代码、音乐）原创。
- 明确**不做**：卡牌/抽牌战斗、背包空间网格、战棋走位。

## 2. 设计支柱

| 支柱 | 含义 | 落地方式 |
|---|---|---|
| 限制中找最优解 | 每回合资源不够做所有事 | 三选一主观行动 + 食物单一硬通货 |
| 情绪抗压 | 损失要有痛感，但不能让人弃游 | 士兵不消失、不饿死；代价转到食物与巢穴健康 |
| 复盘 | 一局结束后能说清"我哪儿错了" | 双时钟（事件/回合）让因果清晰、可追溯 |
| 精妙 combo | 单位、种子、虫珀之间有乘数 | 共生昆虫、蚁种被动、战粮 |
| 反复重开 | 15–40 分钟一局，信息量撑得住重玩 | 4 季 × 10 回合；事件组随机组合 |

## 3. 时间结构

```
1 局 = 4 季节 = 40 回合
1 季节 = 10 回合
1 回合 = 1 个事件组 = A → B → C → D（4 个事件）
```

- **1 回合不等于 1 天**，是抽象决策单位。
- 层级：季节（大回合）→ 小回合（事件组，带进度条）→ 事件（最小进度单元）。
- 点击「准备就绪」= 结算当前事件 → 推进进度条；**战斗轮次不占进度条**。
- 天气默认三种：晴天（正向）/ 多云（中性）/ 下雨（负向）。

## 4. 双时钟（核心节奏设计）

| 时钟 | 单位 | 驱动什么 |
|---|---|---|
| 生产时钟 | **事件** | 生产单位按事件计周期，周期与等级有关 |
| 恢复时钟 | **回合** | 工蚁数量 → 每回合少量恢复巢穴健康 |

- 目的：让"生产"和"经营决策"节奏不同，避免所有系统挤在同一拍上。
- 主动「基地恢复」是爆发式修复，数值显著高于工蚁被动恢复。

## 5. 一回合流程

```
回合开始
  → 收入汇报（生产单位产出）
  → 蚁后生成工蚁
  → 工蚁数量 → 巢穴健康少量恢复
  → 主观行动（三选一）：冒险 / 基地恢复 / 建筑升级 / 等
  → 选择事件组（N 选 1，默认 3）
  → 事件 A → B → C → D（准备 → 准备就绪 → 结算）
  → 回合奖励
```

- **工蚁**：消耗品；不能出战；决定被动恢复量；冒险时按遇到的随机事件牺牲数量。
- **士兵**：持久资产，不消失、不饿死；战斗失败 = 扣巢穴健康 + 返场。
- **招募**：改为**事件触发**（不占三选一），触发时 3 选 1，食物为主，可牺牲食物刷新一次。

## 6. 经济

- 资源：食物 / 石头 / 植物纤维（是否合并为"材料"待定，Q-061）。
- 资源与物品**默认无上限**（战粮道具栏是可能的例外，Q-072）。
- **食物是硬通货**：招募、战斗补给、修复、孵化都吃食物。
- 收入来自**生产单位**，周期以事件为单位；生产单位具体形态待定（Q-044）。
- **战粮**：生产单位的第二类产出，给士兵加临时属性，存道具栏，战斗中可用。
  目的是"用经济系统替代士兵死亡惩罚"，同时给手动 AP 战斗加一层战术选择。
- 战斗补给**按出场单位 × 兵种**计食物，空位不计；恶劣天气放大（下雨暂 ×1.5）。

## 7. 巢穴与种子

- 抽象蜂巢，中心六边形 = 蚁后室，升级向外加圈；最多 4 级，理论 1 / 7 / 19 / 37 格。
- **全部格子都在蚁穴内部**，没有地表地图。
- 巢穴位置（河边 / 人类房屋边 / 沙漠）影响事件池、资源、种子、敌人，并可**阻断某一侧扩展**。
- **种子系统取代地势系统**（2026-11-08）：
  - 冒险带回种子 → 巢穴升级/扩张后在外圈格**播种**；
  - **收获型**种子产出资源；**共生昆虫**提供战斗 buff 或给其它生产单位增益。
- 播种的规模、次数、是否占行动未定（Q-064 / Q-065 / Q-069 / Q-070）。

## 8. 战斗

- 在蚁穴外进行；**前 5 + 后 4 = 9 格上限**，早期可以不满、允许空位。
- **手动 AP**（2026-11-08 确定）：玩家阶段 → 敌方 AI 阶段；攻击单向；敌人优先打前排。
- 失败 → 巢穴完整性受损，士兵返场，不损失单位。
- 关键词（已改名，规避原作表达）：**扼守 / 先遣 / 遗讯 / 负伤 / 战蜕**。
- 季节与天气是战斗的乘数层：春（敌人更强）、夏（双方伤害↑、敌人更少）、
  秋（额外掉落）、冬（双方伤害↓、巢穴更脆）。
- 具体 AP、行为、AI、数值全部待定（Q-028 / Q-032 / Q-052 / Q-057）。

## 10. 已确定 / 待定（按影响排序）

**已确定**：四季 40 回合、双时钟、手动 AP、士兵不消失不饿死、工蚁消耗品、
食物为招募主工具、招募事件触发、种子取代地势、战粮。

**最影响结构的三项**（建议优先拍板）：

1. **Q-061 资源种类**——决定兵种配方、建筑升级、种子产出、战粮四张表的结构。
2. **Q-062 决策密度**——160 次事件结算 + 三选一 + 招募，对 15–40 分钟偏重；需要合并或降频。
3. **Q-064 / Q-065 / Q-069 种子规模**——决定"生产单位"到底是什么，而战粮挂在生产单位上。

其余待定：Q-052 补给数值、Q-053/057/058 天气与季节数值及叠加、Q-054 工蚁恢复公式、
Q-055 断粮、Q-044/045 生产单位形态与时点、Q-046 三选一菜单、Q-068 招募频率、
Q-071–074 战粮细节、以及胜负条件（Q-022）与局外成长。
