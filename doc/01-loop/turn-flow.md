# 回合流程（草案 v0.1）

> 时间：1 季 = 6 回合；1 局 = 24 回合（见 `time-and-seasons.md`）。
> 本文件写“一回合里发生什么”；数值待平衡。
> 2026-11-08 用户口述：回合开始 / 每个事件之前的准备时间。

## 0. 开局状态（2026-11-09）

- 巢穴 **L1**：中心蚁后室 + 7 格，其中 **3 个肥沃格**。
- 初始食物 **15**，起始种子 **1 颗基础食物型**。
- 第一回合即可：播种 / 冒险 / 扩建 / 恢复，无强制开场流程。
- 一局内可扩建 2 次：L1 → L2 → L3（肥沃格 3 → 6 → 9）。

## 1. 回合开始：招募窗口（2026-11-11）

> 用户口述：“招募可以一直招募，直到玩家点击下一步为止。”

- 每回合开始先打开**招募窗口**：3 个候选，**可反复招募**，直到玩家点「结束招募，下一步」。
- 招募窗口**不占**主观行动；每次招募按单位标价扣食物。
- 第 1 回合开局有 **2 次免费招募**；之后各回合的招募窗口按标价付费。
- 刷新候选：优先消耗免费刷新（度支蚁等），否则 1 食物，可反复刷新。
- 事件也可以触发额外的招募窗口（见 §4），同样是**可反复招募**，直到玩家主动结束。
- 数值见 `04-slice/spring-v0.md` 与 `02-systems/economy.md`。

## 1.5 生产时钟

- **生产时钟：事件**——生产单位按事件计周期。
- **巢穴恢复不是时钟**：工蚁系统已删除（2026-11-09），恢复只能通过三选一里的主动「巢穴恢复」。
- 收入 / 三选一的时点仍待确认（Q-035）。

## 2. 收入汇报

1. **收入汇报**
   - 显示本回合食物的产出与消耗。
   - 收入来自**已播种的收获型种子**（生产单位）；生产周期以**事件**为最小单位，周期 N 由种子类型决定（Q-064 / Q-069）。
   - 每条种子的产出是**食物或某一种战果**，固定不混产（Q-071）。
   - 生产在事件结算时触发还是回合开始汇总，待定（Q-045）。
2. **没有人口 / 维持结算**（2026-11-09 删除工蚁系统与维持费）：回合开始只做收入汇报。

## 3. 主观行动（三选一，事件组之后）

事件组 A→D 结算完后，玩家拿着本回合收入，从一组**主观行动**中选一个（暂定）：

| 行动 | 做什么 | 风险 / 代价 | 收益 |
|---|---|---|---|
| **冒险** | 周边探索 | 消耗食物；数量由遇到的随机事件决定；可能遇敌对势力 | 食物、虫珀、种子 |
| **巢穴恢复** | 修复巢穴完整度 | 消耗食物 | 巢穴健康回升 |
| **巢穴扩建** | 向外扩一圈 | 消耗食物 | 新增 3 个肥沃格，开放播种 |
| **等** | 迁移、其他主观行动 | 待定 | 待定 |

- **冒险**：探索在蚁穴外；食物代价与探索遇到的随机事件有关（Q-039）；恶劣天气、寄生虫等事件会放大损失。
- **巢穴恢复**：**唯一可主动选择的修复行动**，主动修复；战斗内另有守廪 / 堞垒蚁的少量回复，不替代它。具体消耗与数值待定（Q-046）。
- **巢穴扩建**：向外扩一圈，累计肥沃格变为 3 / 6 / 9，新增格开放播种（Q-065）。
- **默认只能选一个**；部分虫珀 / 物品可以让你选多个（Q-037）。
- 候选可能多于 3 个（当前列出 4 类），最终菜单与每回合出现几个待定（Q-046）。
- **选定一个行动后本回合立即结束**，进入下一回合的招募窗口。
- **招募发生在回合开始的招募窗口**（可反复招募），事件也可触发额外招募窗口；不再占用三选一（Q-068）。

## 3.5 播种窗口

- 触发：每次**巢穴扩建**之后。
- 内容：在新增的 3 个肥沃格播种；种子来自冒险。
- 播种是否消耗食物 / 占行动待定（Q-065）。
- 一局最多同时照料 9 颗种子（L3）。

## 4. 事件组

- 招募窗口结束后，进入本回合的事件组（N 选 1，见 `events.md`）。
- 组内 A → B → C → D：每个事件前有准备窗口（布兵 / 环境 / 天气防护）。
- 事件可能触发**招募窗口**（同样可反复招募到「结束招募」）、带回**种子**。
- 点击「准备就绪」→ 结算当前事件 → 进入下一个事件。
- A→D 全部结算后，进入 §3 的主观行动。

## 5. 回合结束

- 主观行动结算完 → **直接进入下一回合**（回合奖励机制待定）。
- 第 6 回合结束后春季结束，进入结算。

## 6. 时序图

```
回合开始
  → 天气 / 收入汇报
  → 招募窗口（3 选 1，可反复招募，直到「结束招募」）
  → 选事件组（N 选 1）
  → A → B → C → D（准备 → 准备就绪 → 结算；可能触发战斗 / 额外招募）
  → 主观行动三选一：冒险 / 巢穴恢复 / 巢穴扩建
  → 下一回合
```

## 7. 关键规则

- **收入来自收获型种子**：种子即生产单位，周期以**事件**为最小单位（Q-064 / Q-069）。
- **不做建筑系统**：三选一中的“建筑升级”改为**巢穴扩建**，只负责开放肥沃格（2026-11-09）。
- **没有工蚁 / 人口层**（2026-11-09）：不生成工蚁、没有维持费、巢穴只能主动修复。
- **食物是招募的主要工具**：不做单位转化（Q-041）。
- **士兵不会因战斗消失，也不会饿死**：战斗失败 → 士兵返场，损失的是巢穴完整度；**出战不扣食物**（Q-036 / Q-049 / Q-052）。
- **恶劣天气 / 气候会放大冒险的食物损失**（Q-053）。
- **敌对势力基本不可避免**（Q-056）。
- **种子来自冒险**：播在肥沃格（累计 3 / 6 / 9），产出食物 / 战果 / 工具效果（Q-064 / Q-067）。
- **收获型种子按类型产出**：每颗种子固定产出食物或某一种战果，战果存入道具栏（Q-071 ~ Q-073）。战果定位接近法术卡：加属性或挂 buff（Q-094）。
- **招募窗口在回合开始 + 事件触发**：两处都可反复招募，直到玩家点「结束招募」；不再占用三选一（Q-068）。
- **三选一默认只能选一个**；部分虫珀 / 物品可解锁多选（Q-037）。
