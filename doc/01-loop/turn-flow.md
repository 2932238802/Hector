# 回合流程（草案 v0.1）

> 时间：1 季 = 6 回合；1 局 = 24 回合（见 `time-and-seasons.md`）。
> 本文件写“一回合里发生什么”；数值待平衡。
> 2026-11-08 用户口述：回合开始 / 每个事件之前的准备时间。

## 0. 开局状态（2026-11-09）

- 巢穴 **L2**：中心蚁后室 + 7 格，其中 **3 个肥沃格**。
- 初始食物 **15**，起始种子 **1 颗基础食物型**。
- 第一回合即可：播种 / 冒险 / 扩建 / 恢复，无强制开场流程。
- 一局内可扩建 2 次：L2 → L3 → L4（肥沃格 3 → 6 → 9）。

## 1. 准备窗口

> 用户原话：“回合开始的时候，或者说每个事件之前的准备时间。”
>
> 当前按 **每回合一次** 记录：在事件组之前。
> 如果实际是“每个事件 A / B / C / D 前都发生一次”，一回合就会有 4 次收入 + 4 次三选一；
> 这个时点差异很大，登记为 Q-035。

## 1.5 双时钟

- **生产时钟：事件**——生产单位按事件计周期。
- **恢复时钟：回合**——工蚁恢复巢穴健康按回合结算（用户 2026-11-08 强调“注意是回合”）。
- 两者不冲突：一回合内有多个事件，生产可在事件间触发；恢复每回合结算一次。
- 收入 / 三选一的时点仍待确认（Q-035）。

## 2. 收入与工蚁

1. **收入汇报**
   - 显示本回合食物的产出与消耗。
   - 收入来自**已播种的收获型种子**（生产单位）；生产周期以**事件**为最小单位，周期 N 由种子类型决定（Q-064 / Q-069）。
   - 每条种子的产出是**食物或某一种战果**，固定不混产（Q-071）。
   - 生产在事件结算时触发还是回合开始汇总，待定（Q-045）。
2. **蚁后生成工蚁**
   - 蚁后每回合产出一定数量工蚁；数量待定（Q-025）。
   - 工蚁是巢穴的修复力，也是探索的消耗品。
   - **工蚁数量 = 每回合巢穴健康恢复的基数**：工蚁越多，恢复越多（公式待定，Q-054）。
   - 工蚁也可以被牺牲去冒险，换取高回报。

## 3. 主观行动（三选一）

玩家拿着本回合收入，从一组**主观行动**中选一个（暂定）：

| 行动 | 做什么 | 风险 / 代价 | 收益 |
|---|---|---|---|
| **冒险** | 周边探索 | 牺牲工蚁；数量由遇到的随机事件决定；可能遇敌对势力 | 食物、虫珀、种子 |
| **巢穴恢复** | 修复巢穴完整度 | 消耗食物 | 巢穴健康回升 |
| **巢穴扩建** | 向外扩一圈 | 消耗食物 | 新增 3 个肥沃格，开放播种 |
| **等** | 迁移、其他主观行动 | 待定 | 待定 |

- **冒险**：探索在蚁穴外；牺牲工蚁数量与探索遇到的随机事件有关（Q-039）；恶劣天气 / 气候、寄生虫等事件会放大牺牲数量。
- **巢穴恢复**：主动修复，恢复量显著高于工蚁被动恢复；具体消耗与数值待定（Q-046 / Q-054）。
- **巢穴扩建**：向外扩一圈，累计肥沃格变为 3 / 6 / 9，新增格开放播种（Q-065）。
- **默认只能选一个**；部分虫珀 / 物品可以让你选多个（Q-037）。
- 候选可能多于 3 个（当前列出 4 类），最终菜单与每回合出现几个待定（Q-046）。
- **招募改为事件触发**，不占三选一：触发时 3 选 1，以食物为主（见 `units.md`、Q-047 / Q-068）。

## 3.5 播种窗口

- 触发：每次**巢穴扩建**之后。
- 内容：在新增的 3 个肥沃格播种；种子来自冒险。
- 播种是否消耗食物 / 占行动待定（Q-065）。
- 一局最多同时照料 9 颗种子（L4）。

## 4. 事件组

- 准备阶段结束后，进入本回合的事件组（N 选 1，见 `events.md`）。
- 组内 A → B → C → D：每个事件前有准备窗口（布兵 / 环境 / 天气防护）。
- 事件可能触发**招募**、带回**种子**。
- 点击「准备就绪」→ 结算当前事件 → 进入下一个事件。

## 5. 回合结束

- 事件组结算完 → 回合奖励（内容待定）。
- 进入下一回合。

## 6. 时序图

```
回合开始
  → 收入汇报
  → 蚁后生成工蚁
  → 工蚁数量 → 巢穴健康恢复
  → 三选一：冒险 / 巢穴恢复 / 巢穴扩建等
  → 选事件组（N 选 1）
  → A → B → C → D（准备 → 准备就绪 → 结算）
  → 回合奖励
  → 下一回合
```

## 7. 关键规则

- **收入来自收获型种子**：种子即生产单位，周期以**事件**为最小单位（Q-064 / Q-069）。
- **不做建筑系统**：三选一中的“建筑升级”改为**巢穴扩建**，只负责开放肥沃格（2026-11-09）。
- **工蚁是消耗品**：探索会牺牲工蚁；工蚁数量决定每回合巢穴健康恢复（Q-054）。
- **食物是招募的主要工具**：不再使用工蚁转化（Q-041）。
- **士兵不会因战斗消失，也不会饿死**：战斗失败 → 士兵返场，损失的是巢穴完整度；战斗会损耗食物（Q-036 / Q-049 / Q-052）。
- **恶劣天气 / 气候会放大战斗食物损耗与冒险工蚁损失**（Q-053）。
- **敌对势力基本不可避免**（Q-056）。
- **种子来自冒险**：播在肥沃格（累计 3 / 6 / 9），产出食物 / 战果 / 工具效果（Q-064 / Q-067）。
- **收获型种子按类型产出**：每颗种子固定产出食物或某一种战果，战果存入道具栏（Q-071 ~ Q-073）。战果定位接近法术卡：加属性或挂 buff（Q-094）。
- **招募改为事件触发**，不再每回合固定出现（Q-068）。
- **三选一默认只能选一个**；部分虫珀 / 物品可解锁多选（Q-037）。
