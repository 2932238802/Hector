# 回合流程（草案 v0.1）

> 时间：1 季 = 10 回合；1 局 = 40 回合（见 `time-and-seasons.md`）。
> 本文件写“一回合里发生什么”；数值待平衡。
> 2026-11-08 用户口述：回合开始 / 每个事件之前的准备时间。

## 1. 准备窗口

> 用户原话：“回合开始的时候，或者说每个事件之前的准备时间。”
>
> 当前按 **每回合一次** 记录：在事件组之前。
> 如果实际是“每个事件 A / B / C / D 前都发生一次”，一回合就会有 4 次收入 + 4 次三选一；
> 这个时点差异很大，登记为 Q-035。

## 1.5 双时钟

- **生产时钟：事件**——生产单位按事件计周期。
- **恢复时钟：回合**——工蚁恢复巢穴健康按回合结算（用户 2026-11-08 强调“注意是回合”）。
- 两者不冲突：一回合内有多个事件，生产可在事件间触发；恢复每回合结算一次。
- 收入 / 三选一的时点仍待确认（Q-035）。

## 2. 收入与工蚁

1. **收入汇报**
   - 显示本回合食物 / 石头 / 植物纤维的产出与消耗。
   - 收入来自**生产单位**；生产周期以**事件**为最小单位，周期长度与生产单位等级有关（Q-044）。
   - 工蚁是否参与生产、如何分配到生产单位，待定（Q-044）。
   - 具体结算时点待定（Q-045）。
2. **蚁后生成工蚁**
   - 蚁后每回合产出一定数量工蚁；数量待定（Q-025）。
   - 工蚁是巢穴的修复力，也是探索的消耗品。
   - **工蚁数量 = 每回合巢穴健康恢复的基数**：工蚁越多，恢复越多（公式待定，Q-054）。
   - 工蚁也可以被牺牲去冒险，换取高回报。

## 3. 主观行动（三选一）

玩家拿着本回合收入，从一组**主观行动**中选一个（暂定）：

| 行动 | 做什么 | 风险 / 代价 | 收益 |
|---|---|---|---|
| **冒险** | 周边探索 | 牺牲工蚁；数量由遇到的随机事件决定；可能遇敌对势力 | 资源、虫珀、种子 |
| **基地恢复** | 修复巢穴完整度 | 消耗资源 | 巢穴健康回升 |
| **建筑升级点数** | 投入建筑升级 | 消耗资源 / 点数 | 生产单位升级，缩短周期或提高产量 |
| **等** | 迁移、其他主观行动 | 待定 | 待定 |

- **冒险**：探索在蚁穴外；牺牲工蚁数量与探索遇到的随机事件有关（Q-039）；恶劣天气 / 气候、寄生虫等事件会放大牺牲数量。
- **基地恢复**：主动修复，恢复量显著高于工蚁被动恢复；具体消耗与数值待定（Q-046 / Q-054）。
- **建筑升级点数**：投入建筑升级；内穴扩张后新增外圈格可播种（Q-044 / Q-065）。
- **默认只能选一个**；部分虫珀 / 物品可以让你选多个（Q-037）。
- 候选可能多于 3 个（当前列出 4 类），最终菜单与每回合出现几个待定（Q-046）。
- **招募改为事件触发**，不占三选一：触发时 3 选 1，以食物为主（见 `units.md`、Q-047 / Q-068）。

## 3.5 播种窗口

- 触发：每次巢穴升级、内穴扩张之后。
- 内容：在新增外圈格播种；种子来自冒险。
- 播种是否消耗资源 / 占行动待定（Q-065）。

## 4. 事件组

- 准备阶段结束后，进入本回合的事件组（N 选 1，见 `events.md`）。
- 组内 A → B → C → D：每个事件前有准备窗口（布兵 / 环境 / 天气防护）。
- 事件可能触发**招募**、带回**种子**。
- 点击「准备就绪」→ 结算当前事件 → 进入下一个事件。

## 5. 回合结束

- 事件组结算完 → 回合奖励（内容待定）。
- 进入下一回合。

## 6. 时序图

```
回合开始
  → 收入汇报
  → 蚁后生成工蚁
  → 工蚁数量 → 巢穴健康恢复
  → 三选一：冒险 / 基地恢复 / 建筑升级等
  → 选事件组（N 选 1）
  → A → B → C → D（准备 → 准备就绪 → 结算）
  → 回合奖励
  → 下一回合
```

## 7. 关键规则

- **收入来自生产单位**：生产周期以**事件**为最小单位，周期长度与生产单位等级有关（Q-044 / Q-045）。
- **工蚁是消耗品**：探索会牺牲工蚁；工蚁数量决定每回合巢穴健康恢复（Q-054）。
- **食物是招募的主要工具**：不再使用工蚁转化（Q-041）。
- **士兵不会因战斗消失，也不会饿死**：战斗失败 → 士兵返场，损失的是巢穴完整度；战斗会损耗食物（Q-036 / Q-049 / Q-052）。
- **恶劣天气 / 气候会放大战斗食物损耗与冒险工蚁损失**（Q-053）。
- **敌对势力基本不可避免**（Q-056）。
- **种子来自冒险**：播种在外圈，收获资源或提供 buff（Q-064 / Q-067）。
- **生产单位还产出战粮**：强化食物存入道具栏，战斗中使用（Q-071 ~ Q-073）。
- **招募改为事件触发**，不再每回合固定出现（Q-068）。
- **三选一默认只能选一个**；部分虫珀 / 物品可解锁多选（Q-037）。
