# 局外成长、难度与无尽（草案 v0.1）

> 2026-11-09 用户口述：最终胜利 = 撑过冬天；可选无尽模式；难度 1–20 对标一个虫种的熟练度。
> 本文只定**结构与方向**；每级具体修正器与数值登记为待定。

## 1. 一局的胜负

| 结果 | 条件 |
|---|---|
| **默认胜利** | **撑过冬天**：第 24 回合（冬季第 6 回合）结束时，巢穴完整度 > 0 |
| **失败** | 巢穴完整度归零（任意时刻） |
| **无尽** | 胜利后可**主动选择**继续；默认不进入 |

- 胜利后是否播放终局事件（初霜 / 大洪水 / 敌巢总攻 / 越冬）待定。
- 蚁后死亡是否直接判负、还是折算为巢穴完整度归零，待定（Q-081）。
- 其他失败条件（例如关键种子全毁）不设，保持单一血条（见 `nest-honeycomb.md` 5.1）。

## 2. 无尽模式

- 触发：默认胜利后出现选项「继续越冬 / 进入无尽」；默认选「结束」。
- 进入后季节循环：春 → 夏 → 秋 → 冬 → 春……
- 每轮循环敌人与事件强度递增；递增曲线待定（Q-080）。
- 无尽模式是否计入熟练度 / 难度解锁，待定（Q-080）。
- 无尽模式不再有“胜利”，只有“撑到第几轮”的记录。

## 3. 熟练度与难度 1–20

- **每个虫种独立**的熟练度 / 难度进度。
- 初始开放 **难度 1**。
- 以某虫种通关难度 N → 解锁该虫种的 **N+1**。
- **难度 20** 是该虫种的最终挑战。
- 难度即熟练度：一个数字，不另设经验条。
- 通关是否给永久奖励（新兵种 / 新种子 / 外观），待定（Q-079）。
- 换虫种不继承难度进度；共享内容（虫珀、事件）是否共享，待定。

## 4. 难度修正器（候选）

> 方向来自用户 2026-11-09 举例；具体每级挂哪个、数值多少待定（Q-078）。
> 食物是唯一资源，因此“金钱减少”落地为**食物收入减少**。

| 修正器 | 效果方向 | 影响的决策 |
|---|---|---|
| 食物收入降低 | 种子产量 / 初始食物下降 | 更紧的分配 |
| 恶劣天气增多 | 下雨等负向天气概率上升 | 冒险损失与探索风险 |
| 虫珀出现概率降低 | 遗物更少 | 少一条成长线 |
| 招募费用提高 | 兵种食物成本上升 | 军队成型更慢 |
| 敌人更强 | 敌方 HP / 攻击上升 | 战斗更险 |
| 敌人更多 | 敌方上场数量增加 | 阵型与 AOE 价值上升 |
| 巢穴完整度上限降低 | 容错变小 | 修复优先级上升 |
| 事件惩罚加重 | 失败后果更重 | 准备阶段更重要 |
| 初始资源减少 | 开局食物 / 种子减少 | 开局更紧 |
| 最终裁决掉落进一步减少 | 拖局收益更低 | 鼓励主动清场 |
| 精英 / Boss 提前 | 强敌出现更早 | 成长曲线压缩 |

## 5. 叠加原则

- 每级新增 **1–2 个修正器**，后期叠加；不一次性全开。
- 优先改变**决策结构**（天气频率、虫珀概率、招募成本），而不是单纯加数值。
- 高难度应让玩家“换打法”，而不是“同一套打法数字更大”。
- 具体 1–20 的配置表待设计（Q-078）。

## 6. 内容拓展方向

- 后续拓展以**新增兵种、新增虫种**为主（2026-11-09 确认，Q-097）。
