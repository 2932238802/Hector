### 3.3 数据文件结构没跟上 `data-contract.md`

- `signature` 是 **string**；契约要求 `{id, name, text, params}`，**数值不得写死在 `text` 里**（弩手 30%、采薇 +1–3 等现在都是字符串）。
- **缺 `keywords: string[]`**；`weakness` / `status` 也缺。
- 契约第 8 节要求 `keywords` 取枚举值、`hp / attack` 最多 1 位小数；当前加载器只校验 `schema_version` 与必填顶层字段，**不做枚举 / 小数位校验**。
