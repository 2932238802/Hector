# 最小回合 MVP（2026-11-11）

> **已废弃（2026-11-11）**：本页记录的是临时 MVP。用户确认后已改为直接在 `scenes/main.tscn` / `scripts/core/game_state.gd` 上向成品推进；正式切片见 `spring-v0.md`，实现状态见 `../05-handoff/dev-status.md`。`scripts/mvp/`、`scenes/mvp.tscn`、`tools/run_mvp.ps1` 保留作历史参考，不再迭代。

> 目的：先跑通 **一个能亲手玩的回合**，感受「粮 → 兵 → 战斗 → 再投资」的节奏，再决定下一步扩什么。
> 这不是正式切片，也不替代 `spring-v0.md`；它只保留最核心的一条循环，规则按当前文档裁到最小。

## 1. 一回合长什么样

```
回合开始
  → 招募事件：3 选 1（4 食物），可刷新（1 食物），可跳过
  → 经营：从「播种 / 修复 / 仓曹训练 / 跳过」里选 1 个
  → 战斗：自动结算，前排全灭后才打后排
  → 结算：胜利 +3 食物；每块田 +2 食物；全队生命回满
  → 下一回合（共 3 回合）
```

- **胜利**：撑过 3 回合且巢穴完整度 > 0。
- **失败**：巢穴完整度归零（战斗失败 −5，满值 20）。
- 单位**不会永久死亡**；战斗结束后按文档规则回满生命。

## 2. 最小数值

| 项 | 值 |
|---|---|
| 开局食物 | 15 |
| 开局队伍 | 候望蚁 + 弧矢蚁 |
| 开局田 | 1 块（每回合 +2 食物） |
| 招募 | 4 食物 / 次；刷新 1 食物；每回合 1 次 |

| 战斗奖励 | 胜利 +3 食物 |

## 4. 明确不在 MVP 里

- 种子三选一、田的产出大类、收获周期、开仓 / 守廪主动技能。
- 七格阵型摆位（MVP 自动按前排优先）。
- 战果、虫珀、事件组、天气 / 季节、巢穴扩建、二星合成。
- 招募池的阶级概率与升阶保底（MVP 固定从 6 人池抽 3）。

## 6. 玩过之后要拍板的事

1. **一回合的行动数**：现在只能选 1 个（播种 / 修复 / 训练），是否太少？
2. **招募频率**：每回合都有 3 选 1 是否过密？要不要改成事件触发。
3. **战斗长度**：当前 2–4 轮自动结算；要不要让玩家手动分配行动点。
4. **田的回本速度**：3 食物播种、每回合 +2，3 回合内刚好回本；是否改成周期产出。
5. **先扩哪条线**：种子 / 战果 / 阵型 / 虫珀，只能先选一个。
