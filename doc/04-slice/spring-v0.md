# 春季垂直切片 v0（第一季 · 一阶）

> **范围**：只做「第一个大回合」= 春季（6 回合 / 24 次事件结算）＋ 一阶兵种。
> 夏 / 秋 / 冬、二阶 / 三阶、天赋、羁绊、完整虫珀池全部**不在本期**。
> **目的**：让这一季能从头玩到尾，并把调参链路（`data/*.json` → 网页工具 → Godot 热更）跑通。
> **文件分工**：兵种见 `03-content/units.md`，虫种见 `species.md`，战果见 `results.md`，虫珀见 `relics.md`。本文件只写"这一季怎么串起来"，不复制条目。

## 2. 开局流程（Q-114 已定）

1. 巢穴 **L2**：7 格、**3 个肥沃格**。
2. 起始资源：**15 食物**、**1 颗基础食物种子**。
3. 巢穴完整度：**100 / 100**。
4. **开局免费招募 2 次**：每次从**一阶池（12 个）**随机 3 选 1，免费、不占行动。
5. 两次招募完成后进入第 1 回合；**不预设固定开局阵容**（用户 2026-11-09 定）。
6. 若两次招募都跳过，第一场战斗只能谈判 / 回避——这是玩家的选择，不额外补偿。

> **风险登记**：开局只有 2 个兵（用户 2026-11-09 定）；`combat-math.md` 的早期敌人数量提案是 3–4 个，两者是否匹配、每场数量调到多少，**要等敌人设计完成后才能定**（Q-122）。

## 3. 回合循环（一局 6 回合）

```
回合开始
  → 显示天气（当回合 + 未来 2 回合预报）
  → 结算维持：食物 − (1 + ceil(人口 / 5))
  → 结算种子产出（按各自周期）
  → 生成 3 个事件组（春季权重，模板不重复）
  → 玩家选 1 组 → 组内 A → B → C → D 依次结算
  → 三选一（冒险 / 巢穴恢复 / 巢穴扩建等，见 Q-046）
  → 回合结束
```

- 每回合固定 **3 组**（切片不做 4–5 组）。
- 每季 **6 回合**；第 6 回合结束 = 春季结束，切片在此收尾并展示结算画面。

## 5. 天气（春季 6 回合）

- **季初一次性生成 6 个天气**；每回合 1 个，A→D 共用。
- 预报：默认看**未来 2 回合**（Q-091）。
- 约束：连续同天气 ≤ 3；6 个天气里至少 1 晴、至少 1 非晴。
- 效果：晴 = 正向（生产 +1，提案）；多云 = 无修正；雨 = 战斗补给 ×1.5、探索工蚁损失 +1。

## 8. 战斗流程（切片速查）

- 布阵：前排 4 / 后排 3；开战锁定；前排全灭才可打后排。
- 支付：部署确认后按出场单位付补给；付不起撤人；一个都派不出 → 只能谈判 / 回避。
- 行动：我方阶段自由顺序，每单位 1 行动点；敌方阶段自动。
- 轮数：目标 3–4 轮；第 6 轮结束未分胜负 → 最终裁决。
- 战后：**所有参战单位 HP 回满（含阵亡）**；士兵不消失；失败只扣巢穴完整度。
