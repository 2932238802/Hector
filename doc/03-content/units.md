# 兵种系统（卡牌层）

> 类比：卡牌。
> 但注意：**"类似卡牌"指收集与构筑结构，不是抽牌打牌。** 战斗是实际部署蚂蚁队伍。
> **详细设计暂缓（2026-11-08）**：先确立设计原则，具体兵种稍后定稿。

## 1. 定位

- 兵种是局内招募、编队、部署的单位。
- 你的兵种池 = 你的"牌库"；招募 = 以食物为主；人口上限 = 场上限制。
- 战斗不是手牌结算，而是把蚂蚁派到**蚁穴外**迎敌；蚁穴内则负责生产 / 防御准备。

## 1.5 设计原则（2026-11-08）

- **每个兵种都有优点和缺点。**
- **没有一只兵种能完美替代另一只。**
- **所有兵种都应该有用**，强弱取决于搭配与取舍。
- 不做"数值上位替代"：新兵种不是旧兵种的严格升级。
- 玩家的乐趣来自"看自己的搭配、做自己的取舍"。

## 1.6 士兵的持久性（2026-11-08）

- **士兵是持久资产**：战斗不会让士兵消失，也**不会饿死**（2026-11-08 确定）。
- 战斗失败 → 扣巢穴完整度；士兵保留。
- 战斗失败 → 士兵返场；损失的是巢穴完整度。
- **战斗的真实代价是食物**：每次战斗损耗食物，恶劣天气会放大（Q-052 / Q-053）。
- **战斗补给按兵种计**：每个出场单位每次战斗消耗一定食物，空位不计，数值待填（Q-052）。
- **工蚁是消耗品**：探索会牺牲；工蚁数量决定每回合巢穴健康恢复。

## 2. 结构模板

每个兵种定义：

| 字段 | 说明 |
|---|---|
| 名称 / 阶级 | 工蚁、兵蚁、特化蚁 |
| 标签 | 采集、战斗、建造、侦察、自杀、守护 |
| 资源配方 | 食物 + 石头 / 纤维等 |
| 食物成本 | 生成该兵种需要多少食物（主要成本） |
| 战斗补给 | 每次出场消耗的食物（按兵种不同） |
| 生命 / 攻击 / 防御 / 速度 | 基础数值 |
| 被动 / 主动 | 技能 |
| 经济职能 | 采集、挖掘、产粮、储粮 |
| 战斗职能 | 前排、输出、控制、自爆 |
| Combo | 和哪些兵种/蚁种咬合 |

## 3. 招募机制

- **招募改为事件触发**（2026-11-08 确定）：不再每回合固定 3 选 1。
- 触发来源：商人 / 中立生物 / 巢穴事件等（待定，Q-068）。
- 触发时仍是 **3 选 1**。
- 生成 = **食物为主 + 少量其他资源**；具体配方按兵种不同。
- **不再使用工蚁转化**（2026-11-08 确定）。
- 食物或材料不足时，对应兵种不进入候选，或显示"不可招募"。
- 可牺牲食物刷新一次；部分虫珀可刷新一次（Q-042 / Q-048）。
- 人口上限由巢穴与蚁后决定；满员时不能招募。
- 候选池按蚁种加权：共享池 + 蚁种专属池。
- **候选池受探索进度限制**：没发现对应种子 / 材料，就刷不出对应兵种。

## 3.5 探索解锁兵种

- 招募池不是一开始全开。
- 探索带回特殊种子 / 材料后，对应兵种才进入候选池。
- 例：
  - 带回黏土相关种子 → 解锁黏土系建筑 / 兵种
  - 带回树脂相关种子 → 解锁树脂系兵种
  - 带回菌床种子 → 解锁真菌系兵种
- 因此**探索是招募的前置**，不是可选支线。

## 4. 首版共享兵种（占位）

| 兵种 | 配方 | 战斗补给（食物） | 定位 | 技能 |
|---|---|---|---|---|
| 工蚁 | 3 食物（可选；主要靠蚁后生成） | —（不能出战） | 经济 | 采集 +1；可挖掘/建造 |
| 兵蚁 | 5 食物 + 2 石头 | ? | 前排 | 高血，基础攻击 |
| 侦察蚁 | 3 食物 + 1 纤维 | ? | 情报 | 开图、预警 |
| 采集蚁 | 4 食物 | ? | 经济 | 采集 +2 |
| 守卫蚁 | 5 食物 + 2 石头 | ? | 防御 | 扼守 / 减伤 |
| 爆炸蚁 | 4 食物 + 1 纤维 | ? | 自爆 | 范围伤害；自爆后返场（是否例外待定） |

> 数值为首版占位，待平衡。
> 工蚁不能出战，只用于生产 / 探索 / 转化。

## 4.5 战粮（强化食物）

- 生产单位除普通食物外，产出**给士兵增加属性的食物**，暂称“战粮”。
- 战粮存入**道具栏**（平面列表，不做背包网格），战斗中使用。
- 示例方向：临时攻击、生命、防御、速度（数值待定，Q-074）。
- 产出方式、存放容量、使用规则待定（Q-071 ~ Q-073）。

## 5. 专属兵种

每个蚁种有 2–4 个专属兵种，只能在该蚁种局中出现。示例：

- 行军蚁：突袭蚁、行军兵蚁
- 切叶蚁：菌农蚁、园丁蚁
- 织叶蚁：织工蚁、桥梁蚁
- 蜜罐蚁：蜜罐蚁、守卫蚁
- 收获蚁：收获工蚁、种子守卫

## 6. 成长与持久性

- **士兵是持久资产**：战斗不会让士兵消失，也不会饿死；工蚁才是消耗品。
- 兵种本身是否升级 / 老兵系统待定。
- 成长来自：
  - 招募更强的兵种
  - 事件 / 天赋给单个蚂蚁附加变异
  - 蚁种被动与巢穴加成
  - 虫珀

> 旧说法“蚂蚁是消耗品，死了就没了”作废（2026-11-08）。

## 7. Combo 示例

| 组合 | 效果 |
|---|---|
| 行军蚁 + 蜜罐蚁 | 战利品存起来，撑过断粮期 |
| 织叶蚁 + 采集蚁 | 搭桥缩短采集路线，效率翻倍 |
| 切叶蚁 + 守卫蚁 | 守住真菌农场，滚雪球 |
| 侦察蚁 + 爆炸蚁 | 提前发现敌群，自爆埋伏 |
