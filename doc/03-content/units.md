# 兵种系统（卡牌层）

> 类比：卡牌。
> 但注意：**"类似卡牌"指收集与构筑结构，不是抽牌打牌。** 战斗是实际部署蚂蚁队伍。
> **详细设计暂缓（2026-11-08）**：先确立设计原则，具体兵种稍后定稿。

## 1. 定位

- 兵种是局内招募、编队、部署的单位。
- 你的兵种池 = 你的"牌库"；招募 = 以食物为主；出战格（前 4 + 后 3） = 场上限制。
- 战斗不是手牌结算，而是把蚂蚁派到**蚁穴外**迎敌；蚁穴内则负责生产 / 防御准备。

## 1.5 设计原则（2026-11-08）

- **每个兵种都有优点和缺点。**
- **没有一只兵种能完美替代另一只。**
- **所有兵种都应该有用**，强弱取决于搭配与取舍。
- **每个兵种必须有签名特性**（2026-11-09 定）：至少 1 个能一句话说清“为什么选它”的被动或主动；共用关键词只是实现手段，不替代签名特性。
- **兵种都是战斗单位**（2026-11-09 定）：不存在“驻守巢穴 / 在家生产”的非战斗状态；经济型兵种的收益必须挂在**参战或战斗结算**上，不设计脱离战斗的生产模式。
- **成长不设硬上限**（2026-11-09 定）：兵种成长、战果叠加不做数值封顶，优先满足玩家“越打越强”的感觉。
- 不做"数值上位替代"：新兵种不是旧兵种的严格升级。
- **数值允许小数**：HP / 攻击可用 1 位小数，不强制整数（2026-11-09 定）。属性只保留 **HP / 攻击 / 行动点**；**防御与速度已删除**（2026-11-09 定，见 `combat.md` / `combat-math.md`）。
- **攻击有波动**：以攻击力为基数的伤害按 **±10%** 浮动，双方通用；内部与 UI 保留 1 位小数（2026-11-09 定，见 `combat.md` Q-028）。
- 玩家的乐趣来自"看自己的搭配、做自己的取舍"。

## 1.6 士兵的持久性（2026-11-08）

- **士兵是持久资产**：战斗不会让士兵消失，也**不会饿死**（2026-11-08 确定）。
- 战斗失败 → 扣巢穴完整度；士兵保留。
- **战斗失败 → 士兵返场；损失的是巢穴完整度。**
- **战后 HP 一律回满**（2026-11-09 定）：每场战斗结束后，所有参战单位 HP 回满，**包括本场阵亡的单位**；HP 不跨场累积。
- **战斗不额外消耗食物**（2026-11-09 改定）：**取消「战斗补给」**，出战本身不扣食物；食物压力只剩招募、修复与扩建。
- **食物不能扣到 0 以下**：任何支付最多扣到 0，不足即为“付不起”。
- 战斗失败仍然只扣巢穴完整度；士兵保留、战后 HP 回满。
- **士兵是持久资产**：战败返场、不会饿死；没有工蚁 / 人口层（2026-11-09 删除工蚁系统，Q-025）。

## 2. 结构模板

每个兵种定义：

| 字段 | 说明 |
|---|---|
| 名称 / 阶级 | 弧矢蚁、专属兵种 |
| 标签 | 采集、战斗、建造、侦察、自杀、守护 |
| 食物成本 | **统一 4 食物**（2026-11-11 定；不再逐兵种定价） |
| 生命 / 攻击 | 基础数值；可用 1 位小数（**无防御 / 速度**；战斗只有数值与状态，**没有减伤**） |
| 行动点 | 每轮可行动次数；**所有兵种基础 1 点**，技能 / 虫珀 / 特性可提高（见 `combat.md`） |
| 签名特性 | **每兵种至少 1 个**；被动或主动，可用共用关键词实现（见 `combat.md` 6） |
| 被动 / 主动 | 技能 |
| 经济职能 | 采集、挖掘、产粮、储粮 |
| 战斗职能 | 前排、输出、控制、阵亡爆炸 |
| Combo | 和哪些兵种/虫种咬合 |

## 3. 招募机制

- **招募窗口在回合开始 + 事件触发**（2026-11-11 定）：不占三选一。
- 每回合开始时固定打开一次招募窗口；事件也可能触发额外窗口（Q-068）。
- 每个窗口都是 **3 选 1**，且**可反复招募**，直到玩家点「结束招募」。
- 生成 = **食物**；统一 4 食物 / 个（见 `economy.md`）。
- **不做单位转化**（2026-11-08 确定）。
- 食物不足时，对应兵种不进入候选，或显示"不可招募"。
- 刷新候选：优先消耗免费刷新，否则 **1 食物 / 次**，可反复刷新；部分虫珀可提供免费刷新（Q-042 / Q-048）。
- 可持有兵种数量 / 招募上限由什么决定，待定（Q-123）。
- 候选池按虫种加权：**共享池 12 + 虫种专属池 24**。
- **候选池按当前阶级概率抽取**（2026-11-09 定，Q-103）：L1 只出一阶；L2 出一阶 60% / 二阶 40%；L3 出一阶 45% / 二阶 35% / 三阶 20%；每个候选独立结算。升阶后第一次招募有**新阶级保底**，详见 4.0。
- **候选池按巢穴等级解锁**（Q-103）：L1 只出一阶，L2 加入二阶，L3 加入三阶；不受探索进度限制。

## 3.5 兵种解锁（2026-11-09 改定）

- 招募池**按巢穴等级分批开放**：L1 一阶 / L2 二阶 / L3 三阶，出现率见第 3 节与 4.0。
- 旧的“探索带回种子 → 解锁对应兵种”方案**已废止**；种子只作为生产单位，不再承担兵种解锁。
- 升阶后第一次招募有**新阶级保底**。

### 4.0 阶级 = 解锁层级（2026-11-09 定，Q-103）

- **阶级不是数值升阶**：不做同一兵种的 L1 / L2 / L3 三套数值，也不做同一兵种的高阶严格上位。
- **每个兵种只有一个条目**；阶级只决定它**什么时候进入招募池**。
- 阶级只决定**解锁时机**；兵种之间的差异由**定位 + 签名特性**承担，不由阶级承担。
- **名称统一为「一阶 / 二阶 / 三阶」**，对应巢穴等级：**一阶 = L1，二阶 = L2，三阶 = L3**（2026-11-09 定）。文档和 UI 不再用“一级 / 二级 / 三级”，避免玩家误以为一级 = L1。

**阶级的角色分工（2026-11-09 定）**

- **一阶 = 成长位，很多是未来的大哥**：不少一阶兵种靠签名特性滚雪球（仓曹蚁、馈粮蚁、烽燧蚁），**早期投入培养没有问题**，它们不是“过渡货”，不保证会被高阶替换。
- **二阶 / 三阶 = 机制位**：价值在**机制**（规则、组合、资源转换、条件触发），而不是数值上位。补的是“新打法”，不是“更强的同一件事”。
- 推论：**一阶兵必须有撑到后期的成长 / 转换路径**；反过来，二阶 / 三阶兵如果只是“一阶的加强版”，就是设计失败。
- 这条不推翻 4.0 的「阶级不是数值升阶」：阶级仍只决定解锁时机，但**强度不随阶级单调上升**。

**可适用玩法标签（2026-11-09）**

- 手册里每个兵种都标注了 **1–3 个玩法标签**（如 积廪 / 劝农 / 守廪 / 承伤 / 控场 / 战果流 / 花粮），用于检索与搭配提示。
- 标签**不是规则、不产生效果**，只说明这个兵种适合往哪个方向搭；实际判定以签名特性与数值为准。
- 三个虫种专属流派的标签（积廪 / 劝农 / 守廪）来自 `species.md` 3.0 的流派骨架；共享兵种只标通用玩法。

**每虫种总池：目标 36 = 共享 12 + 专属 24（当前实装 31 = 共享 12 + 专属 19；2026-11-11 改定）**

- **共享池（目标 12、实装 12）是全局共用池**；**专属 24 个是每个虫种各一套**，不同虫种的专属池不互通。
- **专属 24 = 三条玩法线**（廪实：积廪 / 劝农 / 守廪）；每条线内部按「五类角色」配齐（见 4.0.2）。

| 阶级 | 对应巢穴 | 共享 | 专属 | 累计可用 | 本阶新增 |
|---|---|---|---|---|---|
| 一阶 | L1 | 6 / 6 | 8 | 14 / 18 | 14（共享 6 + 专属 8） |
| 二阶 | L2 | 10 / 10（累计） | 15 | 25 / 30 | 11（共享 +4，专属 +7） |
| 三阶 | L3 | 12 / 12（累计） | 19 | 31 / 36 | 6（共享 +2，专属 +4） |

> 共享列与累计列为「实装 / 目标」；共享池已满编（12 / 12）。

**招募时各阶出现率（按每个候选独立抽取，暂定，Q-106）**

| 当前巢穴 | 一阶 | 二阶 | 三阶 |
|---|---|---|---|
| L1（一阶池） | 100% | — | — |
| L2（一阶 + 二阶池） | 60% | 40% | — |
| L3（全池） | 45% | 35% | 20% |

- 每档合计 100%；概率按**每个候选**独立结算，不是整次招募只抽一次阶级（暂定，Q-106）。
- 池子变大后，同一阶级的单个兵种出现率被摊薄；**升阶保底**仍然保证第一次招募必出新阶级。
- **升阶保底（2026-11-09 定）**：每次升到新阶级后的**第一次招募**，至少出现 **1 个新阶级单位**。即：升 L2 后第一次招募必出二阶单位；升 L3 后第一次招募必出三阶单位。保底只作用于该次招募，不改变后续概率；保底单位是否必须付得起待定（Q-106）。
- 设计意图：给巢穴扩建第二收益（当前只有肥沃格 + 植物携带数），同时控制前期招募池的信息量。
- 具体每个阶级放哪些兵种**已排定名单**（2026-11-11 改定，Q-105）：共享 **一阶 6 个（候望蚁 / 燧火蚁 / 弧矢蚁 / 烽燧蚁 / 耘耨蚁 / 度支蚁）；二阶 4 个（驿传蚁 / 赳武蚁 / 将作蚁 / 因粮蚁）；三阶 2 个（旌旗蚁 / 钦天蚁）**（2026-11-11 删除先锋蚁 / 城守蚁 / 辅弼蚁 / 网罟蚁；司农蚁 / 质库蚁移入廪实专属；烽燧蚁 / 耘耨蚁移入共享；度支蚁补最后一个一阶位）。旧名对照见第 4 节表。数值统一待测试校准（Q-109 / Q-118 / Q-119）。专属 19 个已出廪实重构提案（见 5.0，Q-107 / Q-136）。
- 招募抽取细节（是否允许同种重复、保底与刷新如何交互）待定（Q-106）。

> 招募池的“分批”不等于“高阶兵种更强”；每个兵种仍按定位与缺点设计，不做数值上位替代。

### 4.0.1 兵种服务于玩法（2026-11-11 定，总原则）

> 任何兵种必须先回答「它改变玩家的哪个决策」，再回答「它在战斗里做什么」。顺序不能反。

- **每个兵种至少声明一个玩法接口**，且必须写进条目：

| 接口 | 玩家决策 | 兵种怎么接入 |
|---|---|---|
| **经济 / 种子** | 这块田种什么、什么时候换线 | 营巢触发：返粮、改产出大类、加速周期、降低播种成本 |
| **事件 / 探索** | 这组事件接不接、怎么接 | 战斗外修正：探索损耗、谈判收益、天气 / 事件预览、招募保底 |
| **巢穴 / 扩编** | 修巢还是扩巢、招谁 | 完整度恢复、扩建经验、招募折扣、人口 / 格位相关 |
| **战斗** | 这场怎么布阵、先打谁 | 关键词与签名（仅此一项不够） |

- **经济类 / 倒转类必须有战斗外接口**（优先用「营巢」）；只在战斗里生效的经济兵 = 设计失败。
- **战斗过渡类必须对应一个具体战斗压力**（例：敌方 3 前排、敌方后排输出、第 3 轮血线告急），不能写「加点攻击」了事。
- **自成类必须不依赖构筑**：单独进池就成立，但上限低于专精线。
- 验收口径：说不清「服务哪条玩法线、改变哪个决策」的兵种，**不进池**。

### 4.0.2 兵种五类（2026-11-11 定）

每个兵种必须归入且只归入一类。分类是设计约束，不是 UI 标签。

| 类型 | 定义 | 判据 | 每线数量 |
|---|---|---|---|
| 成长 | 越打越强，能成为后期核心 | 有【永久】成长，且能跨战斗累积 | 2（一阶苗子 + 三阶大哥） |
| 经济·前期 | 早期过渡，防止卡死 | 低阶、低成本、即时兑现 | 1 |
| 经济·后期 | 中后期补给，滚雪球 | 与田 / 食物 / 战果规模挂钩 | 1 |
| 战斗过渡 | 提供一时支撑 | 只给【战时】属性 / 临时 buff | 2 |
| 倒转 | 玩法走死时换线 | 能返还、转换或重置已有投资 | 1 |
| 自成 | 不依赖构筑也有用 | 单独上场即成立，不要求配合 | 1 |

- 每线 2+1+1+2+1+1 = 8，三条线合计 24。
- **倒转**是本次新增的类型：允许玩家在一条线走不通时，把资源（田、种子、已投入的食物）转向另一条线，而不是硬扛到崩盘。
- **不做无用设计**：任何兵种如果说不清它服务哪条线、哪一类，就不进池。

### 4.0.2.1 共享兵种的设计约束（2026-11-11 定）

- **即插即用**：共享位不绑定任何虫种玩法线，任何阵容招到就能用；效果从「加攻 / 加护盾 / 加行动点 / 经济 / 控场」里选。
- **给足量级**：共享位的【战时】效果按 **+1.0–+3.0 / 轮**（或等价团队收益）给，不能出现「条件成立也只有 +0.5」的设计——否则玩家没有理由为它占一个出战位。
- **优先团队向 / 比例向**：全体、同排、按攻击力比例结算的效果，比单体小额条件 buff 更通用。
- **单体成长型可以无上限，但触发必须受敌方行为约束**（例：赳武蚁「每次实际掉血」）——不能给「每轮自动 + 攻击」这类无成本叠加；无上限的前提是玩家要付出挨打的代价。
- **可用通用倍数，但只乘基础值**：比例效果以「基础攻击 / 基础生命」为基数，不与局内【永久】成长叠乘。
- **三阶共享位优先做倍率 / 倒转接口**：三阶不靠身板，靠「让已有机制多触发一次」或「把已有投资换线」放大阵容（旌旗蚁：号令绑定迅捷；钦天蚁：号令绑定不甘）。倍率比固定数值更有组合空间。

### 4.0.3 命名规范（2026-11-11 定，取代旧「两字、不带蚁」）

- **三字**：`<职能 / 官制词> + 蚁`。例：弧矢蚁、司农蚁、仓曹蚁。
- 前两字取**中华传统官制 / 农政 / 军制词汇**，优先有典籍出处的词：司农、督耕、候望、驿传、钦天、仓曹、庾吏、障塞、烽燧。
- 同一虫种的专属兵种共享一个**词根域**：廪实 = 仓廪 / 农事 / 城守，不混用其他虫种的词。
- 共享兵种用**通用军制词**，不绑定虫种。
- 旧规则「兵种名两字、不带'蚁'」作废（见 `doc/README.md` 同步）。

### 4.0.4 属性标注（2026-11-11 定）

- 每个带数值增益的签名必须显式标注：
  - **【永久】**：跨战斗、整局保留（例：烽燧蚁每次实际掉血 +0.5 最大生命）。
  - **【战时】**：只在当前战斗内有效（例：赳武蚁本场攻击 +3.0 / 层）。
- 不允许使用「本场……永久」这类自相矛盾的写法。
- 不标注 = 视为设计未完成，不得进入实现。

### 4.0.5 通用关键词（2026-11-11 定）

- **每个兵种恰好 1 个通用关键词**，取自 `02-systems/combat.md` §6 词表；关键词只定义触发时机，具体效果写在兵种条目。
- 当前词表共 **12 个**：迅捷 / 角质化 / 点卯 / 营巢 / 不甘 / 号令 / 余勇 / 猎杀 / 反噬 / 狂热 / 引导 / 扼守（2026-11-11 精简）。
- 新增关键词必须先定美术表现，再进池（沿用 `combat.md` §6 规则）。
- 经济 / 倒转类兵种优先使用 **营巢**（战斗外触发）；这是把兵种接回经营循环的主要接口。
- **号令**是增幅型关键词：自身不单独产生触发，只放大签名绑定的关键词；绑定哪个关键词写在签名里（旌旗蚁 → 迅捷、钦天蚁 → 不甘）。

| 经济·前 / 后期 | 营巢 |

> **2026-11-11 生命封顶取消**：不存在全局生命上限；生命只由数值平衡控制，不再设封顶值（原 16 / 13 / 10 等封顶全部作废）。

**统一成本（2026-11-11 定，取代下列公式）**

- **所有兵种招募成本统一为 4 食物**，不分阶级、不看身板与签名。阶级只决定**解锁时机**，不再决定价格。
- 兵种之间的差异只由**生命 / 攻击 / 签名特性 / 关键词**体现，不再用成本做平衡杠杆；文档也不再逐兵种标注价格。
- 招募刷新统一 **1 食物 / 次**。

**~~成本公式（已作废）~~**

- 身板分 **B = 生命 + 2 × 攻击**（1 攻击按 2 生命折算）。
- 基础成本 **C₀ = B ÷ 2 = 生命 ÷ 2 + 攻击**。
- 最终成本 **C = round(C₀ + 签名溢价)**，四舍五入到整数。

- 概率 / 随机收益按期望值取档，不按上限取档。

**时效折算（2026-11-11 定）**

- 同一触发频率、同一作用范围下，**【战时】数值必须明显高于【永久】**，建议 **≥ 2 倍**。临时加成如果只给到永久档位的数值，玩家就没有理由为它占一个出战位。
- 【永久】签名只写小数：每次 **+0.1–+1.5**（生命 / 攻击），靠触发次数与多场累积滚雪球（烽燧蚁 +0.5、圃畦蚁 +0.5）。
- 【战时】签名给大数：每轮 / 每场 **+1.0–+3.0**，可叠加或覆盖全队（耘耨蚁 +1.0、镇廪蚁 1.5 护盾）。
- 换算口径：一场战斗按 3–6 次触发估算。例：【永久】每次攻击 +0.2 攻击 ≈ 单场 +0.6–+1.2，对应【战时】每轮 +1.0；【永久】每场 +0.5 最大生命 ≈ 【战时】每场 +1.0–+2.0 护盾。
- 溢价按**净收益**（单次数值 × 触发次数）取档，不按单次数值大小取档。

### 4.2 候望蚁（旧名斥候；第二个定稿兵种，2026-11-09）

> 旧名「侦察蚁」；按两字命名规则工作名「斥候」，备选「探马」。
> 定位不是“开图”，而是**前期信息 + 战果生成**：用迅捷拿天气预报，用不甘赌食物 / 巢穴经验。

| 字段 | 内容 |
|---|---|
| 定位 | **前期信息位 / 战果生成**：低血低攻，靠迅捷与不甘产出战果；通常放前排主动卖死触发不甘 |
| 阶级 | **一阶**（巢穴 L1 池） |
| 生命 | **5.5**（提案，待平衡；明显低于前排主力） |
| 攻击 | **2.0**（提案，待平衡） |
| 行动点 | **1**（基础值） |
| 主动技能 | **待定**（当前只确认迅捷 / 不甘） |

**迅捷（通用关键词，战斗开始时；无加成时每场 1 次）**

- 战斗开始时，获得 **1 个战果【迅捷】**（2026-11-09 定名，与关键词同名）。
- 【迅捷】使用后：**延长天气预报窗口**，让玩家看得更远（具体延长回合数待定，提案 +1 回合；Q-091 / Q-108）。
- 无 buff / 加成时，每场战斗只触发 **1 次**；有加成可增加触发次数。
- 战果进入**道具栏**；使用后消耗（沿用 Q-073）。

**不甘（通用关键词，阵亡时；无加成时每场 1 次）**

- 候望蚁阵亡时，获得 **1 个战果【不甘】**（2026-11-09 定名，与关键词同名）。
- 【不甘】**使用的时候才结算**，随机三选一（概率待定，提案均等）：
  - **食物 −1**
  - **食物 +1**
  - **巢穴经验 +1**（Q-098 / Q-100）
- 无 buff / 加成时，每场战斗只触发 **1 次**；有加成可增加触发次数（复活后是否可再次触发待定，Q-108）。
- 战果进入**道具栏**；使用后消耗。

**站位**

- **推荐前排**：低血低攻，站前排更容易被击杀，从而触发不甘。
- 放后排也可，但前排未全灭时不会被攻击，不甘触发不稳定。
- 它不靠站场输出，靠“死得其所”换战果；前排格是它的成本。

**缺点**

- **低血低攻**：站场贡献低，容易在发挥作用前就被击杀。
- **不甘是概率收益**：可能 −1 食物，等于用一次死亡换一个负面结果。
- **占一个前排格**：前排本来应该放能扛的单位；带候望蚁等于用稳定性换信息 / 经济。
- **迅捷的天气预报可能冗余**：如果当前预报窗口已经覆盖明天，【迅捷】的收益会下降；因此它被设计成“看得更远”，而不是“看明天”。

**Combo**

- 与「燧火蚁」等死亡触发单位：前排卖死，换取多次不甘类效果。
- 与巢穴经验线：不甘的 +1 经验可推进巢穴升级（Q-098 / Q-100）。
- 与天气 / 雨季规划：迅捷提前看到坏天气，决定是否留食物应对探索损耗。

> 两个战果定名【迅捷】/【不甘】（与关键词同名）；是否为候望蚁专属、是否进入种子战果池、延长回合数与随机概率均待定（Q-108）。当前只确认：**候望蚁的迅捷绑定【迅捷】、不甘绑定【不甘】**；两只战果进入道具栏、使用后消耗。其他兵种的迅捷 / 不甘绑定效果待设计，不能默认都产战果。

| 生命 | **6.5**（提案，待平衡） |
| 攻击 | **2.0**（提案，待平衡） |
| 行动点 | **1**（基础值） |
| 通用关键词 | **不甘**（阵亡时触发绑定效果） |
| 主动技能 | **无**（不能主动引爆，只能等被击杀） |
| 绑定效果 | 对敌方当前前排每个存活单位造成 **自身攻击力 ×50%** 伤害；**前排全灭后才能打后排** |

**不甘触发（2026-11-09 定）**

- 燧火蚁**没有主动技能，不能主观引爆**：唯一触发方式是**在战斗中被击杀阵亡**。
- 阵亡时触发「不甘」，结算一次爆炸；每场只结算 1 次。
- 活着就是普通前排（攻击 2.0 / 1 行动点），不会自己炸。
- 若整场都没被打死，则**没有任何爆炸收益**。

**不甘绑定：爆炸（2026-11-09 定）**

- 伤害基数 = **燧火蚁自身的攻击力 × 50%**。
  - 基础攻击 2.0 → 每个目标 **1.0**（按 ±10% 波动，即 0.9–1.1）。
  - 攻击力被战果 / 虫珀等提高后，爆炸伤害同步提高；燧火蚁本身没有独立成长。
- 结算顺序：
  1. 对**敌方当前前排**的每个存活单位各造成一次伤害。
  2. **只有当前排全灭后**，同一爆炸才能继续对**敌方后排**的每个存活单位各造成一次伤害。
- **前排未全灭时，爆炸不会命中后排**：这是“前排全灭前不可打后排”的通用规则，爆炸不构成例外。
- 爆炸发动时前排已经全灭 → 直接打后排。
- **前后排各只结算 1 轮**；不会因为后排也被清空而继续扩散。
- 先打前排、**前排全灭后**才轮到后排，与“前排全灭前后排不可被攻击”的规则完全一致，不构成例外。

**战后**

- 阵亡只是本场退场；**战后照常返场**，不永久消失（沿用 Q-036）。
- 阵亡只影响本场阵容，不额外扣食物。

**缺点**

- **触发不可控**：必须被打死才会爆炸；玩家不能决定时机，敌人也可能先杀别的目标。
- **一次性**：阵亡后本场少一个单位，后续轮次没有它。
- **伤害只有攻击力的一半**：基础攻击 2.0，每个目标只 **1.0**，数值不高。
- **需要先打残前排**：前排满血时清空不了，爆炸打不到后排。
- **低血**：8.0，容易被敌人提前打死——这对燧火蚁反而是好事，但也意味着它可能还没等到前排被压残就先炸了。
- **占一个出战格**：带它等于用一个单位赌一次范围伤害。

**Combo**

- 与堡坞蚁 / 候望蚁：前排互相掩护；燧火蚁被击杀时顺带清场。
- 与弧矢蚁：先把敌方前排压到 1.0 以下，等燧火蚁阵亡时清空前排、顺势打到后排。
- 与密集前排的敌人：前排越密、血线越低，1.0 的覆盖面越大。

> 伤害来源已定：**自身攻击力 ×50%**（基础 2.0 → 每目标 1.0），先打前排、前排全灭后继续打后排（Q-112）。**触发方式已定：只能由「不甘」（阵亡）触发，没有主动引爆**。HP 6.5 / 攻击 2.0 是首版数值，待平衡；爆炸击杀的归属、是否触发战蜕 / 击杀奖励，待定（Q-112）。

**号令 + 督造（关键词 + 签名，2026-11-11 定）**

- **号令**：友方单位（含自身）触发【营巢】时，除原本结算外**额外结算 1 次**；**二星 2 次**（Q-130 明文例外）。

- **无递归**：号令只作用于绑定的关键词，不作用于号令自身；额外结算不再触发新的号令。

**因粮（签名特性）**

**拾遗（签名特性，2026-11-09 改版）**

- **每场战斗开始时触发 1 次**，且**只有馈粮蚁自己参战**才触发；待命 / 未上阵不结算。
- 三件事在同一时点结算：

  2. **随机 1 名友军**（不含馈粮蚁自己）**永久 +1.0 最大生命**；

**缺点**

- **越用越脆**：10.0 → 8.0 → 6.0 → 4.0 → 2.0 → 0，五场后归零，前排还占着格子。
- **成长不可控**：+1.0 生命随机落到某个友军身上，可能喂到不需要的单位。
- **食物收益不稳**：2–3 随机，且必须先上阵、先挨这一刀。

### 5.6 司农蚁（旧名采薇；2026-11-09 定稿，2026-11-11 由共享移入积廪）

> 旧名「采集蚁」；工作名「采薇」，备选「农夫」。
> 定位：**战斗结算型经济位**——不靠产粮建筑，靠“打赢，或活着回来”带回额外食物。

| 字段 | 内容 |
|---|---|
| 定位 | **战斗结算型经济**：参战并满足条件，额外带回 1–3 食物 |
| 阶级 | **一阶**（巢穴 L1 池，廪实专属·积廪） |
| 生命 | **5.0**（2026-11-09 定；2026-11-11 全局削弱后维持） |
| 攻击 | **1.5**（2026-11-09 定） |
| 行动点 | **1**（基础值） |
| 站位 | **后排**（推定） |
| 关键词 | **营巢**（战斗外触发一次绑定效果） |
| 主动技能 | **待定**（当前只确认签名特性「采撷」） |

**签名特性「采撷」（2026-11-09 定）**

- 司农蚁参与的战斗结束后，只要满足**任一**条件，**额外获得 1–3 食物**（随机）：
  - **打败敌方**（战斗胜利）
  - **司农蚁存活**
- 两个条件同时满足，也只结算 **1 次**，不叠加。
- 唯一没有额外收益的情况：**战斗失败且司农蚁阵亡**。
- **常规战斗奖励照常结算**（食物 + 战果）；额外食物是在常规奖励**之上追加**，不替换。
- 多只司农蚁：每场战斗最多结算 **1 次**，不叠加（2026-11-09 定）。

**缺点**

- **低血低攻**：站场贡献弱，容易在发挥作用前被击杀。
- **占一个出战格**：不打仗就没有经济收益。
- **收益受场次限制**：一局约 13 场战斗，理论额外 **13–39 食物**，不能无限滚。
- **“打败敌方”放宽了保护要求**：胜利即结算；她是否存活只在**战败**时决定有没有额外食物。

**Combo**

- 与堡坞蚁 / 庇护苔等保护型单位：战败时尽量让她活下来，仍能拿额外食物。
- 与快速清场阵容：胜利即结算，不依赖她存活。
- 与积廪线烧粮单位：额外食物回补仓曹蚁 / 太仓蚁的粮食开销。

> 「采撷」的随机分布（1–3 是否均等）、最终裁决是否算“打败敌方”、额外食物是否受战果 / 虫珀 / 虫种被动加成，待定（Q-110）。

### 5.7 质库蚁（新；2026-11-11 提案，同日由共享移入积廪）

> 定位：**卖出兑现型经济位**——在场越久，卖出时回得越多；用出战格换延迟收益。

| 字段 | 内容 |
|---|---|
| 定位 | **经济·后期**：把出战次数沉淀成卖出时的额外食物 |
| 阶级 | **一阶**（巢穴 L1 池，廪实专属·积廪） |
| 生命 | **5.5**（提案） |
| 攻击 | **1.5**（提案） |
| 行动点 | **1**（基础值） |
| 站位 | **后排** |
| 关键词 | **营巢** |
| 签名 | **每经历 1 场战斗，卖出自身时额外 +1 食物，无上限** |

**结算规则**

- 每完整参与 **1 场战斗**记 1 层；卖出时按层数额外返还食物，**无上限**。
- 卖出基础返还 **2 食物**；额外部分叠在基础返还之上。
- 未参战就卖出：只拿基础返还，没有额外食物。
- 多只质库蚁各自计层，不共享。
- 卖出后单位离队，层数不再存在；是否允许战斗中卖出待定。

**缺点**

- **战斗白板**：签名只在卖出时兑现，场上等于少一个技能。
- **占一个出战格**：为了攒层数必须带它打，短期战力吃亏。
- **延迟兑现**：层数只有卖掉才变现；留到后期卖收益更高，但一直占着位置。
- **低血低攻**：后排也怕穿透 / AOE。

> 层数是否受“战败但存活”影响、卖出价格是否受其它经济加成影响，待实测（Q-109）。

## 6. 成长与持久性

- **士兵是持久资产**：战斗不会让士兵消失，也不会饿死；没有工蚁 / 人口层（2026-11-09 删除）。
- **兵种本身不做 L1 / L2 / L3 数值升级**（2026-11-09 定）；阶级只是解锁层级。是否另有老兵系统待定。
- 成长来自：
  - **合成升星（3 合 1 → 2 星）**
  - 招募更强的兵种
  - 事件 / 虫珀给单个蚂蚁附加变异
  - 虫种被动与巢穴加成
  - 虫珀

### 6.1 合成升星（2026-11-09 定）

> **3 个同名一星 → 1 个二星，2 星封顶。**

- **只到 2 星**：不存在 3 星；二星就是一局内的成长终点（2026-11-09 定）。
- **同名才合**：同一虫种、同一兵种；不同兵种 / 不同虫种之间不能合。共享兵种与专属兵种都能合。
- **自动合成**：凑齐第 3 个同名一星的**结算瞬间**自动合并成 1 个二星，**不耗食物、不占行动、不可拒绝**。招募事件结算后、其它获得单位的来源结算后各检查一次。
- **只占 1 个队伍位**：二星是 1 个单位，不是 3 个（与「一阶是未来的大哥」一致——复制品靠合成变成长期主力）。
- **本局永久**：星级不因战斗、阵亡、战后回满而改变；重开重置。
- **对局内只有 1★ 和 2★**：招募永远给一星；已持有二星不会阻止该兵种继续出现在招募里（再凑 3 个可以出第二个二星）。

**二星效果（2026-11-09 定：数值 + 签名部分强化）**

| 部分 | 变化 |
|---|---|
| **生命 / 攻击** | **在一星现有属性上再加一份「一星基础数值」**：生命 +基础生命，攻击 +基础攻击。未成长时等于 ×2（弧矢蚁 5.0 / 3.0 → 10.0 / 6.0） |
| **签名特性** | **部分强化**：签名里的**收益**固定数值 ×2；**代价 / 负面**数值、**次数 / 范围 / 目标数 / 触发条件 / 上限**一律不变（代价是否也 ×2 待定）。**例外**：签名明文写了二星变化的，以签名为准（旌旗蚁 / 钦天蚁的【号令】额外触发次数 1 → 2）。 |
| 成本 / 阶级 / 站位 | 不变（成本只是招募价，二星不再花食物） |
| 战果 / 虫珀等外部加成 | 照常作用在一个单位上 |

- **是「加一份基础值」，不是「把当前值乘二」**：局内永久成长的属性（仓曹蚁积粮 +3 生命 / +2 攻击、馈粮蚁等）只**保留**，**不再跟着翻倍**——否则越早养越离谱。
- **为什么值这份加成**：3 合 1 的总身板必然下降，二星买的是**槽位效率**；而合成**自动、不可拒绝**，系统必须让玩家明确变强——一格当一格半以上的用，才对得起丢掉的两个身位。
- 例：仓曹蚁「积粮」+3 生命 / +2 攻击 → 二星 **+6 / +4**；堡坞蚁每轮 1.0 护盾 → **2.0**；馈粮蚁随机友军 +1.0 最大生命 → **+2.0**（自身代价 −2.0 不变）；堞垒蚁「迅捷」+2 完整度 → **+4**。
- 概率 / 范围类签名（弧矢蚁 30%、司农蚁 +1–3 食物）如何「部分」强化，逐条待定（Q-130）；未定的先**保持原值**。

> 未定：三个被合成的单位**当前属性不一致**时（有永久成长的兵）取哪一个——暂按**取三者中的最高当前值**（Q-131）；签名里的**代价 / 负面数值**是否也加一份（暂按不变）、概率 / 范围类签名怎么放大、二星是否需要单独的视觉标识、能否主动拆回三个一星、二星在随机友军 / 目标选择里算 1 个还是 3 个（按 1 个，待确认）。

> 旧说法“蚂蚁是消耗品，死了就没了”作废（2026-11-08）。
