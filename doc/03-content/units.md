# 兵种系统（卡牌层）

> 类比：卡牌。
> 但注意：**"类似卡牌"指收集与构筑结构，不是抽牌打牌。** 战斗是实际部署蚂蚁队伍。
> **详细设计暂缓（2026-11-08）**：先确立设计原则，具体兵种稍后定稿。

## 1. 定位

- 兵种是局内招募、编队、部署的单位。
- 你的兵种池 = 你的"牌库"；招募 = 以食物为主；人口上限 = 场上限制。
- 战斗不是手牌结算，而是把蚂蚁派到**蚁穴外**迎敌；蚁穴内则负责生产 / 防御准备。

## 1.5 设计原则（2026-11-08）

- **每个兵种都有优点和缺点。**
- **没有一只兵种能完美替代另一只。**
- **所有兵种都应该有用**，强弱取决于搭配与取舍。
- **每个兵种必须有签名特性**（2026-11-09 定）：至少 1 个能一句话说清“为什么选它”的被动或主动；共用关键词只是实现手段，不替代签名特性。
- **成长不设硬上限**（2026-11-09 定）：兵种成长、战果叠加不做数值封顶，优先满足玩家“越打越强”的感觉。
- 不做"数值上位替代"：新兵种不是旧兵种的严格升级。
- **数值允许小数**：HP / 攻击 / 防御 / 速度可用 1 位小数，不强制整数（2026-11-09 定）。
- **攻击有波动**：以攻击力为基数的伤害按 **±10%** 浮动，双方通用；内部与 UI 保留 1 位小数（2026-11-09 定，见 `combat.md` Q-028）。
- 玩家的乐趣来自"看自己的搭配、做自己的取舍"。

## 1.6 士兵的持久性（2026-11-08）

- **士兵是持久资产**：战斗不会让士兵消失，也**不会饿死**（2026-11-08 确定）。
- 战斗失败 → 扣巢穴完整度；士兵保留。
- 战斗失败 → 士兵返场；损失的是巢穴完整度。
- **战斗的真实代价是食物**：每次战斗损耗食物，恶劣天气会放大（Q-052 / Q-053）。
- **战斗补给按兵种计**：开战前、部署确认后，按实际出场单位逐个支付；空位 / 后备不计（2026-11-09 定，Q-052）。
- 食物不足时撤下单位直到付得起；一个都派不出则不能迎战，只能谈判 / 回避。
- 补给不退还；失败、撤退、最终裁决同样消耗。
- **工蚁是消耗品**：探索会牺牲；工蚁数量决定每回合巢穴健康恢复。

## 2. 结构模板

每个兵种定义：

| 字段 | 说明 |
|---|---|
| 名称 / 阶级 | 工蚁、锐士、专属兵种 |
| 标签 | 采集、战斗、建造、侦察、自杀、守护 |
| 资源配方 | 食物（唯一基础资源，2026-11-09 定） |
| 食物成本 | 生成该兵种需要多少食物（主要成本） |
| 战斗补给 | 每次出场消耗的食物（按兵种不同） |
| 生命 / 攻击 / 防御 / 速度 | 基础数值；可用 1 位小数 |
| 行动点 | 每回合可行动次数；**所有兵种基础 1 点**，技能 / 虫珀 / 特性可提高（见 `combat.md`） |
| 签名特性 | **每兵种至少 1 个**；被动或主动，可用共用关键词实现（见 `combat.md` 6） |
| 被动 / 主动 | 技能 |
| 经济职能 | 采集、挖掘、产粮、储粮 |
| 战斗职能 | 前排、输出、控制、自爆 |
| Combo | 和哪些兵种/虫种咬合 |

## 3. 招募机制

- **招募改为事件触发**（2026-11-08 确定）：不再每回合固定 3 选 1。
- 触发来源：商人 / 中立生物 / 巢穴事件等（待定，Q-068）。
- 触发时仍是 **3 选 1**。
- 生成 = **食物**；具体成本按兵种不同（见 `economy.md`）。
- **不再使用工蚁转化**（2026-11-08 确定）。
- 食物不足时，对应兵种不进入候选，或显示"不可招募"。
- 可牺牲食物刷新一次；部分虫珀可刷新一次（Q-042 / Q-048）。
- 人口上限由巢穴与蚁后决定；满员时不能招募。
- 候选池按虫种加权：**共享池 12 + 虫种专属池 12**。
- **候选池按当前阶级概率抽取**（2026-11-09 定，Q-103）：L2 只出一阶；L3 出一阶 60% / 二阶 40%；L4 出一阶 45% / 二阶 35% / 三阶 20%；每个候选独立结算。升阶后第一次招募有**新阶级保底**，详见 4.0。
- **候选池受探索进度限制**：没发现对应种子，就刷不出对应兵种。

## 3.5 探索解锁兵种

- 招募池不是一开始全开。
- 探索带回特殊**种子**后，对应兵种才进入候选池。
- 例：
  - 带回黏土共生种子 → 解锁黏土系建筑 / 兵种
  - 带回树脂共生种子 → 解锁树脂系兵种
  - 带回菌床种子 → 解锁真菌系兵种
- 因此**探索是招募的前置**，不是可选支线。

## 4. 共享兵种（12 个，占位）

> **2026-11-09 定**：共享兵种池为 **12 个**；按阶级分布为**一阶 8 / 二阶 3 / 三阶 1**（见 4.0）。
> **工蚁不属于共享兵种槽**，它是经济单位，由蚁后生成，见 `economy.md` 2.5。
> **所有兵种基础 行动点 = 1**（2026-11-09 定）；表中不再逐项列 2 / 3，只有条目写明加成时才提高。

**两字命名（2026-11-09）**

> 兵种名**不带“蚁”**，统一为**两个字**；每个兵种保留**两个候选**。第一列为**工作名**（文档暂用），第二列为**备选**；最终定名等 **12 个**共享兵种设计完再拍。

| 旧名 | 定位 | 工作名 | 备选 |
|---|---|---|---|
| 兵蚁 | 前排主力 | **锐士** | 武士 |
| 侦察蚁 | 情报 | **斥候** | 探马 |
| 采集蚁 | 经济 | **采薇** | 农夫 |
| 守卫蚁 | 防御 | **干城** | 卫士 |
| 爆炸蚁 | 自爆 | **焚卒** | 爆卒 |
| （远程位） | 后排输出 | **弩手** | 射手 |
| （支援位） | 后排支援 | **辅兵** | 援兵 |
| （控制位） | 控制 | **缚者** | 扰者 |

- 原分类名（含“蚁”）改为**专属兵种**，不再带“蚁”。
- 工蚁、蚁后是生物 / 经济角色，不在本次改名范围。
- 旧虫种示例中的专属兵种名是历史占位，待专属兵种设计时按新规则重做。

### 4.0 阶级 = 解锁层级（2026-11-09 定，Q-103）

- **阶级不是数值升阶**：不做「锐士」的 L2 / L3 / L4 三套数值，也不做同一兵种的高阶严格上位。
- **每个兵种只有一个条目**；阶级只决定它**什么时候进入招募池**。
- 阶级只决定**解锁时机**；兵种之间的差异由**定位 + 签名特性**承担，不由阶级承担。
- **名称统一为「一阶 / 二阶 / 三阶」**，对应巢穴等级：**一阶 = L2，二阶 = L3，三阶 = L4**（2026-11-09 定）。文档和 UI 不再用“一级 / 二级 / 三级”，避免玩家误以为一级 = L1。

**每虫种总池：24 = 共享 12 + 专属 12**

- **共享 12 个是全局共用池**；**专属 12 个是每个虫种各一套**，不同虫种的专属池不互通。

| 阶级 | 对应巢穴 | 共享 | 专属 | 累计可用 | 本阶新增 |
|---|---|---|---|---|---|
| 一阶 | L2 | 8 | 4 | 12 | 12（共享 8 + 专属 4） |
| 二阶 | L3 | 11 | 9 | 20 | 8（共享 +3，专属 +5） |
| 三阶 | L4 | 12 | 12 | 24 | 4（共享 +1，专属 +3） |

**招募时各阶出现率（按每个候选独立抽取，暂定，Q-106）**

| 当前巢穴 | 一阶 | 二阶 | 三阶 |
|---|---|---|---|
| L2（一阶池） | 100% | — | — |
| L3（二阶池） | 60% | 40% | — |
| L4（三阶池） | 45% | 35% | 20% |

- 每档合计 100%；概率按**每个候选**独立结算，不是整次招募只抽一次阶级（暂定，Q-106）。
- 二阶 60/40 摊到 12 / 8 个单位上，**每个单位正好 5%**；三阶 45/35/20 摊到 12 / 8 / 4，每个单位约 **3.75% / 4.375% / 5%**——三阶单位单体概率最高，这是“少而精”的有意设计。
- **升阶保底（2026-11-09 定）**：每次升到新阶级后的**第一次招募**，至少出现 **1 个新阶级单位**。即：升 L3 后第一次招募必出二阶单位；升 L4 后第一次招募必出三阶单位。保底只作用于该次招募，不改变后续概率；保底单位是否必须付得起待定（Q-106）。
- 设计意图：给巢穴扩建第二收益（当前只有肥沃格 + 植物携带数），同时控制前期招募池的信息量。
- 具体每个阶级放哪些兵种**待定**：共享 12 个中，当前 8 个已命名（见下表）均为一阶；**二阶 3 个 + 三阶 1 个待设计**（Q-105）。专属 12 个的具体名单待设计（Q-107）。
- 招募抽取细节（是否允许同种重复、保底与刷新如何交互）待定（Q-106）。

> 招募池的“分批”不等于“高阶兵种更强”；每个兵种仍按定位与缺点设计，不做数值上位替代。

| 兵种 | 食物成本 | 战斗补给（食物） | 行动点 | 定位 | 技能 |
|---|---|---|---|---|---|
| **锐士** | 8 | 1 | 1 | 前排主力 | 每次攻击永久成长（见 4.1） |

| **弩手** | 待定 | 待定 | 1 | 后排输出 | 待设计 |

> 数值为首版占位，待平衡。

> 工蚁不能出战，只用于生产 / 探索 / 被动恢复；它不占共享兵种槽。

### 4.1 锐士（首个定稿兵种，2026-11-09）

> 旧名「兵蚁」；按 2026-11-09 两字命名规则改为「锐士」，备选「武士」。

| 字段 | 内容 |
|---|---|
| 定位 | **标准前排**：高生命、稳定输出，靠持续攻击滚雪球 |
| 阶级 | **一阶**（巢穴 L2 池） |
| 食物成本 | **8** |
| 战斗补给 | **1** |
| 生命 | **12.0** |
| 攻击 | **3.0**（伤害按 ±10% 浮动，即 2.7–3.3） |
| 防御 / 速度 | 待定；速度不影响行动顺序 |
| 行动点 | **1**（基础值，所有兵种相同） |
| 主动技能 | **待定**（目前只确认成长被动；是否给主动技能未定） |

**被动：每次攻击后永久成长（正式关键词名待定）**

- 「锐士」**每次发动攻击后**，在本局内**永久**随机获得以下一项（2026-11-09 定）：
  - **生命 +1.0**
  - **攻击 +0.25**
- 随机二选一，玩家不可指定；成长跨战斗保留，**重开新局重置**。
- **成长无上限**（2026-11-09 定）：生命 / 攻击可以一直累加，不设封顶。
- 成长只由“攻击”触发：被攻击、待机、使用战果都不触发。

**缺点（待确认）**

- 按“每个兵种都有缺点”的原则，「锐士」需要有明确短板；具体短板与是否用“无主动技能”承担，待确认。
- 成长是长线收益，前期兑现慢，这是它无上限的代价。

> 「锐士」的成长**不设上限**（Q-102，2026-11-09 定）；是否受战果 / 虫珀 / 虫种被动放大或复制，待定（Q-104）。

### 4.2 斥候（第二个定稿兵种，2026-11-09）

> 旧名「侦察蚁」；按两字命名规则工作名「斥候」，备选「探马」。
> 定位不是“开图”，而是**前期信息 + 战果生成**：用迅捷拿天气预报，用不甘赌食物 / 巢穴经验。

| 字段 | 内容 |
|---|---|
| 定位 | **前期信息位 / 战果生成**：低血低攻，靠迅捷与不甘产出战果；通常放前排主动卖死触发不甘 |
| 阶级 | **一阶**（巢穴 L2 池） |
| 食物成本 | **5** |
| 战斗补给 | **1** |
| 生命 | **7.0**（提案，待平衡；明显低于锐士） |
| 攻击 | **2.0**（提案，待平衡） |
| 防御 / 速度 | 待定；速度不影响行动顺序 |
| 行动点 | **1**（基础值） |
| 主动技能 | **待定**（当前只确认迅捷 / 不甘） |

**迅捷（通用关键词，战斗开始时；无加成时每场 1 次）**

- 战斗开始时，获得 **1 个战果【占风】**（暂名）。
- 【占风】使用后：**延长天气预报窗口**，让玩家看得更远（具体延长回合数待定，提案 +1 回合；Q-091 / Q-108）。
- 无 buff / 加成时，每场战斗只触发 **1 次**；有加成可增加触发次数。
- 战果进入**道具栏**；使用后消耗（沿用 Q-073）。

**不甘（通用关键词，阵亡时；无加成时每场 1 次）**

- 斥候阵亡时，获得 **1 个战果【遗报】**（暂名）。
- 【遗报】**使用的时候才结算**，随机三选一（概率待定，提案均等）：
  - **食物 −1**
  - **食物 +1**
  - **巢穴经验 +1**（Q-098 / Q-100）
- 无 buff / 加成时，每场战斗只触发 **1 次**；有加成可增加触发次数（复活后是否可再次触发待定，Q-108）。
- 战果进入**道具栏**；使用后消耗。

**站位**

- **推荐前排**：低血低攻，站前排更容易被击杀，从而触发不甘。
- 放后排也可，但前排未全灭时不会被攻击，不甘触发不稳定。
- 它不靠站场输出，靠“死得其所”换战果；前排格是它的成本。

**缺点**

- **低血低攻**：站场贡献低，容易在发挥作用前就被击杀。
- **不甘是概率收益**：可能 −1 食物，等于用一次死亡换一个负面结果。
- **占一个前排格**：前排本来应该放能扛的单位；带斥候等于用稳定性换信息 / 经济。
- **迅捷的天气预报可能冗余**：如果当前预报窗口已经覆盖明天，【占风】的收益会下降；因此它被设计成“看得更远”，而不是“看明天”。

**Combo**

- 与「焚卒」等死亡触发单位：前排卖死，换取多次不甘类效果。
- 与巢穴经验线：不甘的 +1 经验可推进巢穴升级（Q-098 / Q-100）。
- 与天气 / 雨季规划：占风提前看到坏天气，决定是否留食物付战斗补给。

> 两个战果暂名【占风】/【遗报】，是否为斥候专属、是否进入种子战果池、延长回合数与随机概率均待定（Q-108）。当前只确认：**斥候的迅捷绑定【占风】、不甘绑定【遗报】**；两只战果进入道具栏、使用后消耗。其他兵种的迅捷 / 不甘绑定效果待设计，不能默认都产战果。

## 4.5 战果

- **种子产出分三类**（2026-11-09 定）：食物型 → 食物；战果型 → 战果；工具型 → 恢复 / 增益 / 羁绊 / 战斗植物。
- **战果**：定位接近**法术卡**的战斗道具（2026-11-09 用户定位）；可以直接给士兵加属性，也可以挂 buff（成长、攻击附带毒性、死亡触发等）。
- 每颗种子固定一种产出大类，不混产（Q-071）。
- **兵种也能生成战果**（2026-11-09 定）：关键词的绑定效果可以产出战果，当前仅「斥候」确认（迅捷 → 【占风】、不甘 → 【遗报】，见 4.2）；其他兵种是否以此产战果待设计（Q-032 / Q-108）。
- 战果存入**道具栏**（平面列表，不做背包网格）。
- **使用时机**：准备阶段随时可用；战斗中我方尚未失败时随时可用；部分战果可对敌对势力使用（Q-073）。
- **不占 行动点、无每轮 / 每场次数上限**，只受持有数量限制；使用后消耗（Q-073）。
- **时效**：部分持续本场，部分本局永久（重开重置）（Q-094）。
- **叠加**：属性型每次使用按牌面累加（没有“取最高 / 覆盖”）；特性型同名特性可叠层（Q-094）。
- 示例方向：攻击、生命、防御、速度、毒性、成长、死亡触发（数值待定，Q-074）。
- 存放容量待定（Q-072）。

## 4.6 战斗植物（非兵种）

- 由**防守型工具种子**生成，不属于招募兵种，不进入兵种池。
- **不占前 4 / 后 3 部署格，也不额外占肥沃格**；不消耗战斗补给。
- 行动时点、攻击 / 防守目标规则见 `combat.md` 4.3（Q-092 / Q-095）。

## 5. 专属兵种（每虫种 12 个）

> 术语：用户口中的「特殊兵种」= 本文「专属兵种」；正式文档统一用**专属兵种**。旧分类名「特化兵种」不再作为正式名。

- 每个虫种有 **12 个专属兵种**，只能在该虫种局中出现（2026-11-09 定）。
- 阶级分布：**一阶 4 / 二阶 5 / 三阶 3**；与共享池合计后，单虫种总池 24 个（见 4.0）。
- 每个专属兵种仍遵守：两字命名、不带“蚁”、至少 1 个签名特性、有缺点、不做数值上位替代。
- 廪实的 12 个专属兵种名单待设计（Q-107）。

> **以下为旧示例，专属兵种名仍带“蚁”，是历史占位**；正式设计时按“两字 / 不带蚁”的规则重做。

- 行军蚁：突袭蚁、行军锐士
- 切叶蚁：菌农蚁、园丁蚁
- 织叶蚁：织工蚁、桥梁蚁
- 蜜罐蚁：蜜罐蚁、干城
- 收获蚁：收获工蚁、种子守卫

## 6. 成长与持久性

- **士兵是持久资产**：战斗不会让士兵消失，也不会饿死；工蚁才是消耗品。
- **兵种本身不做 L2 / L3 / L4 数值升级**（2026-11-09 定）；阶级只是解锁层级。是否另有老兵系统待定。
- 成长来自：
  - 招募更强的兵种
  - 事件 / 虫珀给单个蚂蚁附加变异
  - 虫种被动与巢穴加成
  - 虫珀

> 旧说法“蚂蚁是消耗品，死了就没了”作废（2026-11-08）。
