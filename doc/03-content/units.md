# 兵种系统（卡牌层）

> 类比：卡牌。
> 但注意：**"类似卡牌"指收集与构筑结构，不是抽牌打牌。** 战斗是实际部署蚂蚁队伍。
> **详细设计暂缓（2026-11-08）**：先确立设计原则，具体兵种稍后定稿。

## 1. 定位

- 兵种是局内招募、编队、部署的单位。
- 你的兵种池 = 你的"牌库"；招募 = 以食物为主；出战格（前 4 + 后 3） = 场上限制。
- 战斗不是手牌结算，而是把蚂蚁派到**蚁穴外**迎敌；蚁穴内则负责生产 / 防御准备。

## 1.5 设计原则（2026-11-08）

- **每个兵种都有优点和缺点。**
- **没有一只兵种能完美替代另一只。**
- **所有兵种都应该有用**，强弱取决于搭配与取舍。
- **每个兵种必须有签名特性**（2026-11-09 定）：至少 1 个能一句话说清“为什么选它”的被动或主动；共用关键词只是实现手段，不替代签名特性。
- **兵种都是战斗单位**（2026-11-09 定）：不存在“驻守巢穴 / 在家生产”的非战斗状态；经济型兵种的收益必须挂在**参战或战斗结算**上，不设计脱离战斗的生产模式。
- **成长不设硬上限**（2026-11-09 定）：兵种成长、战果叠加不做数值封顶，优先满足玩家“越打越强”的感觉。
- 不做"数值上位替代"：新兵种不是旧兵种的严格升级。
- **数值允许小数**：HP / 攻击可用 1 位小数，不强制整数（2026-11-09 定）。属性只保留 **HP / 攻击 / 行动点**；**防御与速度已删除**（2026-11-09 定，见 `combat.md` / `combat-math.md`）。
- **攻击有波动**：以攻击力为基数的伤害按 **±10%** 浮动，双方通用；内部与 UI 保留 1 位小数（2026-11-09 定，见 `combat.md` Q-028）。
- 玩家的乐趣来自"看自己的搭配、做自己的取舍"。

## 1.6 士兵的持久性（2026-11-08）

- **士兵是持久资产**：战斗不会让士兵消失，也**不会饿死**（2026-11-08 确定）。
- 战斗失败 → 扣巢穴完整度；士兵保留。
- **战斗失败 → 士兵返场；损失的是巢穴完整度。**
- **战后 HP 一律回满**（2026-11-09 定）：每场战斗结束后，所有参战单位 HP 回满，**包括本场阵亡的单位**；HP 不跨场累积。
- **战斗不额外消耗食物**（2026-11-09 改定）：**取消「战斗补给」**，出战本身不扣食物；食物压力只剩招募、修复与扩建。
- **食物不能扣到 0 以下**：任何支付最多扣到 0，不足即为“付不起”。
- 战斗失败仍然只扣巢穴完整度；士兵保留、战后 HP 回满。
- **士兵是持久资产**：战败返场、不会饿死；没有工蚁 / 人口层（2026-11-09 删除工蚁系统，Q-025）。

## 2. 结构模板

每个兵种定义：

| 字段 | 说明 |
|---|---|
| 名称 / 阶级 | 锐士、专属兵种 |
| 标签 | 采集、战斗、建造、侦察、自杀、守护 |
| 资源配方 | 食物（唯一基础资源，2026-11-09 定） |
| 食物成本 | 生成该兵种需要多少食物（主要成本） |
| 生命 / 攻击 | 基础数值；可用 1 位小数（**无防御 / 速度**；战斗只有数值与状态，**没有减伤**） |
| 行动点 | 每轮可行动次数；**所有兵种基础 1 点**，技能 / 虫珀 / 特性可提高（见 `combat.md`） |
| 签名特性 | **每兵种至少 1 个**；被动或主动，可用共用关键词实现（见 `combat.md` 6） |
| 被动 / 主动 | 技能 |
| 经济职能 | 采集、挖掘、产粮、储粮 |
| 战斗职能 | 前排、输出、控制、阵亡爆炸 |
| Combo | 和哪些兵种/虫种咬合 |

## 3. 招募机制

- **招募改为事件触发**（2026-11-08 确定）：不再每回合固定 3 选 1。
- 触发来源：商人 / 中立生物 / 巢穴事件等（待定，Q-068）。
- 触发时仍是 **3 选 1**。
- 生成 = **食物**；具体成本按兵种不同（见 `economy.md`）。
- **不做单位转化**（2026-11-08 确定）。
- 食物不足时，对应兵种不进入候选，或显示"不可招募"。
- 可牺牲食物刷新一次；部分虫珀可刷新一次（Q-042 / Q-048）。
- 可持有兵种数量 / 招募上限由什么决定，待定（Q-123）。
- 候选池按虫种加权：**共享池 12 + 虫种专属池 12**。
- **候选池按当前阶级概率抽取**（2026-11-09 定，Q-103）：L1 只出一阶；L2 出一阶 60% / 二阶 40%；L3 出一阶 45% / 二阶 35% / 三阶 20%；每个候选独立结算。升阶后第一次招募有**新阶级保底**，详见 4.0。
- **候选池受探索进度限制**：没发现对应种子，就刷不出对应兵种。

## 3.5 探索解锁兵种

- 招募池不是一开始全开。
- 探索带回特殊**种子**后，对应兵种才进入候选池。
- 例：
  - 带回黏土共生种子 → 解锁黏土系建筑 / 兵种
  - 带回树脂共生种子 → 解锁树脂系兵种
  - 带回菌床种子 → 解锁真菌系兵种
- 因此**探索是招募的前置**，不是可选支线。

### 4.0 阶级 = 解锁层级（2026-11-09 定，Q-103）

- **阶级不是数值升阶**：不做「锐士」的 L1 / L2 / L3 三套数值，也不做同一兵种的高阶严格上位。
- **每个兵种只有一个条目**；阶级只决定它**什么时候进入招募池**。
- 阶级只决定**解锁时机**；兵种之间的差异由**定位 + 签名特性**承担，不由阶级承担。
- **名称统一为「一阶 / 二阶 / 三阶」**，对应巢穴等级：**一阶 = L1，二阶 = L2，三阶 = L3**（2026-11-09 定）。文档和 UI 不再用“一级 / 二级 / 三级”，避免玩家误以为一级 = L1。

**阶级的角色分工（2026-11-09 定）**

- **一阶 = 成长位，很多是未来的大哥**：不少一阶兵种靠签名特性滚雪球（锐士、仓士、饷者），**早期投入培养没有问题**，它们不是“过渡货”，不保证会被高阶替换。
- **二阶 / 三阶 = 机制位**：价值在**机制**（规则、组合、资源转换、条件触发），而不是数值上位。补的是“新打法”，不是“更强的同一件事”。
- 推论：**一阶兵必须有撑到后期的成长 / 转换路径**；反过来，二阶 / 三阶兵如果只是“一阶的加强版”，就是设计失败。
- 这条不推翻 4.0 的「阶级不是数值升阶」：阶级仍只决定解锁时机，但**强度不随阶级单调上升**。

**可适用玩法标签（2026-11-09）**

- 手册里每个兵种都标注了 **1–3 个玩法标签**（如 积廪 / 劝农 / 守廪 / 承伤 / 控场 / 战果流 / 花粮），用于检索与搭配提示。
- 标签**不是规则、不产生效果**，只说明这个兵种适合往哪个方向搭；实际判定以签名特性与数值为准。
- 三个虫种专属流派的标签（积廪 / 劝农 / 守廪）来自 `species.md` 3.0 的流派骨架；共享兵种只标通用玩法。

**每虫种总池：24 = 共享 12 + 专属 12**

- **共享 12 个是全局共用池**；**专属 12 个是每个虫种各一套**，不同虫种的专属池不互通。

| 阶级 | 对应巢穴 | 共享 | 专属 | 累计可用 | 本阶新增 |
|---|---|---|---|---|---|
| 一阶 | L1 | 8 | 4 | 12 | 12（共享 8 + 专属 4） |
| 二阶 | L2 | 11 | 9 | 20 | 8（共享 +3，专属 +5） |
| 三阶 | L3 | 12 | 12 | 24 | 4（共享 +1，专属 +3） |

**招募时各阶出现率（按每个候选独立抽取，暂定，Q-106）**

| 当前巢穴 | 一阶 | 二阶 | 三阶 |
|---|---|---|---|
| L1（一阶池） | 100% | — | — |
| L2（二阶池） | 60% | 40% | — |
| L3（三阶池） | 45% | 35% | 20% |

- 每档合计 100%；概率按**每个候选**独立结算，不是整次招募只抽一次阶级（暂定，Q-106）。
- 二阶 60/40 摊到 12 / 8 个单位上，**每个单位正好 5%**；三阶 45/35/20 摊到 12 / 8 / 4，每个单位约 **3.75% / 4.375% / 5%**——三阶单位单体概率最高，这是“少而精”的有意设计。
- **升阶保底（2026-11-09 定）**：每次升到新阶级后的**第一次招募**，至少出现 **1 个新阶级单位**。即：升 L2 后第一次招募必出二阶单位；升 L3 后第一次招募必出三阶单位。保底只作用于该次招募，不改变后续概率；保底单位是否必须付得起待定（Q-106）。
- 设计意图：给巢穴扩建第二收益（当前只有肥沃格 + 植物携带数），同时控制前期招募池的信息量。
- 具体每个阶级放哪些兵种**已排定名单**（2026-11-09，Q-105）：一阶 8 个（锐士 / 斥候 / 采薇 / 干城 / 焚卒 / 弩手 / 辅兵 / 缚者）；二阶 3 个（传令 / 悍卒 / 队正）；三阶 1 个（司天）。其中**锐士 / 斥候 / 采薇 / 干城 / 焚卒 / 弩手 / 辅兵 / 缚者已定稿**；**传令 / 悍卒 / 队正 / 司天已给提案条目**（4.9–4.12）；数值统一待测试校准（Q-109 / Q-118 / Q-119）。专属 12 个已出廪实提案（见 5.0，Q-107）。
- 招募抽取细节（是否允许同种重复、保底与刷新如何交互）待定（Q-106）。

### 4.1 锐士（首个定稿兵种，2026-11-09）

> 旧名「兵蚁」；按 2026-11-09 两字命名规则改为「锐士」，备选「武士」。

| 字段 | 内容 |
|---|---|
| 定位 | **标准前排**：高生命、稳定输出，靠持续攻击滚雪球 |
| 阶级 | **一阶**（巢穴 L1 池） |
| 食物成本 | **8** |
| 生命 | **10.0**（2026-11-09 由 12.0 下调） |
| 攻击 | **3.0**（伤害按 ±10% 浮动，即 2.7–3.3） |
| 行动点 | **1**（基础值，所有兵种相同） |
| 关键词 | **角质化**（每次攻击命中后触发绑定效果） |
| 效果 | 每次攻击后永久 +0.2 攻击 |
| 主动技能 | **待定**（目前只确认角质化；是否给主动技能未定） |

**角质化：每次攻击后永久成长（2026-11-09 定名）**

- 「锐士」**每次发动攻击后**，在本局内**永久获得攻击 +0.2**（2026-11-09 定）。
- **不再增加生命**，也不再随机；成长只加攻击。
- 成长跨战斗保留，**重开新局重置**。
- **成长无上限**（2026-11-09 定）：攻击可以一直累加，不设封顶。
- 成长只由“攻击”触发：被攻击、待机、使用战果都不触发。

**缺点（待确认）**

- 按“每个兵种都有缺点”的原则，「锐士」需要有明确短板；具体短板与是否用“无主动技能”承担，待确认。
- 成长是长线收益，前期兑现慢，这是它无上限的代价。

> 「锐士」的成长**不设上限**（Q-102，2026-11-09 定）；是否受战果 / 虫珀 / 虫种被动放大或复制，待定（Q-104）。
> **2026-11-09 平衡调整**：生命 12.0 → **10.0**；成长改为每次攻击**永久 +0.2 攻击**，**不再增加生命**；攻击 3.0 与成本 8 不变。目的是给干城（成本 9、防御位）留出位置：锐士只滚输出，不再同时滚血量。

### 4.2 斥候（第二个定稿兵种，2026-11-09）

> 旧名「侦察蚁」；按两字命名规则工作名「斥候」，备选「探马」。
> 定位不是“开图”，而是**前期信息 + 战果生成**：用迅捷拿天气预报，用不甘赌食物 / 巢穴经验。

| 字段 | 内容 |
|---|---|
| 定位 | **前期信息位 / 战果生成**：低血低攻，靠迅捷与不甘产出战果；通常放前排主动卖死触发不甘 |
| 阶级 | **一阶**（巢穴 L1 池） |
| 食物成本 | **5** |

**迅捷（通用关键词，战斗开始时；无加成时每场 1 次）**

- 战斗开始时，获得 **1 个战果【迅捷】**（2026-11-09 定名，与关键词同名）。
- 【迅捷】使用后：**延长天气预报窗口**，让玩家看得更远（具体延长回合数待定，提案 +1 回合；Q-091 / Q-108）。
- 无 buff / 加成时，每场战斗只触发 **1 次**；有加成可增加触发次数。
- 战果进入**道具栏**；使用后消耗（沿用 Q-073）。

**不甘（通用关键词，阵亡时；无加成时每场 1 次）**

- 斥候阵亡时，获得 **1 个战果【不甘】**（2026-11-09 定名，与关键词同名）。
- 【不甘】**使用的时候才结算**，随机三选一（概率待定，提案均等）：
  - **食物 −1**
  - **食物 +1**
  - **巢穴经验 +1**（Q-098 / Q-100）
- 无 buff / 加成时，每场战斗只触发 **1 次**；有加成可增加触发次数（复活后是否可再次触发待定，Q-108）。
- 战果进入**道具栏**；使用后消耗。

**站位**

- **推荐前排**：低血低攻，站前排更容易被击杀，从而触发不甘。
- 放后排也可，但前排未全灭时不会被攻击，不甘触发不稳定。
- 它不靠站场输出，靠“死得其所”换战果；前排格是它的成本。

**缺点**

- **低血低攻**：站场贡献低，容易在发挥作用前就被击杀。
- **不甘是概率收益**：可能 −1 食物，等于用一次死亡换一个负面结果。
- **占一个前排格**：前排本来应该放能扛的单位；带斥候等于用稳定性换信息 / 经济。
- **迅捷的天气预报可能冗余**：如果当前预报窗口已经覆盖明天，【迅捷】的收益会下降；因此它被设计成“看得更远”，而不是“看明天”。

**Combo**

- 与「焚卒」等死亡触发单位：前排卖死，换取多次不甘类效果。
- 与巢穴经验线：不甘的 +1 经验可推进巢穴升级（Q-098 / Q-100）。
- 与天气 / 雨季规划：迅捷提前看到坏天气，决定是否留食物应对探索损耗。

> 两个战果定名【迅捷】/【不甘】（与关键词同名）；是否为斥候专属、是否进入种子战果池、延长回合数与随机概率均待定（Q-108）。当前只确认：**斥候的迅捷绑定【迅捷】、不甘绑定【不甘】**；两只战果进入道具栏、使用后消耗。其他兵种的迅捷 / 不甘绑定效果待设计，不能默认都产战果。

**签名特性「采撷」（2026-11-09 定）**

- 采薇参与的战斗结束后，只要满足**任一**条件，**额外获得 1–3 食物**（随机）：
  - **打败敌方**（战斗胜利）
  - **采薇存活**
- 两个条件同时满足，也只结算 **1 次**，不叠加。

- **收益受场次限制**：一局约 13 场战斗，理论额外 **13–39 食物**，不能无限滚。
- **“打败敌方”放宽了保护要求**：胜利即结算；她是否存活只在**战败**时决定有没有额外食物。

**Combo**

- 与干城 / 庇护苔等保护型单位：战败时尽量让她活下来，仍能拿额外食物。
- 与快速清场阵容：胜利即结算，不依赖她存活。
- 与缺粮期：额外食物直接补进经济，缓解修复与扩建压力。

> 「采撷」的随机分布（1–3 是否均等）、最终裁决是否算“打败敌方”、额外食物是否受战果 / 虫珀 / 虫种被动加成，待定（Q-110）。

### 4.5 焚卒（第五个定稿兵种，2026-11-09）

> 工作名「焚卒」，备选「爆卒」。
> 定位：**阵亡爆炸 / 范围清场**；只能由「不甘」触发——**没有主动引爆**，必须真的被打死，才能用自身阵亡换取对敌方前排（清空后延及后排）的范围伤害。

| 字段 | 内容 |
|---|---|
| 定位 | **阵亡爆炸 / 范围清场**（前排优先，清空后延及后排；只能被击杀触发） |
| 阶级 | **一阶**（巢穴 L1 池） |
| 食物成本 | **6** |
| 生命 | **8.0**（提案，待平衡） |
| 攻击 | **2.0**（提案，待平衡） |
| 行动点 | **1**（基础值） |
| 通用关键词 | **不甘**（阵亡时触发绑定效果） |
| 主动技能 | **无**（不能主动引爆，只能等被击杀） |
| 绑定效果 | 对敌方当前前排每个存活单位造成 **自身攻击力 ×50%** 伤害；前排全灭后继续打后排 |

**不甘触发（2026-11-09 定）**

- 焚卒**没有主动技能，不能主观引爆**：唯一触发方式是**在战斗中被击杀阵亡**。
- 阵亡时触发「不甘」，结算一次爆炸；每场只结算 1 次。
- 活着就是普通前排（攻击 2.0 / 1 行动点），不会自己炸。
- 若整场都没被打死，则**没有任何爆炸收益**。

**不甘绑定：爆炸（2026-11-09 定）**

- 伤害基数 = **焚卒自身的攻击力 × 50%**。
  - 基础攻击 2.0 → 每个目标 **1.0**（按 ±10% 波动，即 0.9–1.1）。
  - 攻击力被战果 / 虫珀等提高后，爆炸伤害同步提高；焚卒本身没有独立成长。
- 结算顺序：
  1. 对**敌方当前前排**的每个存活单位各造成一次伤害。
  2. 结算后若**敌方前排全灭**，同一爆炸继续对**敌方后排**的每个存活单位各造成一次伤害。
- 爆炸发动时前排已经全灭 → 直接打后排。
- **前后排各只结算 1 轮**；不会因为后排也被清空而继续扩散。
- 先打前排、前排清空后才轮到后排，与“前排全灭前后排不可被攻击”的规则一致，不构成例外。

**战后**

- 阵亡只是本场退场；**战后照常返场**，不永久消失（沿用 Q-036）。
- 阵亡只影响本场阵容，不额外扣食物。

**缺点**

- **触发不可控**：必须被打死才会爆炸；玩家不能决定时机，敌人也可能先杀别的目标。
- **一次性**：阵亡后本场少一个单位，后续轮次没有它。
- **伤害只有攻击力的一半**：基础攻击 2.0，每个目标只 **1.0**，数值不高。
- **需要先打残前排**：前排满血时清空不了，爆炸打不到后排。
- **低血**：8.0，容易被敌人提前打死——这对焚卒反而是好事，但也意味着它可能还没等到前排被压残就先炸了。
- **占一个出战格**：带它等于用一个单位赌一次范围伤害。

**Combo**

- 与干城 / 斥候：前排互相掩护；焚卒被击杀时顺带清场。
- 与弩手 / 缚者：先把敌方前排压到 1.0 以下，等焚卒阵亡时清空前排、顺势打到后排。
- 与密集前排的敌人：前排越密、血线越低，1.0 的覆盖面越大。

> 伤害来源已定：**自身攻击力 ×50%**（基础 2.0 → 每目标 1.0），先打前排、前排全灭后继续打后排（Q-112）。**触发方式已定：只能由「不甘」（阵亡）触发，没有主动引爆**。HP 8.0 / 攻击 2.0 是首版数值，待平衡；爆炸击杀的归属、是否触发战蜕 / 击杀奖励，待定（Q-112）。

| 字段 | 内容 |

**角质化：连射效果（2026-11-09 定名）**

- 弩手每**发动一次攻击**，独立判定 **30%**：
  - **触发** → 立即获得 **+1 行动点**。
  - **未触发** → 本次行动结算结束。
- **可连锁**：获得的行动点可以继续攻击，攻击后再次判定，理论上没有次数上限。
- 30% 连锁的**期望攻击次数 ≈ 1.43 次/回合**（1 / (1 − 0.3)），不会失控。
- 未用完的行动点在本轮结束清零（沿用全局 行动点规则）。
- 只由**攻击**触发：被攻击、使用战果、待机都不触发。
- 额外行动点只能由弩手自己使用。

**站位**

- **必须后排**：6.0 生命，站前排容易被秒。
- 后排只有在前排全灭后才会被攻击；前排一塌，弩手直接暴露。

**缺点**

- **低血**：6.0，前排崩溃后很难活过一轮。
- **概率收益**：运气差时就是一回合一次攻击，上限不可控。
- **单体**：一次只打一个目标，不能清群。
- **依赖前排**：没有单位替它挡，连射打不出来。

**Combo**

- 与干城 / 悍卒：前排顶住，弩手在后排稳定连射。
- 与传令：传令额外 +1 行动点（提案，Q-109），与连射叠加。
- 与缚者：先控住 / 削弱目标，再让弩手集中输出。

> 30% 与 HP 6.0 / 攻击 3.0 / 食物 7 是首版数值（Q-113）。未定：概率能否被战果 / 虫珀提高、技能攻击是否同样触发、多目标或多次攻击按“每次攻击”还是“每个目标”判定。

**缠缚（签名特性，2026-11-09 定）**

- 每轮**玩家阶段开始时**，选择 **1 个敌方单位**，使其获得状态【削弱】。
- 【削弱】= 该单位**本轮造成的攻击 ×50%**（只改攻击值，见 `combat-math.md`）。
- **层数 = 剩余持续时间**：每次施加 +1 层，每轮结束 −1 层，降到 0 时移除；**层数再多，效果都只有 ×50%**，不叠加倍率。无加成时每轮 1 次。

**缺点**

- **输出极低**：攻击只有 1.5，基本打不死人。
- **只能控 1 人**：多敌人时覆盖面不足。
- **对不攻击的单位无效**：纯增益 / 治疗型敌人不受影响。
- **脆**：6.0 生命，站后排才有保障。

**Combo**

- 与干城：削弱高攻敌人 + 护盾，把前排伤害再压一层。
- 与弩手 / 锐士：减少前排压力，换更多输出轮次。
- 与 AOE 敌人：削弱的是攻击值，AOE 同样被减半。

> 2026-11-09 定稿：生命 6.0 / 攻击 1.5。削弱能否叠加、能否清除、能否重复选同一目标，属于全局状态规则，见 Q-117。

**营巢：积粮效果（2026-11-09 改版）**

**Combo**

**拾遗（签名特性，2026-11-09 改版）**

- **每场战斗开始时触发 1 次**，且**只有饷者自己参战**才触发；待命 / 未上阵不结算。
- 三件事在同一时点结算：
  1. 饷者自身**永久 −2.0 最大生命**；
  2. **随机 1 名友军**（不含饷者自己）**永久 +1.0 最大生命**；
  3. 获得 **2–3 食物**（随机，2 或 3）。
- **「永久」= 本局永久**：跨战斗保留，重开重置；不是本场 buff。
- **付不起就不触发**：最大生命**不足 2.0 时，整条效果不触发**——不扣血、不给友军、不给食物。所以 9.0 起可触发 4 次（9 → 7 → 5 → 3 → 1），之后变白板。
- **没有其它友军**时，+1.0 生命部分不结算，食物照给（仍要付 −2.0）。
- 战后 HP 回满的全局规则不变：最大生命降低后，回满到**新的最大值**。

**缺点**

- **越用越脆**：9.0 → 7.0 → 5.0 → 3.0 → 1.0，四场后变白板，前排还占着格子。
- **成长不可控**：+1.0 生命随机落到某个友军身上，可能喂到不需要的单位。
- **食物收益不稳**：2–3 随机，且必须先上阵、先挨这一刀。
- **占前排格**：低血低攻，长期占用承伤位。

## 6. 成长与持久性

- **士兵是持久资产**：战斗不会让士兵消失，也不会饿死；没有工蚁 / 人口层（2026-11-09 删除）。
- **兵种本身不做 L1 / L2 / L3 数值升级**（2026-11-09 定）；阶级只是解锁层级。是否另有老兵系统待定。
- 成长来自：
  - **合成升星（3 合 1 → 2 星）**
  - 招募更强的兵种
  - 事件 / 虫珀给单个蚂蚁附加变异
  - 虫种被动与巢穴加成
  - 虫珀

### 6.1 合成升星（2026-11-09 定）

> **3 个同名一星 → 1 个二星，2 星封顶。**

- **只到 2 星**：不存在 3 星；二星就是一局内的成长终点（2026-11-09 定）。
- **同名才合**：同一虫种、同一兵种；不同兵种 / 不同虫种之间不能合。共享兵种与专属兵种都能合。
- **自动合成**：凑齐第 3 个同名一星的**结算瞬间**自动合并成 1 个二星，**不耗食物、不占行动、不可拒绝**。招募事件结算后、其它获得单位的来源结算后各检查一次。
- **只占 1 个队伍位**：二星是 1 个单位，不是 3 个（与「一阶是未来的大哥」一致——复制品靠合成变成长期主力）。
- **本局永久**：星级不因战斗、阵亡、战后回满而改变；重开重置。
- **对局内只有 1★ 和 2★**：招募永远给一星；已持有二星不会阻止该兵种继续出现在招募里（再凑 3 个可以出第二个二星）。

**二星效果（2026-11-09 定：数值 + 签名部分强化）**

| 部分 | 变化 |
|---|---|
| **生命 / 攻击** | **在一星现有属性上再加一份「一星基础数值」**：生命 +基础生命，攻击 +基础攻击。未成长时等于 ×2（锐士 10.0 / 3.0 → 20.0 / 6.0） |
| **签名特性** | **部分强化**：签名里的**收益**固定数值 ×2；**代价 / 负面**数值、**次数 / 范围 / 目标数 / 触发条件 / 上限**一律不变（代价是否也 ×2 待定） |
| 成本 / 阶级 / 站位 | 不变（成本只是招募价，二星不再花食物） |
| 战果 / 虫珀等外部加成 | 照常作用在一个单位上 |

- **是「加一份基础值」，不是「把当前值乘二」**：局内永久成长的属性（锐士每次攻击 +0.2 攻击、仓士积粮 +4 生命、饷者等）只**保留**，**不再跟着翻倍**——否则越早养越离谱。
- **为什么值这份加成**：3 合 1 的总身板必然下降，二星买的是**槽位效率**；而合成**自动、不可拒绝**，系统必须让玩家明确变强——一格当一格半以上的用，才对得起丢掉的两个身位。
- 例：仓士「积粮」+4 生命 / +2 攻击 → 二星 **+8 / +4**；干城每轮 3.0 护盾 → **6.0**；饷者随机友军 +1.0 最大生命 → **+2.0**（自身代价 −2.0 不变）；垒卒「迅捷」+2 完整度 → **+4**。
- 概率 / 范围类签名（弩手 30%、采薇 +1–3 食物、缚者 ×50%）如何「部分」强化，逐条待定（Q-130）；未定的先**保持原值**。

> 未定：三个被合成的单位**当前属性不一致**时（有永久成长的兵）取哪一个——暂按**取三者中的最高当前值**（Q-131）；签名里的**代价 / 负面数值**是否也加一份（暂按不变）、概率 / 范围类签名怎么放大、二星是否需要单独的视觉标识、能否主动拆回三个一星、二星在随机友军 / 目标选择里算 1 个还是 3 个（按 1 个，待确认）。

> 旧说法“蚂蚁是消耗品，死了就没了”作废（2026-11-08）。
