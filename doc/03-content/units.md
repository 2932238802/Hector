# 兵种系统（卡牌层）

> 类比：卡牌。
> 但注意：**"类似卡牌"指收集与构筑结构，不是抽牌打牌。** 战斗是实际部署蚂蚁队伍。
> **详细设计暂缓（2026-11-08）**：先确立设计原则，具体兵种稍后定稿。

## 1. 定位

- 兵种是局内招募、编队、部署的单位。
- 你的兵种池 = 你的"牌库"；招募 = 以食物为主；人口上限 = 场上限制。
- 战斗不是手牌结算，而是把蚂蚁派到**蚁穴外**迎敌；蚁穴内则负责生产 / 防御准备。

## 1.5 设计原则（2026-11-08）

- **每个兵种都有优点和缺点。**
- **没有一只兵种能完美替代另一只。**
- **所有兵种都应该有用**，强弱取决于搭配与取舍。
- **每个兵种必须有签名特性**（2026-11-09 定）：至少 1 个能一句话说清“为什么选它”的被动或主动；共用关键词只是实现手段，不替代签名特性。
- **兵种都是战斗单位**（2026-11-09 定）：不存在“驻守巢穴 / 在家生产”的非战斗状态；经济型兵种的收益必须挂在**参战或战斗结算**上，不设计脱离战斗的生产模式。
- **成长不设硬上限**（2026-11-09 定）：兵种成长、战果叠加不做数值封顶，优先满足玩家“越打越强”的感觉。
- 不做"数值上位替代"：新兵种不是旧兵种的严格升级。
- **数值允许小数**：HP / 攻击可用 1 位小数，不强制整数（2026-11-09 定）。属性只保留 **HP / 攻击 / 行动点**；**防御与速度已删除**（2026-11-09 定，见 `combat.md` / `combat-math.md`）。
- **攻击有波动**：以攻击力为基数的伤害按 **±10%** 浮动，双方通用；内部与 UI 保留 1 位小数（2026-11-09 定，见 `combat.md` Q-028）。
- 玩家的乐趣来自"看自己的搭配、做自己的取舍"。

## 1.6 士兵的持久性（2026-11-08）

- **士兵是持久资产**：战斗不会让士兵消失，也**不会饿死**（2026-11-08 确定）。
- 战斗失败 → 扣巢穴完整度；士兵保留。
- **战斗失败 → 士兵返场；损失的是巢穴完整度。**
- **战后 HP 一律回满**（2026-11-09 定）：每场战斗结束后，所有参战单位 HP 回满，**包括本场阵亡的单位**；HP 不跨场累积。
- **战斗的真实代价是食物**：每次战斗损耗食物，恶劣天气会放大（Q-052 / Q-053）。
- **战斗补给按兵种计**：开战前、部署确认后，按实际出场单位逐个支付；空位 / 后备不计（2026-11-09 定，Q-052）。
- 食物不足时撤下单位直到付得起；一个都派不出则不能迎战，只能谈判 / 回避。
- 补给不退还；失败、撤退、最终裁决同样消耗。
- **工蚁是消耗品**：探索会牺牲；工蚁数量决定每回合巢穴健康恢复。

## 2. 结构模板

每个兵种定义：

| 字段 | 说明 |
|---|---|
| 名称 / 阶级 | 工蚁、锐士、专属兵种 |
| 标签 | 采集、战斗、建造、侦察、自杀、守护 |
| 资源配方 | 食物（唯一基础资源，2026-11-09 定） |
| 食物成本 | 生成该兵种需要多少食物（主要成本） |
| 战斗补给 | 每次出场消耗的食物（按兵种不同） |
| 生命 / 攻击 | 基础数值；可用 1 位小数（**无防御 / 速度**；战斗只有数值与状态，**没有减伤**） |
| 行动点 | 每轮可行动次数；**所有兵种基础 1 点**，技能 / 虫珀 / 特性可提高（见 `combat.md`） |
| 签名特性 | **每兵种至少 1 个**；被动或主动，可用共用关键词实现（见 `combat.md` 6） |
| 被动 / 主动 | 技能 |
| 经济职能 | 采集、挖掘、产粮、储粮 |
| 战斗职能 | 前排、输出、控制、自爆 |
| Combo | 和哪些兵种/虫种咬合 |

## 3. 招募机制

- **招募改为事件触发**（2026-11-08 确定）：不再每回合固定 3 选 1。
- 触发来源：商人 / 中立生物 / 巢穴事件等（待定，Q-068）。
- 触发时仍是 **3 选 1**。
- 生成 = **食物**；具体成本按兵种不同（见 `economy.md`）。
- **不再使用工蚁转化**（2026-11-08 确定）。
- 食物不足时，对应兵种不进入候选，或显示"不可招募"。
- 可牺牲食物刷新一次；部分虫珀可刷新一次（Q-042 / Q-048）。
- 人口上限由巢穴与蚁后决定；满员时不能招募。
- 候选池按虫种加权：**共享池 12 + 虫种专属池 12**。
- **候选池按当前阶级概率抽取**（2026-11-09 定，Q-103）：L2 只出一阶；L3 出一阶 60% / 二阶 40%；L4 出一阶 45% / 二阶 35% / 三阶 20%；每个候选独立结算。升阶后第一次招募有**新阶级保底**，详见 4.0。
- **候选池受探索进度限制**：没发现对应种子，就刷不出对应兵种。

## 3.5 探索解锁兵种

- 招募池不是一开始全开。
- 探索带回特殊**种子**后，对应兵种才进入候选池。
- 例：
  - 带回黏土共生种子 → 解锁黏土系建筑 / 兵种
  - 带回树脂共生种子 → 解锁树脂系兵种
  - 带回菌床种子 → 解锁真菌系兵种
- 因此**探索是招募的前置**，不是可选支线。

> **工蚁不属于共享兵种槽**，它是经济单位，由蚁后生成，见 `economy.md` 2.5。
> **所有兵种基础 行动点 = 1**（2026-11-09 定）；表中不再逐项列 2 / 3，只有条目写明加成时才提高。

### 4.0 阶级 = 解锁层级（2026-11-09 定，Q-103）

- **阶级不是数值升阶**：不做「锐士」的 L2 / L3 / L4 三套数值，也不做同一兵种的高阶严格上位。
- **每个兵种只有一个条目**；阶级只决定它**什么时候进入招募池**。
- 阶级只决定**解锁时机**；兵种之间的差异由**定位 + 签名特性**承担，不由阶级承担。
- **名称统一为「一阶 / 二阶 / 三阶」**，对应巢穴等级：**一阶 = L2，二阶 = L3，三阶 = L4**（2026-11-09 定）。文档和 UI 不再用“一级 / 二级 / 三级”，避免玩家误以为一级 = L1。

**每虫种总池：24 = 共享 12 + 专属 12**

- **共享 12 个是全局共用池**；**专属 12 个是每个虫种各一套**，不同虫种的专属池不互通。

| 阶级 | 对应巢穴 | 共享 | 专属 | 累计可用 | 本阶新增 |
|---|---|---|---|---|---|
| 一阶 | L2 | 8 | 4 | 12 | 12（共享 8 + 专属 4） |
| 二阶 | L3 | 11 | 9 | 20 | 8（共享 +3，专属 +5） |
| 三阶 | L4 | 12 | 12 | 24 | 4（共享 +1，专属 +3） |

**招募时各阶出现率（按每个候选独立抽取，暂定，Q-106）**

| 当前巢穴 | 一阶 | 二阶 | 三阶 |
|---|---|---|---|
| L2（一阶池） | 100% | — | — |
| L3（二阶池） | 60% | 40% | — |
| L4（三阶池） | 45% | 35% | 20% |

- 每档合计 100%；概率按**每个候选**独立结算，不是整次招募只抽一次阶级（暂定，Q-106）。
- 二阶 60/40 摊到 12 / 8 个单位上，**每个单位正好 5%**；三阶 45/35/20 摊到 12 / 8 / 4，每个单位约 **3.75% / 4.375% / 5%**——三阶单位单体概率最高，这是“少而精”的有意设计。
- **升阶保底（2026-11-09 定）**：每次升到新阶级后的**第一次招募**，至少出现 **1 个新阶级单位**。即：升 L3 后第一次招募必出二阶单位；升 L4 后第一次招募必出三阶单位。保底只作用于该次招募，不改变后续概率；保底单位是否必须付得起待定（Q-106）。
- 设计意图：给巢穴扩建第二收益（当前只有肥沃格 + 植物携带数），同时控制前期招募池的信息量。
- 具体每个阶级放哪些兵种**已排定名单**（2026-11-09，Q-105）：一阶 8 个（锐士 / 斥候 / 采薇 / 干城 / 焚卒 / 弩手 / 辅兵 / 缚者）；二阶 3 个（传令 / 悍卒 / 队正）；三阶 1 个（司天）。其中**锐士 / 斥候 / 采薇 / 干城 / 焚卒 / 弩手 / 辅兵已定签名**；**缚者 / 传令 / 悍卒 / 队正 / 司天已给提案条目**（4.8–4.12）；数值统一待测试校准（Q-109 / Q-118 / Q-119）。专属 12 个已出廪实提案（见 5.0，Q-107）。
- 招募抽取细节（是否允许同种重复、保底与刷新如何交互）待定（Q-106）。

> 招募池的“分批”不等于“高阶兵种更强”；每个兵种仍按定位与缺点设计，不做数值上位替代。

| 兵种 | 食物成本 | 战斗补给（食物） | 行动点 | 定位 | 技能 |

### 4.1 锐士（首个定稿兵种，2026-11-09）

> 旧名「兵蚁」；按 2026-11-09 两字命名规则改为「锐士」，备选「武士」。

| 字段 | 内容 |
|---|---|
| 定位 | **标准前排**：高生命、稳定输出，靠持续攻击滚雪球 |
| 阶级 | **一阶**（巢穴 L2 池） |
| 食物成本 | **8** |
| 战斗补给 | **1** |
| 生命 | **10.0**（2026-11-09 由 12.0 下调） |
| 攻击 | **3.0**（伤害按 ±10% 浮动，即 2.7–3.3） |
| 行动点 | **1**（基础值，所有兵种相同） |
| 主动技能 | **待定**（目前只确认成长被动；是否给主动技能未定） |

**被动：每次攻击后永久成长（正式关键词名待定）**

- 「锐士」**每次发动攻击后**，在本局内**永久获得攻击 +0.2**（2026-11-09 定）。
- **不再增加生命**，也不再随机；成长只加攻击。
- 成长跨战斗保留，**重开新局重置**。
- **成长无上限**（2026-11-09 定）：攻击可以一直累加，不设封顶。
- 成长只由“攻击”触发：被攻击、待机、使用战果都不触发。

**缺点（待确认）**

- 按“每个兵种都有缺点”的原则，「锐士」需要有明确短板；具体短板与是否用“无主动技能”承担，待确认。
- 成长是长线收益，前期兑现慢，这是它无上限的代价。

> 「锐士」的成长**不设上限**（Q-102，2026-11-09 定）；是否受战果 / 虫珀 / 虫种被动放大或复制，待定（Q-104）。
> **2026-11-09 平衡调整**：生命 12.0 → **10.0**；成长改为每次攻击**永久 +0.2 攻击**，**不再增加生命**；攻击 3.0 与成本 8 不变。目的是给干城（成本 9、防御位）留出位置：锐士只滚输出，不再同时滚血量。

### 4.2 斥候（第二个定稿兵种，2026-11-09）

> 旧名「侦察蚁」；按两字命名规则工作名「斥候」，备选「探马」。
> 定位不是“开图”，而是**前期信息 + 战果生成**：用迅捷拿天气预报，用不甘赌食物 / 巢穴经验。

| 字段 | 内容 |
|---|---|
| 定位 | **前期信息位 / 战果生成**：低血低攻，靠迅捷与不甘产出战果；通常放前排主动卖死触发不甘 |
| 阶级 | **一阶**（巢穴 L2 池） |
| 食物成本 | **5** |
| 战斗补给 | **1** |
| 生命 | **7.0**（提案，待平衡；明显低于锐士） |
| 攻击 | **2.0**（提案，待平衡） |
| 行动点 | **1**（基础值） |
| 主动技能 | **待定**（当前只确认迅捷 / 不甘） |

**迅捷（通用关键词，战斗开始时；无加成时每场 1 次）**

- 战斗开始时，获得 **1 个战果【占风】**（暂名）。
- 【占风】使用后：**延长天气预报窗口**，让玩家看得更远（具体延长回合数待定，提案 +1 回合；Q-091 / Q-108）。
- 无 buff / 加成时，每场战斗只触发 **1 次**；有加成可增加触发次数。
- 战果进入**道具栏**；使用后消耗（沿用 Q-073）。

**不甘（通用关键词，阵亡时；无加成时每场 1 次）**

- 斥候阵亡时，获得 **1 个战果【遗报】**（暂名）。
- 【遗报】**使用的时候才结算**，随机三选一（概率待定，提案均等）：
  - **食物 −1**
  - **食物 +1**
  - **巢穴经验 +1**（Q-098 / Q-100）
- 无 buff / 加成时，每场战斗只触发 **1 次**；有加成可增加触发次数（复活后是否可再次触发待定，Q-108）。
- 战果进入**道具栏**；使用后消耗。

**站位**

- **推荐前排**：低血低攻，站前排更容易被击杀，从而触发不甘。
- 放后排也可，但前排未全灭时不会被攻击，不甘触发不稳定。
- 它不靠站场输出，靠“死得其所”换战果；前排格是它的成本。

**缺点**

- **低血低攻**：站场贡献低，容易在发挥作用前就被击杀。
- **不甘是概率收益**：可能 −1 食物，等于用一次死亡换一个负面结果。
- **占一个前排格**：前排本来应该放能扛的单位；带斥候等于用稳定性换信息 / 经济。
- **迅捷的天气预报可能冗余**：如果当前预报窗口已经覆盖明天，【占风】的收益会下降；因此它被设计成“看得更远”，而不是“看明天”。

**Combo**

- 与「焚卒」等死亡触发单位：前排卖死，换取多次不甘类效果。
- 与巢穴经验线：不甘的 +1 经验可推进巢穴升级（Q-098 / Q-100）。
- 与天气 / 雨季规划：占风提前看到坏天气，决定是否留食物付战斗补给。

> 两个战果暂名【占风】/【遗报】，是否为斥候专属、是否进入种子战果池、延长回合数与随机概率均待定（Q-108）。当前只确认：**斥候的迅捷绑定【占风】、不甘绑定【遗报】**；两只战果进入道具栏、使用后消耗。其他兵种的迅捷 / 不甘绑定效果待设计，不能默认都产战果。

### 4.3 采薇（第三个定稿兵种，2026-11-09）

> 旧名「采集蚁」；工作名「采薇」，备选「农夫」。
> 定位：**战斗结算型经济位**——不靠产粮建筑，靠“打赢，或活着回来”带回额外食物。

| 字段 | 内容 |
|---|---|
| 定位 | **战斗结算型经济**：参战并满足条件，额外带回 1–3 食物 |
| 阶级 | **一阶**（巢穴 L2 池） |
| 食物成本 | **6** |
| 战斗补给 | **1** |
| 生命 | **6.0**（2026-11-09 定） |
| 攻击 | **1.5**（2026-11-09 定） |
| 行动点 | **1**（基础值） |
| 主动技能 | **待定**（当前只确认签名特性「采撷」） |

**签名特性「采撷」（2026-11-09 定）**

- 采薇参与的战斗结束后，只要满足**任一**条件，**额外获得 1–3 食物**（随机）：
  - **打败敌方**（战斗胜利）
  - **采薇存活**
- 两个条件同时满足，也只结算 **1 次**，不叠加。
- 唯一没有额外收益的情况：**战斗失败且采薇阵亡**。
- **常规战斗奖励照常结算**（食物 + 战果）；额外食物是在常规奖励**之上追加**，不替换。
- 多只采薇：每场战斗最多结算 **1 次**，不叠加（2026-11-09 定）。

**缺点**

- **低血低攻**：站场贡献弱，容易在发挥作用前被击杀。
- **占一个出战格**：不打仗就没有经济收益。
- **收益受场次限制**：一局约 13 场战斗，理论额外 **13–39 食物**，不能无限滚。
- **“打败敌方”放宽了保护要求**：胜利即结算；她是否存活只在**战败**时决定有没有额外食物。

**Combo**

- 与干城 / 庇护苔等保护型单位：战败时尽量让她活下来，仍能拿额外食物。
- 与快速清场阵容：胜利即结算，不依赖她存活。
- 与雨天 / 高补给战斗：额外食物部分抵消补给压力。

> 「采撷」的随机分布（1–3 是否均等）、最终裁决是否算“打败敌方”、额外食物是否受战果 / 虫珀 / 虫种被动加成，待定（Q-110）。

| 通用关键词 | **扼守**（位于前排且存活时，敌方单体攻击必须选择它） |
| 签名特性 | **格挡**：每轮玩家阶段开始时获得 **3.0 护盾** |

**格挡（签名特性，2026-11-09 定）**

- 当前按“**只提高上限、不回复当前生命**”记录；当前生命是否同时 +1 待定（Q-111）。

- **攻击低**：2.0，清场慢，不能靠它赢输出。

- **只吸单体**：AOE 是否受扼守影响逐技能标注；对 AOE 阵容保护有限。
- **成长依赖挨打**：敌人不打它、或战斗快速结束时，成长慢。

### 4.5 焚卒（第五个定稿兵种，2026-11-09）

> 工作名「焚卒」，备选「爆卒」。
> 定位：**一次性自爆 / 范围清场**；主动引爆，用自身阵亡换取对敌方前排（清空后延及后排）的范围伤害。

| 字段 | 内容 |
|---|---|
| 定位 | **自爆 / 范围清场**（前排优先，清空后延及后排） |
| 阶级 | **一阶**（巢穴 L2 池） |
| 食物成本 | **6** |
| 战斗补给 | **1** |
| 生命 | **8.0**（提案，待平衡） |
| 攻击 | **2.0**（提案，待平衡） |
| 行动点 | **1**（基础值） |
| 通用关键词 | **不甘**（阵亡时触发绑定效果） |
| 主动技能 | **自爆**：1 行动点，立即阵亡并触发不甘 |
| 绑定效果 | 对敌方当前前排每个存活单位造成 **自身攻击力 ×50%** 伤害；前排全灭后继续打后排 |

**自爆（主动，2026-11-09 定）**

- 消耗 **1 行动点**，焚卒**立即阵亡**，触发「不甘」。
- 被敌方击杀时同样触发「不甘」。
- **主动自爆与阵亡触发只结算 1 次**，不叠加。
- 自爆本身不造成额外伤害；伤害来自「不甘」的绑定效果。

**不甘绑定：爆炸（2026-11-09 定）**

- 伤害基数 = **焚卒自身的攻击力 × 50%**。
  - 基础攻击 2.0 → 每个目标 **1.0**（按 ±10% 波动，即 0.9–1.1）。
  - 攻击力被战果 / 虫珀等提高后，爆炸伤害同步提高；焚卒本身没有独立成长。
- 结算顺序：
  1. 对**敌方当前前排**的每个存活单位各造成一次伤害。
  2. 结算后若**敌方前排全灭**，同一爆炸继续对**敌方后排**的每个存活单位各造成一次伤害。
- 爆炸发动时前排已经全灭 → 直接打后排。
- **前后排各只结算 1 轮**；不会因为后排也被清空而继续扩散。
- 先打前排、前排清空后才轮到后排，与“前排全灭前后排不可被攻击”的规则一致，不构成例外。

**战后**

- 自爆只是本场退场；**战后照常返场**，不永久消失（沿用 Q-036）。
- 自爆不退还战斗补给。

**缺点**

- **一次性**：自爆后本场少一个单位，后续轮次没有它。
- **伤害只有攻击力的一半**：基础攻击 2.0，每个目标只 **1.0**，数值不高。
- **需要先打残前排**：前排满血时清空不了，爆炸打不到后排。
- **低血**：8.0，容易被敌人提前打死；但阵亡也会触发不甘，不算完全亏。
- **占一个出战格**：带它等于用一个单位换一次范围伤害。

**Combo**

- 与干城 / 斥候：前排卖死，触发其他不甘 / 死亡效果。
- 与弩手 / 缚者：先把敌方前排压到 1.0 以下，再自爆清空前排、顺势打到后排。
- 与密集前排的敌人：前排越密、血线越低，1.0 的覆盖面越大。

> 伤害来源已定：**自身攻击力 ×50%**（基础 2.0 → 每目标 1.0），先打前排、前排全灭后继续打后排（Q-112）。HP 8.0 / 攻击 2.0 是首版数值，待平衡；自爆击杀的归属、是否触发战蜕 / 击杀奖励，待定（Q-112）。

### 4.6 弩手（第六个定稿兵种，2026-11-09）

> 旧槽位「远程位」；工作名「弩手」，备选「射手」。
> 定位：**后排输出 / 连射**——每次攻击都有概率追加行动点，靠连锁把一轮打成多次攻击。

| 字段 | 内容 |

**连射（签名特性，2026-11-09 定）**

- 弩手每**发动一次攻击**，独立判定 **30%**：
  - **触发** → 立即获得 **+1 行动点**。
  - **未触发** → 本次行动结算结束。
- **可连锁**：获得的行动点可以继续攻击，攻击后再次判定，理论上没有次数上限。
- 30% 连锁的**期望攻击次数 ≈ 1.43 次/回合**（1 / (1 − 0.3)），不会失控。
- 未用完的行动点在本轮结束清零（沿用全局 行动点规则）。
- 只由**攻击**触发：被攻击、使用战果、待机都不触发。
- 额外行动点只能由弩手自己使用。

**站位**

- **必须后排**：6.0 生命，站前排容易被秒。
- 后排只有在前排全灭后才会被攻击；前排一塌，弩手直接暴露。

**缺点**

- **低血**：6.0，前排崩溃后很难活过一轮。
- **概率收益**：运气差时就是一回合一次攻击，上限不可控。
- **单体**：一次只打一个目标，不能清群。
- **依赖前排**：没有单位替它挡，连射打不出来。

**Combo**

- 与干城 / 悍卒：前排顶住，弩手在后排稳定连射。
- 与传令：传令额外 +1 行动点（提案，Q-109），与连射叠加。
- 与缚者：先控住 / 削弱目标，再让弩手集中输出。

> 30% 与 HP 6.0 / 攻击 3.0 / 食物 7 是首版数值（Q-113）。未定：概率能否被战果 / 虫珀提高、技能攻击是否同样触发、多目标或多次攻击按“每次攻击”还是“每个目标”判定。

### 5.3 拒卒（一阶专属，提案，2026-11-09）

> 工作名「拒卒」，备选「挡卒」；廪实专属。
> 定位：**前排 / 守廪**——开场一次性硬盾，扛住第一轮爆发。

| 字段 | 内容 |
|---|---|
| 定位 | **前排 / 守廪**：开场一次性护盾 |
| 阶级 | **一阶**（巢穴 L2 池，廪实专属） |
| 食物成本 | **8**（提案） |
| 战斗补给 | **2**（提案） |
| 生命 | **11.0**（提案） |
| 攻击 | **2.0**（提案） |
| 行动点 | **1**（基础值） |
| 站位 | **前排** |
| 签名特性 | **立壁**：战斗开始时获得 3.0 护盾，一次性，不刷新 |
| 主动技能 | **待定** |

**立壁（签名特性，提案）**

- **战斗开始时**（双方入场后）获得 **3.0 护盾**。
- 护盾是**数值**，先于 HP 被扣（见 `combat-math.md`）。
- **一次性**：用完就没了，**不随轮次刷新、也不每轮清零**——它是独立的一次性盾，与辅兵 / 队正的小额护盾不同。
- 多来源护盾如何合并，与 Q-111 一起待定。

**缺点**

- **第二轮起白板**：没有持续防御，也没有成长。
- **3.0 后期不够**：三阶敌人单次攻击常在 3–4.5。
- **和干城重叠**：同为前排承伤位，功能有交集。

**Combo**

- 与干城轮换：早期用拒卒省成本，后期换干城。
- 与障卒：拒卒挡 AOE 前的零头，障卒挡单体。
- 与拾卒 / 殉卒：开场盾换输出时间。

> 3.0 是否够、是否改为每场两次、与干城同队的取舍，待定（Q-107）。

### 5.4 禾卒（一阶专属，提案，2026-11-09）

> 工作名「禾卒」，备选「苗卒」；廪实专属。
> 定位：**后排 / 劝农**——按存活植物数给全队加攻。

| 字段 | 内容 |
|---|---|
| 定位 | **后排 / 劝农**：植物越多，全队越强 |
| 阶级 | **一阶**（巢穴 L2 池，廪实专属） |
| 食物成本 | **7**（提案） |
| 战斗补给 | **2**（提案） |
| 生命 | **7.0**（提案） |
| 攻击 | **1.5**（提案） |
| 行动点 | **1**（基础值） |
| 站位 | **后排** |
| 签名特性 | **护苗**：本场每有 1 个存活的己方战斗植物，全体友军 +0.5 攻击（上限 +2.0） |
| 主动技能 | **待定** |

**护苗（签名特性，提案）**

- 按**当前存活的己方战斗植物数**实时计算：植物被摧毁的瞬间，加成随之下降。
- **每个植物 +0.5，上限 +2.0**（即 4 株封顶，正好是 L4 的携带数）。
- 加成对象是**全体友军单位**；战斗植物自身是否享受，待定。
- 植物携带数：L2 = 2 / L3 = 3 / L4 = 4（Q-095），所以 L2 阶段最多 +1.0。

**缺点**

- **不带植物就是白板**：1.5 攻击，全场最低。
- **加成会掉**：植物先死，全队攻击立刻降。
- **鼓励防守**：必须带植物、必须保植物，和速攻阵容冲突。

**Combo**

- 与田正：植物加盾、禾卒加攻，一攻一守。
- 与荆棘防线 / 毒刺藤 / 庇护苔：三种都能吃到加成。
- 与守廪构筑：植物 + 镇廪 + 禾卒的消耗战。

> 植物自身是否享受加成、植物死亡瞬间的结算、+0.5 / 上限 +2.0 是否合适，待定（Q-107）。

## 6. 成长与持久性

- **士兵是持久资产**：战斗不会让士兵消失，也不会饿死；工蚁才是消耗品。
- **兵种本身不做 L2 / L3 / L4 数值升级**（2026-11-09 定）；阶级只是解锁层级。是否另有老兵系统待定。
- 成长来自：
  - 招募更强的兵种
  - 事件 / 虫珀给单个蚂蚁附加变异
  - 虫种被动与巢穴加成
  - 虫珀

> 旧说法“蚂蚁是消耗品，死了就没了”作废（2026-11-08）。
