# 兵种系统（卡牌层）

> 类比：卡牌。
> 但注意：**"类似卡牌"指收集与构筑结构，不是抽牌打牌。** 战斗是实际部署蚂蚁队伍。
> **详细设计暂缓（2026-11-08）**：先确立设计原则，具体兵种稍后定稿。

## 1. 定位

- 兵种是局内招募、编队、部署的单位。
- 你的兵种池 = 你的"牌库"；招募 = 抽卡/购买；人口上限 = 场上限制。
- 战斗不是手牌结算，而是把蚂蚁派到地表/巢穴执行任务。

## 1.5 设计原则（2026-11-08）

- **每个兵种都有优点和缺点。**
- **没有一只兵种能完美替代另一只。**
- **所有兵种都应该有用**，强弱取决于搭配与取舍。
- 不做"数值上位替代"：新兵种不是旧兵种的严格升级。
- 玩家的乐趣来自"看自己的搭配、做自己的取舍"。

## 2. 结构模板

每个兵种定义：

| 字段 | 说明 |
|---|---|
| 名称 / 阶级 | 工蚁、兵蚁、特化蚁 |
| 标签 | 采集、战斗、建造、侦察、自杀、守护 |
| 资源配方 | 食物 + 石头 / 纤维等 |
| 生命 / 攻击 / 防御 / 速度 | 基础数值 |
| 被动 / 主动 | 技能 |
| 经济职能 | 采集、挖掘、产粮、储粮 |
| 战斗职能 | 前排、输出、控制、自爆 |
| Combo | 和哪些兵种/蚁种咬合 |

## 3. 招募机制

- 每回合（或每 N 回合）出现 **3 个候选兵种**。
- 招募消耗**资源配方**（食物 + 石头 / 纤维等），不只是食物。
- 材料不足时，对应兵种不进入候选，或显示"不可招募"。
- 可花 1 食物刷新。
- 人口上限由巢穴与蚁后决定；满员时不能招募。
- 候选池按蚁种加权：共享池 + 蚁种专属池。
- **候选池受探索进度限制**：没发现对应地形 / 材料，就刷不出对应兵种。

## 3.5 探索解锁兵种

- 招募池不是一开始全开。
- 探索到新地形 / 新材料后，对应兵种才进入候选池。
- 例：
  - 发现黏土坑 → 解锁黏土系建筑 / 兵种
  - 发现树脂树 → 解锁树脂系兵种
  - 发现地下菌床 → 解锁真菌系兵种
- 因此**探索是招募的前置**，不是可选支线。

## 4. 首版共享兵种（占位）

| 兵种 | 配方 | 定位 | 技能 |
|---|---|---|---|
| 工蚁 | 3 食物 | 经济 | 采集 +1；可挖掘/建造 |
| 兵蚁 | 5 食物 + 2 石头 | 前排 | 高血，基础攻击 |
| 侦察蚁 | 3 食物 + 1 纤维 | 情报 | 开图、预警 |
| 采集蚁 | 4 食物 | 经济 | 采集 +2 |
| 守卫蚁 | 5 食物 + 2 石头 | 防御 | 嘲讽 / 减伤 |
| 爆炸蚁 | 4 食物 + 1 纤维 | 自爆 | 范围伤害，自身死亡 |

> 数值为首版占位，待平衡。

## 5. 专属兵种

每个蚁种有 2–4 个专属兵种，只能在该蚁种局中出现。示例：

- 行军蚁：突袭蚁、行军兵蚁
- 切叶蚁：菌农蚁、园丁蚁
- 织叶蚁：织工蚁、桥梁蚁
- 蜜罐蚁：蜜罐蚁、守卫蚁
- 收获蚁：收获工蚁、种子守卫

## 6. 成长

- 兵种本身**不升级**（蚂蚁是消耗品），保持"死了就没了"的压力。
- 成长来自：
  - 招募更强的兵种
  - 事件/天赋给单个蚂蚁附加变异（该蚂蚁死亡则变异消失）
  - 蚁种被动与巢穴加成

> 如果后续觉得缺少养成感，再考虑"精英蚁/老兵"作为可选系统。

## 7. Combo 示例

| 组合 | 效果 |
|---|---|
| 行军蚁 + 蜜罐蚁 | 战利品存起来，撑过断粮期 |
| 织叶蚁 + 采集蚁 | 搭桥缩短采集路线，效率翻倍 |
| 切叶蚁 + 守卫蚁 | 守住真菌农场，滚雪球 |
| 侦察蚁 + 爆炸蚁 | 提前发现敌群，自爆埋伏 |
