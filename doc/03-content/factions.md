# 势力与中立生物（草案）

> 事件组里的"敌对势力"不是单一敌人，而是有类型、有态度的势力。
> 玩家可以选择打谁、交谁。

## 1. 势力类型

| 类型 | 态度 | 风险 | 主要收益 |
|---|---|---|---|
| 中立生物 | 可交友 / 可击败 | 低~中 | 商人 / 战友 / buff / 虫珀 |
| 弱小敌对势力 | 敌对 | 低 | 基础资源、虫珀、战果 |
| 强大敌对势力 | 敌对 | 高 | 稀有虫珀、稀有种子、战果 |

## 2. 中立生物

### 2.1 交友

- 成为**商人**：定期交易资源 / 虫珀 / **种子**，并可能触发**招募**（Q-068）
- 成为**战友**：提供单位或战斗支援
- 成为**战斗 buff**：持续若干回合的加成
- 交友可能需要付出食物 / 资源 / 完成委托

### 2.2 击败

- 获得**虫珀**（遗物类物品）
- 获得食物 / 种子
- 获得**战果**

> 交友 vs 击败是核心取舍：长期关系 or 一次性收益。

## 3. 敌对势力

- **敌对势力基本不可避免**（2026-11-08 确定）：玩家可以选择打谁、什么时候打，但不能靠一直回避完全绕开。
- **弱小**：低风险、低奖励，适合前期练手 / 滚资源。
- **强大**：高风险、高奖励，可能掉落稀有虫珀 / 种子 / 战果。
- **季节影响**：春天敌对势力更强大；夏天遇到敌对势力的可能性更小；秋天击败敌对势力可能额外掉落（Q-057）。
- 击败后可能留下"势力仇恨"或后续报复（待定）。

## 4. 战果作为奖励

- 战果可从以下获得：
  - 击败敌对势力
  - 中立生物交易 / 委托
  - 探索带回种子
  - 事件奖励
- 这让"打谁"直接影响战果获取与战斗构筑。

## 5. 与事件组的关系

- 每个事件组里的"敌对昆虫来访"会指定势力类型。
- 同一回合的不同事件组，可能提供"打弱小"或"打强大"的不同选择。
- 玩家根据巢穴完整度、军力、战果 / 种子需求来选组。
- **敌对压力有保底下限**：6 种事件组模板全部至少含 1 个敌对势力，玩家可以选择打谁、谈谁，但不能完全绕开；具体规则见 `02-systems/events.md`（Q-056）。
