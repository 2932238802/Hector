# 敌人

> 独立文件（2026-11-09）：敌人不是玩家兵种，从切片文档拆出，避免和 `units.md` 混在一起。
> **规则**：敌人与玩家兵种**完全对称**——同样使用 HP / 攻击 / 行动点 / 护盾 / 状态，没有第二套战斗逻辑（2026-11-09 定）。
> **分类**：按**族群**分；**强敌** = 数值更高 + 一个玩家没有的独特机制。
> 数值分档见 `02-systems/combat-math.md` §5（一阶 HP 4.0–8.0 / 攻击 1.5–2.5）。本期只做一阶。

## 1. 族群（春季 3 族，提案）

| 族群 | 风格 | 关键词 |
|---|---|---|
| **甲虫** | 高 HP、低攻、前排硬壳 | 护盾、削弱 |
| **蜘蛛** | 低 HP、高攻、结网削弱 | 削弱 |
| **鸟** | 强敌专属，俯冲越过前排 | 越排攻击 |

## 2. 敌人条目模板

| 字段 | 内容 |
|---|---|
| 族群 | 甲虫 / 蜘蛛 / 鸟 |

## 3. 春季敌人（4 个，提案 v0，Q-122）

### 3.1 盾甲（甲虫）

| 字段 | 内容 |
|---|---|
| 族群 | 甲虫 |
| 阶级 | 一阶 |
| 生命 | **8.0**（提案） |
| 攻击 | **1.5**（提案） |
| 行动点 | 1 |
| 站位 | 前排 |
| 签名 | **厚甲**：每轮玩家阶段开始获得 2.0 护盾，不叠加 |

- 定位：消耗玩家输出时间的肉盾；攻击低，威胁来自拖轮数。
- 与玩家「堡坞蚁」的区别：没有嘲讽、没有成长，只是单纯厚。

### 3.2 锹甲（甲虫）

| 字段 | 内容 |
|---|---|
| 族群 | 甲虫 |
| 阶级 | 一阶 |
| 生命 | **6.0**（提案） |
| 攻击 | **2.5**（提案） |
| 行动点 | 1 |
| 站位 | 前排 |
| 签名 | **挑击**：攻击命中后 30% 使目标获得【削弱】（本回合攻击 ×50%） |

- 定位：前排压力位；【削弱】会直接压低玩家前排输出。
- 与玩家【削弱】状态的区别：锹甲是攻击附带、概率施加；玩家侧的削弱由技能主动选目标、每轮稳定施加（原「网罟蚁」已删除）。

### 3.3 结网蛛（蜘蛛）

| 字段 | 内容 |
|---|---|
| 族群 | 蜘蛛 |
| 阶级 | 一阶 |
| 生命 | **4.0**（提案） |
| 攻击 | **2.0**（提案） |
| 行动点 | 1 |
| 站位 | 后排 |
| 签名 | **吐丝**：每轮玩家阶段开始，对随机 1 名玩家单位施加【削弱】 |

- 定位：后排干扰；血薄，但前排未清空时打不到。
- 两只结网蛛会叠 2 层【削弱】，但效果仍只有 ×50%，只是持续时间更长，不会锁死开局（Q-117）。

### 3.4 掠食雀（鸟，强敌）

| 字段 | 内容 |
|---|---|
| 族群 | 鸟 |
| 阶级 | 一阶（强敌） |
| 生命 | **9.0**（提案，同阶 +12%） |
| 攻击 | **3.0**（提案，同阶 +20%） |
| 行动点 | 1 |
| 站位 | 后排 |
| 签名 | **俯冲**：每轮首次攻击**无视前排**，直接攻击玩家后排 1 名单位 |

- 定位：强敌；独特机制 = **唯一的越排攻击**，打破“前排全灭才能打后排”。
- 限制：每轮只有第一次攻击无视前排，之后按正常前后排规则。
- 还没有：召唤、阶段变化等更复杂机制（可后续加，本期不做）。

## 4. 出场配置（春季）

| 事件 | 组合 | 总数 |
|---|---|---|
| 沙路截击 | 盾甲 ×2 | 2 |
| 树脂争夺 | 锹甲 ×2 | 2 |
| 巢口巡游 | 结网蛛 ×2 | 2 |
| 雀袭（强敌） | 掠食雀 ×1 + 盾甲 ×1 | 2 |

- 开局玩家只有 2 个兵，**前期每场 2 个敌人**；第 3 回合起可加到 3 个（Q-121）。
- 敌阵列同样前 4 后 3；**越排攻击是唯一例外**，且必须写在敌人条目里。
