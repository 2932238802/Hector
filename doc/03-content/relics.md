# 虫珀（遗物类物品）

> 对标：杀戮尖塔的"遗物"——持久被动效果。
> **正式名称：虫珀**（2026-11-08 定，2026-11-09 再次确认）。

## 1. 命名

- 已定名 **虫珀**。
- 命名理由：琥珀包裹昆虫，珍贵、有收藏感，最像"遗物"。
- 以下候选不再使用：虫蜕 / 甲片 / 奇物 / 战利品。

## 2. 定位

- 不额外占用资源。
- 提供**持久被动效果**，改变一局的玩法。
- 一局可持有多个，效果可叠加 / 联动。

## 3. 效果类型

| 类型 | 例 |
|---|---|
| 经济 | 每回合 +1 食物；收获型种子产量 +1 |
| 战斗 | 「锐士」攻击 +1；「焚卒」爆炸伤害 +1 |
| 巢穴 | 完整度上限 +10；修复更便宜 |
| 规则 | 事件组多 1 个选项；三选一可多选；招募可刷新；中立生物更易交友 |
| 招募 | 解锁一个稀有兵种候选 |

## 3.5 已确认的规则类效果

- 部分虫珀可以让**三选一多选**（Q-037）。
- 部分虫珀可以提供**招募刷新一次**（Q-042 / Q-048）。
- 具体是哪些虫珀、每次几个，待设计。

## 4. 获取

- **神秘遗迹：基础奖励 1 个普通虫珀**；另有概率**直接获得** 1 个**诅咒虫珀**，不可拒绝。
- 击败敌对势力（弱小 / 强大）
- 中立生物交易或委托
- 探索带回种子
- 事件奖励

## 5. 稀有度

- 普通 / 稀有 / 传说（暂定）
- 强大势力掉落稀有以上；中立生物给普通 / 特殊。
- **诅咒虫珀**独立于普通稀有度：它按“负面效果强度”分级，不按稀有度。

## 5.1 诅咒虫珀（2026-11-09 新增）

- 定位：带明确负面效果的虫珀，来源以神秘遗迹为主。
- 结构：以“强力正面 + 明确负面”为主；也可以是纯负面但可净化。
- 获取：遗迹基础奖励之外的概率掉落；**触发时直接获得，不可拒绝**。
- 目的：给遗迹增加“赌”的成分，而不是纯随机惩罚；因为强制获得，建议负面可控、正面足够强。
- 净化：特定事件 / 虫珀 / 遗迹可以移除诅咒（具体待定，Q-088）。
- 具体概率、负面强度、可净化方式待测试。
