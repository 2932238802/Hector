# 虫珀（遗物类物品）

> 对标：杀戮尖塔的"遗物"——持久被动效果。
> **正式名称：虫珀**（2026-11-08 确定）。

## 1. 命名

- 已定名 **虫珀**。
- 命名理由：琥珀包裹昆虫，珍贵、有收藏感，最像"遗物"。
- 以下候选不再使用：虫蜕 / 甲片 / 奇物 / 战利品。

## 2. 定位

- 不占人口、不占资源。
- 提供**持久被动效果**，改变一局的玩法。
- 一局可持有多个，效果可叠加 / 联动。

## 3. 效果类型

| 类型 | 例 |
|---|---|
| 经济 | 每天 +1 食物；石头采集 +1 |
| 战斗 | 兵蚁攻击 +1；爆炸蚁范围 +1 |
| 巢穴 | 完整度上限 +10；修复更便宜 |
| 规则 | 事件组多 1 个选项；中立生物更易交友 |
| 招募 | 解锁一个稀有兵种候选 |

## 4. 获取

- 击败敌对势力（弱小 / 强大）
- 中立生物交易或委托
- 探索特殊地形
- 事件奖励

## 5. 稀有度

- 普通 / 稀有 / 传说（暂定）
- 强大势力掉落稀有以上；中立生物给普通 / 特殊。
