# 天赋树（暂缓，不作为 v1 系统）

> **2026-11-09：天赋系统暂缓。** 本文保留为历史存档，不参与当前设计；虫种模板已移除天赋树，成长改由兵种 / 种子 / 战果 / 虫珀 / 巢穴扩建承担。
> 如之后恢复天赋，需要重新评审结构、点数与与其他系统的关系。
>
> **2026-11-08：天赋树的具体结构尚未讨论。**
> 本文只记录已确认的原则与点数规则。
> 旧版"3 分支 × 3 层 / 9–12 节点"是占位假设，**作废**。

## 1. 已确认

- 每个虫种一棵**专属**天赋树。
- 天赋树**改规则**，不是小数值加成。
- 强度对标《王之凝视》的国王技能：每个节点都应显著改变玩法。
- **默认全部解锁**：节点从第 1 回合起可见、可选；不是自动生效。
- **不支持洗点**（2026-11-08 确定）。
- 每局重置；局外只解锁新虫种 / 兵种 / 事件，不锁天赋节点。

## 2. 点数（基础节奏待重调）

> 2026-11-09：一局由 40 回合改为 **24 回合**，原先“每 4 回合 +1 → 基础 10 点”不再成立。
> 下表是**待选方案**，尚未拍板（Q-016）。

| 来源 | 数量 |
|---|---|
| 每 N 个回合 | +1（24 回合下候选：每 3 回合 = 8 点 / 每 4 回合 = 6 点） |
| 事件 / 敌对势力 / 中立交易 / 探索 | 额外最多 +10 |

- 总硬上限仍暂定 **20 点**，但基础点数需随 N 重算（Q-016）。
- 基础点数来自时间，额外点数来自掉落。

## 3. 结构（未讨论）

以下全部待定：

旧版"3×3、9–12 节点"不再作为设计依据。

## 4. 与其他系统的关系

- **天赋改规则，兵种执行。**
- 事件可以直接给天赋、给点数、或给"单体变异"。
- 天赋可以解锁专属兵种。
- 天赋强度与虫珀、势力奖励要有区分，避免重复。
