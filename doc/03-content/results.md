# 战果（战斗道具层）

> 独立文件（2026-11-09）：战果不是兵种，从 `units.md` 拆出，避免开发时和兵种数据混在一起。
> 种子产出大类：食物型 → 食物；**战果型 → 战果**；工具型 → 恢复 / 增益 / 羁绊 / 战斗植物（Q-071）。
> 每颗种子固定一种产出大类，不混产。

## 1. 定位

- **战果 ≈ 法术卡式战斗道具**（2026-11-09 用户定位）：可以直接给士兵加属性，也可以挂 buff（成长、攻击附带毒性、死亡触发等）。
- 不属于兵种、不占部署格、不占行动点。

## 2. 来源

| 来源 | 说明 |
|---|---|
| 战果型种子 | 周期性产出（产出周期见 `seeds.md`） |
| 战斗奖励 | 普通敌对昆虫掉落食物 + 战果（Q-084 / Q-099） |
| 兵种绑定效果 | 关键词绑定效果可以产出战果；当前仅「斥候」确认：迅捷 → 【迅捷】、不甘 → 【不甘】（`units.md` 4.2，Q-108）；其他兵种待设计（Q-032） |

## 3. 使用规则（2026-11-09 定）

- **存放**：进入**道具栏**，平面列表，不做背包网格（Q-072）。
- **使用时机**：准备阶段随时可用；战斗中我方尚未失败时随时可用；部分战果可对敌对势力使用（Q-073）。
- **消耗**：使用后消耗；**不占行动点、无每轮 / 每场次数上限**，只受持有数量限制（Q-073）。
- **时效**：部分持续本场，部分本局永久（重开重置）（Q-094）。
- **叠加**：属性型每次使用按牌面累加，没有“取最高 / 覆盖”；特性型同名特性可叠层（Q-094）。

## 4. 效果方向（数值待定，Q-074）

- 攻击、生命、毒性、成长、死亡触发。
- 存放容量待定（Q-072）。
