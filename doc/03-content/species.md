# 虫种系统（英雄层）

> 类比：杀戮尖塔的角色。
> 每个虫种 = **独特经济 + 1 个被动 + 2 个主动 + 专属兵种**（2026-11-09 定）。
> **2026-11-09：天赋系统暂缓**，虫种不再包含天赋树；三条构筑线由兵种 / 种子 / 战果 / 虫珀 / 巢穴扩建承载。
> **详细设计暂缓（2026-11-08）**：先保留方向，等核心系统稳定后再定稿。

## 1. 定位

- 开局选择（或局外解锁）。
- 虫种之间不是数值强弱，而是**玩法不同**。
- 换虫种 = 换一整套经济、兵种与节奏。

## 2. 结构模板

每个虫种必须定义：

1. 名称与主题
2. 起始资源 / 起始巢穴
3. 被动（**1 个**；经济或战斗）
4. 主动（**2 个**；每局有限次数）
5. **三条构筑方向**（同一虫种池内可分化、可混搭；不设开局选流派）
6. **专属兵种池**（12 个：一阶 4 / 二阶 5 / 三阶 3；见 `units.md` 4.0 / 5；每个兵种 1 个签名特性；阶级 = 巢穴等级 L1 / L2 / L3，Q-103）
7. 共享兵种池权重
8. 独特的胜利/失败条件（可选）
9. 上手难度（**统一为中等**，2026-11-09 定；不再按虫种分档）

## 3. 首版候选

> **当前设计对象：廪实**。3.1–3.5 是旧候选，命名与机制尚未按新规则重做，仅作参考。

### 3.0 廪实（首个设计中虫种）

- **名称 / 主题**：廪实；仓廪充实、以粮为纲的收获之族。
- **技能结构**：**1 个被动 + 2 个主动**（2026-11-09 定）。
- **流派骨架（2026-11-09，提案）**：三条方向各回答一个关于食物的不同问题；专属 12 个按 **4 / 4 / 4** 重排，每阶每条线至少 1 个。
  - **积廪 —— 粮是留着还是花掉？** 四件事各一个兵，不再有第五个「交 N 粮得 buff」：仓士（战外：粮 → 面板）、饷者（战外：面板 → 粮）、釜卒（战斗中：花粮换爆发）、实卒（战斗中：吃库存换被动）。仓士 / 饷者 是反向镜像，釜卒 / 实卒 是第二对。
  - **劝农 —— 粮从哪来？** 闭环是 产田 → 强田 → 保田 → 用田。现有 圃师（强田）、田正（保田），**缺 产田 与 用田 两个新兵**；植物一死整条线就塌，因为没有兵能让植物回来。
  - **守廪 —— 巢穴的血能不能当资源？** 一护一回两花：障卒（护：替友军承受，差额记完整度）、垒卒（回：每场战斗开始先手恢复完整度 2 点）、殉卒（花：扣完整度换战力）、镇廪（花：一次性大额爆发）。**花派单次消耗必须 ≤ 守廪一次回复（25%）**，否则是赌死；护派的意义是给花派攒钱。
  - **落位**：一阶 仓士 / 饷者 / 圃师 / 垒卒；二阶 釜卒 / 田正 / 产田（新） / 障卒 / 殉卒；三阶 实卒 / 用田（新） / 镇廪。
  - **代价**：廪尉、太仓 与釜卒同一声部，被挤出（是否砍掉待定，Q-126）。
  - 共享池已有 干城 / 悍卒 / 队正 兜住通用前排，专属兵不再重复做坦。

**被动：劝农**

- **开局 + 夏 / 秋 / 冬开始**，共 **4 次**种子三选一（2026-11-09 定）。
- 每次从 **3 颗种子中选 1 颗**；种子池包含**食物 / 战果 / 工具**三类，按当前进度与虫种权重抽取。
- **免费、不占三选一行动、可跳过**。
- 获得的种子沿用现有种子系统：进入待播种状态，播种规则见 Q-065。

**主动 1：开仓**

- **效果**：**催熟所有种子**——所有收获型种子立即完成当前周期并产出一次，之后计数器归零（2026-11-09 定）。
- 工具型种子是否受“催熟”影响待定（Q-092）。
- **冷却 6 回合**，与其他主动各自独立计时（2026-11-09 定）。

**主动 2：守廪**

- **效果**：立即恢复**最大巢穴完整度的 25%**（上限 100 时即 25 点），不能一次性回满（2026-11-09 定）。
- **冷却 6 回合**，与开仓各自独立计时（2026-11-09 定）。
- 恢复量是否受难度 / 虫珀影响待定。

**冷却加速**

- 部分虫珀可按**百分比减少冷却**，结果**四舍五入**（2026-11-09 定）；具体百分比由虫珀条目决定。
- 冷却从使用后开始计算；具体在回合开始还是结束时递减，待定。

- **起始资源 / 起始巢穴**：**保持默认开局**——L1、3 个肥沃格、1 颗基础食物种子、15 食物（2026-11-09 定）；不额外加种子或食物。
- **共享兵种池权重**：**均衡**，不偏向经济 / 防守 / 进攻；构筑方向交给种子、战果与玩家选择（2026-11-09 定）。
- **专属兵种池**：**12 个**（一阶 4 / 二阶 5 / 三阶 3）；名单已出提案——一阶 仓士 / 饷者 / 垒卒 / 圃师，二阶 廪尉 / 障卒 / 田正 / 釜卒 / 殉卒，三阶 太仓 / 镇廪 / 实卒（2026-11-09，Q-107；详见 `units.md` 5.0）。
- **上手难度**：**中等**（2026-11-09 起，所有虫种统一为中等；不再按虫种分档）。
- **定位**：稳定经济、可攻可守；适合熟悉基础系统后使用。

**玩法（提案，2026-11-09）**

> 粮就是血：田不能空、仓不能满。开仓把攒下的一轮收成立刻兑现，守廪把失误买回来；专属兵种大多在「把粮烧成战力」和「把粮存成身板」之间选边。

| 阶段 | 怎么打 |
|---|---|
| **开局** | 先把 3 块肥沃格种满——开局那次「劝农」优先拿食物种子。2 次免费招募先补前排（干城 / 垒卒）或经济位（采薇 / 饷者）；没有植物时不要拿圃师。15 食物留作播种与扩田周转，别急着喂仓士。 |
| **前期（春）** | 食物种子每 3 事件 +2，目标是把 3 田喂满、收入不断档。开仓不要顺手就开：等种子计数刚归零再开，等于白拿一整轮产出。守廪留给完整度见底的那一场，满血用掉最亏。 |
| **中期（夏秋）** | 攒巢穴经验扩到 L2（6 田），再按三条流派分叉。夏 / 秋开始的「劝农」按当前方向补种子：积廪补食物或战果，劝农补工具与植物。别为了多一颗田把招募费挤没。 |
| **后期（冬）** | 冬天守廪保完整度；积廪把存粮一次性换成太仓 / 实卒的爆发；劝农靠 9 田与植物滚到底。冬季食物消耗修正只作用在招募与修复上，存粮不会因为冬天变便宜。 |

**核心连招**

- 开仓 → 同一回合进招募组 / 交廪尉 / 太仓：把催熟出来的粮立刻变成战力。
- 饷者每场 2–3 食物 + 随机友军 +1.0 上限，长局里慢慢把干城 / 镇廪喂厚。
- 圃师 + 田正 + 植物三件套：存活植物同时给全队攻击与护盾，越拖越强。

**常见失误**

- 田空着不种——收入断档，后面所有计划都缺粮。
- 开仓在计数快满时用，白白浪费一轮。
- 前期把粮喂仓士，导致没钱扩田 / 招募，节奏直接停摆。
- 只烧粮不存粮：实卒和守廪体系都吃不上资源。

### 3.1 收获蚁（旧候选：平衡 / 新手）

- **被动：种子储备** — 每回合 +1 食物；（原"食物上限 +5"因取消上限而失效，待重做）。
- **主动：丰收** — 每 5 回合一次，立即 +8 食物。
- **专属兵种**：采集型 / 守卫型（旧占位，待按新规则重做）
- **定位**：稳定经济，适合教学与首局。

### 3.2 行军蚁（高压 / 进攻）

- **被动：无被动产出** — 不采集、不种田（是否享受基础粮仓待确认，见 Q-017）。
- **掠夺**：战斗胜利本回合 +4 食物，下回合 +2，之后消失。
- **饥饿**：连续 2 回合没有战斗胜利 → 攻击 −1，蚁后停止产卵。
- **代价**：每回合每 3 只行军蚁系单位额外 +1 食物消耗。
- **主动：全军突袭** — 本回合所有单位 +1 攻，下回合疲劳。
- **专属兵种**：突袭蚁（高攻低防）、行军锐士（冲锋）
- **定位**：必须打仗，断节奏就崩。

### 3.3 切叶蚁（后期 / 经济）

- **被动：真菌农场** — 食物产出每 3 回合 +1（有上限）；占格子（具体待定）。
- **主动：孢子爆发** — 消耗储备，瞬间产出大量食物。
- **专属兵种**：菌农蚁（产粮）、园丁蚁（加速幼虫成长）
- **定位**：慢热，后期滚雪球。

### 3.4 织叶蚁（机动 / 圈层）

- **被动：搭桥** — 在蚁穴圈层间移动消耗 −1（待重做，原依赖地表地图）。
- **主动：织网** — 连接两个格子，持续 2 回合（待重做）。
- **专属兵种**：开路型 / 工事型（旧占位，待按新规则重做）
- **定位**：控制圈层与路线（待重做）。

### 3.5 蜜罐蚁（储存 / 防守）

- **被动：储粮** — **待重做**（原"食物上限 +10"因取消上限而失效）；保留"储粮不腐 / 反刍"方向。
- **主动：反刍** — 把储粮转为即时食物。
- **专属兵种**：蜜罐蚁（储粮）、干城（高防）
- **定位**：龟缩过冬，打防守反击。

## 4. 局外解锁

- 首版解锁 1–2 个虫种；其余用"基因"解锁。
- 每个虫种有独立难度阶梯与成就。
- 局外只解锁**新可能性**（新虫种、新兵种、新事件），不直接加数值。
