# 蚁种系统（英雄层）

> 类比：杀戮尖塔的角色。
> 每个蚁种 = **独特经济 + 被动 + 主动 + 天赋树 + 专属兵种**。
> **详细设计暂缓（2026-11-08）**：先保留方向，等核心系统稳定后再定稿。

## 1. 定位

- 开局选择（或局外解锁）。
- 蚁种之间不是数值强弱，而是**玩法不同**。
- 换蚁种 = 换一整套经济、天赋、兵种与节奏。

## 2. 结构模板

每个蚁种必须定义：

1. 名称与主题
2. 起始资源 / 起始巢穴
3. 被动（经济或战斗）
4. 主动（每局有限次数）
5. **天赋树**（结构待定，见 `talent-trees.md`）
6. **专属兵种池**（2–4 个，见 `units.md`）
7. 共享兵种池权重
8. 独特的胜利/失败条件（可选）
9. 上手难度

## 3. 首版候选

### 3.1 收获蚁（平衡 / 新手）

- **被动：种子储备** — 每回合 +1 食物；（原"食物上限 +5"因取消上限而失效，待重做）。
- **主动：丰收** — 每 5 回合一次，立即 +8 食物。
- **天赋树**：储备 / 采集 / 防御
- **专属兵种**：收获工蚁（采集 +2）、种子守卫（高防）
- **定位**：稳定经济，适合教学与首局。

### 3.2 行军蚁（高压 / 进攻）

- **被动：无被动产出** — 不采集、不种田（是否享受基础粮仓待确认，见 Q-017）。
- **掠夺**：战斗胜利本回合 +4 食物，下回合 +2，之后消失。
- **饥饿**：连续 2 回合没有战斗胜利 → 攻击 −1，蚁后停止产卵。
- **代价**：每回合每 3 只行军蚁系单位额外 +1 食物消耗。
- **主动：全军突袭** — 本回合所有单位 +1 攻，下回合疲劳。
- **天赋树**：突袭 / 嗜血 / 机动
- **专属兵种**：突袭蚁（高攻低防）、行军兵蚁（冲锋）
- **定位**：必须打仗，断节奏就崩。

### 3.3 切叶蚁（后期 / 经济）

- **被动：真菌农场** — 食物产出每 3 回合 +1（有上限）；占格子（具体待定）。
- **主动：孢子爆发** — 消耗储备，瞬间产出大量食物。
- **天赋树**：真菌 / 共生 / 成长
- **专属兵种**：菌农蚁（产粮）、园丁蚁（加速幼虫成长）
- **定位**：慢热，后期滚雪球。

### 3.4 织叶蚁（机动 / 圈层）

- **被动：搭桥** — 在蚁穴圈层间移动消耗 −1（待重做，原依赖地表地图）。
- **主动：织网** — 连接两个格子，持续 2 回合（待重做）。
- **天赋树**：机动 / 工事 / 侦察（待重做）
- **专属兵种**：织工蚁（开路）、桥梁蚁（防御工事）
- **定位**：控制圈层与路线（待重做）。

### 3.5 蜜罐蚁（储存 / 防守）

- **被动：储粮** — **待重做**（原"食物上限 +10"因取消上限而失效）；保留"储粮不腐 / 反刍"方向。
- **主动：反刍** — 把储粮转为即时食物。
- **天赋树**：储存 / 防守 / 反哺
- **专属兵种**：蜜罐蚁（储粮）、守卫蚁（高防）
- **定位**：龟缩过冬，打防守反击。

## 4. 局外解锁

- 首版解锁 1–2 个蚁种；其余用"基因"解锁。
- 每个蚁种有独立难度阶梯与成就。
- 局外只解锁**新可能性**（新蚁种、新兵种、新事件），不直接加数值。
- **天赋树默认全部解锁**，局外不再锁天赋节点。
