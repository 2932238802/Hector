# 虫种系统（英雄层）

> 类比：杀戮尖塔的角色。
> 每个虫种 = **独特经济 + 1 个被动 + 2 个主动 + 专属兵种**（2026-11-09 定）。
> **2026-11-09：天赋系统暂缓**，虫种不再包含天赋树；三条构筑线由兵种 / 种子 / 战果 / 虫珀 / 巢穴扩建承载。
> **详细设计暂缓（2026-11-08）**：先保留方向，等核心系统稳定后再定稿。

## 1. 定位

- 开局选择（或局外解锁）。
- 虫种之间不是数值强弱，而是**玩法不同**。
- 换虫种 = 换一整套经济、兵种与节奏。

## 2. 结构模板

每个虫种必须定义：

1. 名称与主题
2. 起始资源 / 起始巢穴
3. 被动（**1 个**；经济或战斗）
4. 主动（**2 个**；每局有限次数）
5. **三条构筑方向**（同一虫种池内可分化、可混搭；不设开局选流派）
6. **专属兵种池**（12 个：一阶 4 / 二阶 5 / 三阶 3；见 `units.md` 4.0 / 5；每个兵种 1 个签名特性；阶级 = 巢穴等级 L2 / L3 / L4，Q-103）
7. 共享兵种池权重
8. 独特的胜利/失败条件（可选）
9. 上手难度（**统一为中等**，2026-11-09 定；不再按虫种分档）

## 3. 首版候选

> **当前设计对象：廪实**。3.1–3.5 是旧候选，命名与机制尚未按新规则重做，仅作参考。

### 3.0 廪实（首个设计中虫种）

- **名称 / 主题**：廪实；仓廪充实、以粮为纲的收获之族。
- **技能结构**：**1 个被动 + 2 个主动**（2026-11-09 定）。
- **三条构筑方向**（2026-11-09 确认）：
  - **积廪**：存粮 / 开仓，节奏型爆发。
  - **劝农**：扩田 / 加种子 / 缩周期，经济滚雪球。
  - **守廪**：修巢 / 防守植物 / 工蚁，消耗战。

**被动：劝农**

- **开局 + 夏 / 秋 / 冬开始**，共 **4 次**种子三选一（2026-11-09 定）。
- 每次从 **3 颗种子中选 1 颗**；种子池包含**食物 / 战果 / 工具**三类，按当前进度与虫种权重抽取。
- **免费、不占三选一行动、可跳过**。
- 获得的种子沿用现有种子系统：进入待播种状态，播种规则见 Q-065。

**主动 1：开仓**

- **效果**：**催熟所有种子**——所有收获型种子立即完成当前周期并产出一次，之后计数器归零（2026-11-09 定）。
- 工具型种子是否受“催熟”影响待定（Q-092）。
- **冷却 6 回合**，与其他主动各自独立计时（2026-11-09 定）。

**主动 2：守廪**

- **效果**：立即恢复**最大巢穴完整度的 25%**（上限 100 时即 25 点），不能一次性回满（2026-11-09 定）。
- **冷却 6 回合**，与开仓各自独立计时（2026-11-09 定）。
- 恢复量是否受难度 / 虫珀影响待定。

**冷却加速**

- 部分虫珀可按**百分比减少冷却**，结果**四舍五入**（2026-11-09 定）；具体百分比由虫珀条目决定。
- 冷却从使用后开始计算；具体在回合开始还是结束时递减，待定。

- **起始资源 / 起始巢穴**：**保持默认开局**——L2、3 个肥沃格、1 颗基础食物种子、15 食物（2026-11-09 定）；不额外加种子或食物。
- **共享兵种池权重**：**均衡**，不偏向经济 / 防守 / 进攻；构筑方向交给种子、战果与玩家选择（2026-11-09 定）。
- **专属兵种池**：**12 个**（一阶 4 / 二阶 5 / 三阶 3）；具体名单待设计，先做共享兵种（Q-107）。
- **上手难度**：**中等**（2026-11-09 起，所有虫种统一为中等；不再按虫种分档）。
- **定位**：稳定经济、可攻可守；适合熟悉基础系统后使用。

### 3.1 收获蚁（旧候选：平衡 / 新手）

- **被动：种子储备** — 每回合 +1 食物；（原"食物上限 +5"因取消上限而失效，待重做）。
- **主动：丰收** — 每 5 回合一次，立即 +8 食物。
- **专属兵种**：收获工蚁（采集 +2）、种子守卫（高防）
- **定位**：稳定经济，适合教学与首局。

### 3.2 行军蚁（高压 / 进攻）

- **被动：无被动产出** — 不采集、不种田（是否享受基础粮仓待确认，见 Q-017）。
- **掠夺**：战斗胜利本回合 +4 食物，下回合 +2，之后消失。
- **饥饿**：连续 2 回合没有战斗胜利 → 攻击 −1，蚁后停止产卵。
- **代价**：每回合每 3 只行军蚁系单位额外 +1 食物消耗。
- **主动：全军突袭** — 本回合所有单位 +1 攻，下回合疲劳。
- **专属兵种**：突袭蚁（高攻低防）、行军锐士（冲锋）
- **定位**：必须打仗，断节奏就崩。

### 3.3 切叶蚁（后期 / 经济）

- **被动：真菌农场** — 食物产出每 3 回合 +1（有上限）；占格子（具体待定）。
- **主动：孢子爆发** — 消耗储备，瞬间产出大量食物。
- **专属兵种**：菌农蚁（产粮）、园丁蚁（加速幼虫成长）
- **定位**：慢热，后期滚雪球。

### 3.4 织叶蚁（机动 / 圈层）

- **被动：搭桥** — 在蚁穴圈层间移动消耗 −1（待重做，原依赖地表地图）。
- **主动：织网** — 连接两个格子，持续 2 回合（待重做）。
- **专属兵种**：织工蚁（开路）、桥梁蚁（防御工事）
- **定位**：控制圈层与路线（待重做）。

### 3.5 蜜罐蚁（储存 / 防守）

- **被动：储粮** — **待重做**（原"食物上限 +10"因取消上限而失效）；保留"储粮不腐 / 反刍"方向。
- **主动：反刍** — 把储粮转为即时食物。
- **专属兵种**：蜜罐蚁（储粮）、干城（高防）
- **定位**：龟缩过冬，打防守反击。

## 4. 局外解锁

- 首版解锁 1–2 个虫种；其余用"基因"解锁。
- 每个虫种有独立难度阶梯与成就。
- 局外只解锁**新可能性**（新虫种、新兵种、新事件），不直接加数值。
- ~~**天赋树默认全部解锁**，局外不再锁天赋节点。~~（天赋暂缓，2026-11-09）
