# 事件系统 v0.3 —— 事件组

> 时间单位：**1 回合**（不绑定天数，详见 `time-and-seasons.md`）。
> 回合结束，玩家从 **N 个事件组**中选 **1 组**；N 默认 3，可到 5。
> 每组含 **4 个事件（A → B → C → D）**，按顺序结算；数量暂定 4。
> **选择事件组是本作最重要的策略决策之一。**

## 1. 核心结构

```
回合结束
  → 生成 N 个事件组（N = 3~5，默认 3）
  → 玩家选 1 组
  → 组内按 A → B → C → D 顺序结算
  → 进入下一回合
```

- 事件 A 结算完 → 点「准备就绪」→ 进入 B；依此类推，直到 D。

- 事件组数量不固定：3 选 1、4 选 1、5 选 1 都可能出现。
- 组数越多，选择空间越大，但也越容易"选择过载"。
- 组与组之间不是"难度不同"，而是**风险 / 收益 / 成长方向不同**。

## 2. 选择依据（核心策略）

玩家选组时，至少要综合三个要素：

| 要素 | 作用 |
|---|---|
| **巢穴完整度** | 当前扛不扛得住压力 |
| **季节** | 本季的事件池与灾害类型 |
| **巢穴位置** | 河边 / 人类房屋边 / 沙漠等，改变事件池与风险 |

### 2.1 巢穴完整度（单一数值）

- 用一个数代表巢穴健康，暂定 **0–100**。
- 受敌对昆虫、天敌、灾害、断粮影响而下降。
- 可花食物修复。
- 归零 = 本局失败。
- **不做复杂结构**，就一条"血条"。

> 命名待定：巢穴完整度 / 城墙生命值 / 巢穴生命值。

### 2.2 季节

- 不同季节有不同事件池与灾害。
- 例如雨季多洪水、旱季多干旱、寒潮前多低温。
- **季节特性**：
  - 春：冒险风险增加；敌对势力更强大；生产加速。
  - 夏：冒险回报更高；遇到敌对势力可能性更小；损失工蚁增加；生产减速；敌我伤害增加。
  - 秋：生产加速；击败敌对势力可能额外掉落。
  - 冬：食物消耗减少；敌我伤害降低；巢穴更容易受伤。
- **恶劣天气 / 气候会放大战斗食物损耗，也会增加冒险工蚁的牺牲**（Q-053）。
- 具体数值待定（Q-057）。

### 2.3 巢穴位置

- 开局决定：**河边 / 人类房屋边 / 沙漠 / 其他**。
- 位置影响：事件池、资源类型、天敌种类、灾害风险。
- 具体效果之后设计。

## 3. 事件类别

| 类别 | 作用 | 典型选项 | 是否带选择 |
|---|---|---|---|
| 敌对昆虫来访 | 压力 / 战利品 / 领土 | 迎战 / 谈判 / 回避 | 是 |
| 蚁群自我探索 | 成长：天赋 / 建筑 / 招募事件 | 定向选择 / 随机 / 研究 | 是 |
| 随机生物 | 变数：收留 / 吃掉 / 研究 | 收留 / 食用 / 观察 | 是 |
| 冒险探索 | 种子 / 资源 / 虫珀 / 风险（抽象，不做地图） | 深入 / 带回 / 放弃 | 是 |
| 天气事件 | 全局压力 / 预报 | 提前准备 / 硬扛 | 部分 |

## 4. 事件组生成规则

**硬规则**

1. 每组 4 个事件（A → B → C → D，暂定；数量是否固定见 Q-020）。
2. 组内类别不重复。
3. **每组至少 1 个"压力事件"**：敌对昆虫 / 天敌 / 恶劣天气。敌对势力基本不可避免，玩家可以选择打谁，但不能完全绕开（Q-056）。
4. 组与组之间至少 2 个事件类别不同，避免"换汤不换药"。
5. 组数 N 在 3–5 之间，按难度 / 阶段调整。

**软规则（按局势加权）**

- 季节临近灾害期 → 天气事件权重上升
- 巢穴完整度低 → 高压力组出现概率上升（逼玩家做取舍）
- 人口增长 → 生物 / 自我探索上升
- 食物紧张 → 冒险探索 / 生物（食物来源）上升
- 巢穴位置 → 对应事件池加权

## 5. 事件组画像

| 组型 | 构成 | 适合 |
|---|---|---|
| 成长组 | 自我探索 + 压力 + 生物/冒险探索 | 想变强、能扛压 |
| 开拓组 | 冒险探索 + 生物 + 压力 | 缺资源、想找新种子 |
| 压力组 | 天气 + 敌对 + 冒险探索/生物 | 想赌高收益、或被迫应对 |
| 休整组 | 自我探索 + 生物 + 低压力 | 巢穴完整度低时喘口气 |
| 豪赌组 | 高收益 + 高压力 + 双敌对 | 完整度高、想滚雪球 |

## 6. 组内结算

- 按顺序结算事件，每个事件展示选项。
- 事件之间**可以联动**：
  - 先遇到"受伤的甲虫"，再遇到"敌对昆虫"，可选择"放甲虫咬敌人"。
  - 先冒险带回种子，后续播种 / 收获效率提升。
- 联动通过标签 / 状态实现（如获得 `甲虫盟友` 状态），不硬编码。

## 7. 蚁群自我探索（成长核心）

每局主要成长通道，三种模式：

| 模式 | 做法 | 特点 |
|---|---|---|
| 定向 | 从 3 个天赋/兵种/建筑中选 1 | 可控，适合规划 |
| 随机 | 免费获得 1 个随机结果 | 省资源，赌运气 |
| 研究 | 花食物，把结果记入局外图鉴 | 长期收益，短期无战力 |

"定向 vs 随机"是每次都要做的取舍：**掌控感**还是**效率**。

- **招募由事件触发**，不在这里每回合固定出现（Q-068）。

## 8. 一个具体回合

**第 5 回合结束，生成 4 个事件组（4 选 1）：**

**A 组**：敌对昆虫来访 + 蚁群自我探索 + 随机生物 + 冒险探索
> 压力 + 成长 + 变数 + 种子。适合：想补强、且当前军力够打。

**B 组**：天气事件（暴雨预报） + 敌对昆虫来访 + 冒险探索 + 随机生物
> 双重压力 + 种子 + 变数。适合：想赌新种子，但要先扛过暴雨。

**C 组**：冒险探索 + 随机生物 + 敌对昆虫来访 + 蚁群自我探索
> 探索 + 变数 + 压力 + 成长。适合：缺食物、想找新种子。

**D 组**：蚁群自我探索 + 随机生物 + 冒险探索 + 低压力事件
> 休整 + 成长 + 种子。适合：巢穴完整度低，先回血。

玩家当前巢穴完整度 40，选 D 休整，而不是选高收益的 B。

## 9. 反馈与复盘

- 保留**事件组日志**：第几回合、出现了几组、分别是什么、选了什么、结果如何。
- 结算页标出 3 个关键事件组，回答"哪一次选择改变了这局"。
- 复盘不是感觉，而是有记录可查。
