# 事件系统 v0.5 —— 事件类别与事件组

> 时间单位：**1 回合**（不绑定天数，详见 `time-and-seasons.md`）。
> 回合结束，玩家从 **N 个事件组**中选 **1 组**；N 默认 3，可到 5。
> 每组含 **4 个事件（A → B → C → D）**，按顺序结算；固定 4 个。
> **选择事件组是本作最重要的策略决策之一。**

## 1. 核心结构

```
回合结束
  → 生成 N 个事件组（N = 3~5，默认 3）
  → 玩家选 1 组
  → 组内按 A → B → C → D 顺序结算
  → 进入下一回合
```

- 事件 A 结算完 → 点「准备就绪」→ 进入 B；依此类推，直到 D。

- 事件组数量不固定：3 选 1、4 选 1、5 选 1 都可能出现。
- 组数越多，选择空间越大，但也越容易"选择过载"。
- 组与组之间不是"难度不同"，而是**风险 / 收益 / 成长方向不同**。

## 2. 选择依据（核心策略）

玩家选组时，至少要综合三个要素：

| 要素 | 作用 |
|---|---|
| **巢穴完整度** | 当前扛不扛得住压力 |
| **季节** | 本季的事件池与灾害类型 |
| **巢穴位置** | 河边 / 人类房屋边 / 沙漠等，改变事件池与风险 |

### 2.1 巢穴完整度（单一数值）

- 用一个数代表巢穴健康，暂定 **0–100**。
- 受敌对昆虫、天敌、灾害、断粮影响而下降。
- 可花食物修复。
- 归零 = 本局失败。
- **不做复杂结构**，就一条"血条"。

> 命名待定：巢穴完整度 / 城墙生命值 / 巢穴生命值。

### 2.2 季节

- 不同季节有不同事件池与灾害。
- 例如雨季多洪水、旱季多干旱、寒潮前多低温。
- **季节特性**：
  - 春：探索风险增加；敌对势力更强大；生产加速。
  - 夏：探索回报更高；遇到敌对势力可能性更小；探索食物损失增加；生产减速；敌我伤害增加。
  - 秋：生产加速；击败敌对势力可能额外掉落。
  - 冬：食物消耗减少；敌我伤害降低；巢穴更容易受伤。
- **恶劣天气 / 气候会增加探索的食物损失**（Q-053）。
- **天气是回合级修正**：1 回合 = 1 个天气状态，同回合 A→D 四个事件共享；不是每个事件单独掷天气。
- 具体数值待定（Q-057）。

### 2.3 巢穴位置

- 开局决定：**河边 / 人类房屋边 / 沙漠 / 其他**。
- 位置影响：事件池、资源类型、天敌种类、灾害风险。
- 具体效果之后设计。

## 3. 事件类别（6 类）

| 类别 | 作用 | 典型选项 | 是否带选择 |
|---|---|---|---|
| **普通敌对势力** | 常规压力 / 战利品 / 领土 | 迎战 / 谈判 / 回避 | 是 |
| **强大敌对势力** | 高压 / 精英 / 稀有掉落 | 迎战 / 献食 / 绕行 | 是 |
| **探索** | 种子 / 食物 / 虫珀 / 食物损失（抽象，不做地图） | 深入 / 带回 / 放弃 | 是 |
| **意外随机事件** | 变数：生物 / 天气 / 灾害 / 机遇 | 收留 / 利用 / 规避 | 是 |
| **招募事件** | 补兵 / 换阵容 | 3 选 1 / 刷新 / 放弃 | 是 |
| **神秘遗迹** | 独特成长 / 虫珀 / 稀有种子 / 剧情 | 进入 / 研究 / 离开 | 是 |

> 灾害 / 极端天气不再单独成类，统一收进「意外随机事件」的子标签（生物 / 天气 / 灾害 / 机遇）。
> 是否保留灾害玩法、以及它的准备机制，见 Q-029。

## 4. 事件组模板（2026-11-09 提案 v2）

> 先定「一组由哪几类事件组成」，再往里填具体事件。
> 6 个类别对应 6 种模板；模板保证每组都有敌对势力，但不保证每场都打。

**硬规则**

1. 每组固定 4 个事件（A → B → C → D）。
2. 同一模板内同类事件**最多 2 个**，不出现 3 个同类。
3. **每组至少 1 个敌对势力**（普通或强大）——敌对不可避免；但敌对遭遇可以谈判或回避，不等于每场都打。
4. 同一轮提供的 N 组中，**不重复同一模板**。
5. 同一轮最多 **1 个危机组**、最多 **1 个含遗迹的模板**。
6. 每组最多 **1 个强大敌对**、**1 个神秘遗迹**、**1 次招募**。
7. N 默认 3；难度、虫珀、事件可提升到 4–5。

**软规则（按局势加权）**

- 巢穴完整度低 → 巡逻组 / 招募组权重上升；靠三选一「巢穴恢复」与随机事件回血，不设专门休整组。
- 食物紧张 → 远征组 / 探索事件权重上升。
- 食物宽裕 → 招募组 / 随机事件权重上升。
- 巢穴位置 → 对应事件池加权。
- 难度提高 → 强敌组 / 危机组权重上升，远征组 / 招募组下降。
- 季节 → 见 5.2 权重表。

## 5. 模板库（6 种）

| 模板 | 构成（4 事件） | 敌对 | 定位 |
|---|---|---|---|
| **巡逻组** | 普 + 探 + 随 + 随 | 1 普 | 日常：稳定压力 + 高变数 |
| **远征组** | 普 + 探 + 探 + 招 | 1 普 | 找种子 / 食物 + 补兵 |
| **强敌组** | 强 + 探 + 随 + 遗 | 1 强 | 高风险高回报 |
| **危机组** | 普 + 强 + 随 + 探 | 2 敌对 | 高压，赌掉落 |
| **遗迹组** | 普 + 遗 + 探 + 随 | 1 普 | 独特成长 / 虫珀 / 剧情 |
| **招募组** | 普 + 招 + 随 + 探 | 1 普 | 补兵 / 换阵容 |

> 图例：普 = 普通敌对势力；强 = 强大敌对势力；探 = 探索；随 = 意外随机事件；招 = 招募事件；遗 = 神秘遗迹。
> **没有完全安全的一组**：6 种模板全部至少 1 个敌对势力，只是可以谈判或回避。
> **“普 / 强”不等于强制手动战斗**：一组里的敌对格可能通过谈判、献食、绕行解决。
> **强敌必须可绕行**：强敌组默认给出“献食 / 绕行”选项，代价是食物或放弃掉落；否则只是数值卡点。
> **遗迹不是普通探索**：低频、独特奖励、可带事件链；不能当随机资源点用。
> **顺序可变**：表中从左到右是默认顺序；具体事件实例可覆盖为 2–3 种顺序变体，但敌对事件不能缺席。

## 5.1 一局的 96 格预算

> 24 回合 × 4 事件 = 96 次结算。下表是**目标分布**，不是硬性配额；
> 玩家每回合只从 3 组里选 1 组，实际比例会浮动。

| 事件类型 | 目标次数 | 占比 | 说明 |
|---|---|---|---|
| **普通敌对势力** | **20** | 20.83% | 可迎战 / 谈判 / 回避 |
| **强大敌对势力** | **6** | 6.25% | 约每季 1.5 次；必须可绕行 |
| **探索** | **29** | 30.21% | 种子 / 食物 / 虫珀 / 食物损失 |
| **意外随机事件** | **26** | 27.08% | 生物 / 天气 / 灾害 / 机遇 |
| **招募事件** | **8** | 8.33% | 约每 3 回合 1 次 |
| **神秘遗迹** | **7** | 7.29% | 约每 3–4 回合 1 次 |
| **合计** | **96** | 100% | |

> 此表用于**规划内容总量**；5.2.1 的期望值用于**校准权重**。两者已对齐。

**其中手动战斗：约 12–14 场。**

- 26 次敌对遭遇中约 **45–55%** 最终进入手动战斗；其余通过谈判、献食、绕行解决。
- 手动战斗约每 2 回合 1 场，单场 1–1.5 分钟，战斗总时长控制在 15–20 分钟。
- 危机组的双敌对可以只打一场、谈一场——这正是它的取舍点。

## 5.2 四季权重（提供池，非强制）

> 权重决定“抽到哪种模板”的概率，不决定玩家实际选什么。

| 季节 | 巡逻组 | 远征组 | 强敌组 | 危机组 | 遗迹组 | 招募组 |
|---|---|---|---|---|---|---|
| 春 | 35% | 20% | 15% | 10% | 10% | 10% |
| 夏 | 25% | 35% | 5% | 5% | 10% | 20% |
| 秋 | 30% | 20% | 10% | 5% | 20% | 15% |
| 冬 | 25% | 10% | 30% | 20% | 10% | 5% |

- 春：巡逻为主，强敌开始出现，稳定积累。
- 夏：远征最多、强敌最少、招募最多——用探索换资源与兵源。
- 秋：遗迹与招募偏高，探索仍高——成长窗口。
- 冬：强敌 + 危机最多，远征与招募收缩，生存压力最大；强敌组常带遗迹，遗迹总数也高。

### 5.2.1 初步验算（按四季权重平均、玩家随机选组）

| 类型 | 权重期望 / 局 | 96 格预算 | 差异 |
|---|---|---|---|
| 普通敌对势力 | 20.4 | 20 | +0.4 |
| 强大敌对势力 | 6.0 | 6 | 0 |
| 探索 | 29.1 | 29 | +0.1 |
| 意外随机事件 | 25.8 | 26 | −0.2 |
| 招募事件 | 8.1 | 8 | +0.1 |
| 神秘遗迹 | 6.6 | 7 | −0.4 |

- 偏差都在 0.5 以内，预算与权重已基本闭合。
- 实际玩家会偏向某类模板，偏差会重新出现；仍按实测校准（Q-082）。

### 5.2.2 每季事件类型期望（每季 24 格）

> 按四季权重、随机选组计算；实际会因玩家偏好浮动。

| 季节 | 普通敌对 | 强大敌对 | 探索 | 意外随机 | 招募 | 遗迹 | 合计 |
|---|---|---|---|---|---|---|---|
| 春 | 5.1 | 1.5 | 7.2 | 6.9 | 1.8 | 1.5 | 24 |
| 夏 | 5.7 | 0.6 | 8.1 | 5.4 | 3.3 | 0.9 | 24 |
| 秋 | 5.4 | 0.9 | 7.2 | 6.6 | 2.1 | 1.8 | 24 |
| 冬 | 4.2 | 3.0 | 6.6 | 6.9 | 0.9 | 2.4 | 24 |
| **全局 4 季** | **20.4** | **6.0** | **29.1** | **25.8** | **8.1** | **6.6** | **96** |

- 春：起步均衡，探索与随机为主。
- 夏：普通敌对、探索、招募三项最高，强敌最少——扩张窗口。
- 秋：强大敌对少，招募与遗迹偏高——成长窗口。
- 冬：强大敌对与遗迹最多，招募最少——生存压力最大。

## 5.3 生成流程（提案）

1. 按当前季节权重抽 **N 个不重复模板**。
2. 校验本轮最多 **1 个危机组**。
3. 校验本轮最多 **1 个含遗迹的模板**（强敌组 / 遗迹组）。
4. 按模板槽位抽具体事件；同一事件在连续 2 轮内不重复。
5. 应用巢穴位置、难度、虫珀与局势修正。
6. 生成 3 组供玩家选择；玩家选 1 组后进入 A → D。

**约束冲突时的退化顺序**

1. 先放宽“最多 1 个含遗迹的模板”，允许 2 个。
2. 再允许同一模板出现 2 次（但最多 2 次）。
3. 最后才允许危机组出现 2 个。
4. 任何情况下不减少到少于 3 组；组数不足时用当前季节权重重新抽。

## 5.4 内容量（初算）

- 96 次结算；每个事件最多复用 2 次。
- 首版建议 **60–77 个独立事件**，每个 2–3 个选项。

| 类别 | 96 格预算 | 建议独立事件数 |
|---|---|---|
| 普通敌对势力 | 20 | 12–16 |
| 强大敌对势力 | 6 | 5–7 |
| 探索 | 29 | 16–20 |
| 意外随机事件 | 26 | 16–20 |
| 招募事件 | 8 | 5–7 |
| 神秘遗迹 | 7 | 5–7 |
| **合计** | **96** | **59–77** |

- 意外随机事件内部再分 4 个子标签：生物 / 天气 / 灾害 / 机遇；每个子标签至少 4–5 个事件。
- 具体总量仍受 v1.0 范围约束（Q-003）。

## 6. 组内结算

- 按顺序结算事件，每个事件展示选项。
- 事件之间**可以联动**：
  - 先遇到"受伤的甲虫"，再遇到"敌对昆虫"，可选择"放甲虫咬敌人"。
  - 先探索带回种子，后续播种 / 收获效率提升。
- 联动通过标签 / 状态实现（如获得 `甲虫盟友` 状态），不硬编码。

## 7. 神秘遗迹（成长核心）

- 6 类事件里没有独立“成长”类别；成长主要来自**神秘遗迹**、虫珀与巢穴扩建。
- 遗迹是低频、独特事件：约 7 次/局，不做普通资源点。
- 每次遗迹提供三种处理方式：

| 方式 | 做法 | 特点 |
|---|---|---|
| 进入 | 承担战斗 / 解谜 / 食物损失，换取稀有奖励 | 高回报，高风险 |
| 研究 | 花食物，把结果记入局外图鉴 / 解锁情报 | 长期收益，短期无战力 |
| 离开 | 无风险，无收益 | 保守，保留资源 |

- “进入 vs 研究 vs 离开”是遗迹的核心取舍：**即时战力**、**长期解锁**、**保存资源**。
- **基础奖励：1 个普通虫珀。**
- **额外掷骰：有概率直接获得 1 个「诅咒虫珀」，不可拒绝。**
  - 诅咒虫珀 = 明确负面效果 +（建议）强力正面效果；不是普通虫珀的数值下位。
  - 因为强制塞给玩家，建议以“强正面 + 明确负面”为主，避免变成纯随机惩罚；也可以是纯负面但可净化（Q-088）。
  - 出现概率不固定，待测试；难度越高可略升。
- 遗迹奖励类型：普通虫珀 / 诅咒虫珀 / 稀有种子 / 兵种解锁 / 剧情碎片（Q-067 / Q-086）。
- 正式名：**虫珀**（2026-11-09 确认）。
- **天赋系统暂缓（2026-11-09）**，遗迹不再发放天赋点；如恢复天赋，再重议遗迹奖励。
- 招募由事件触发，不在这里固定出现（Q-068）。

## 8. 一个具体回合

**第 5 回合结束（春季），生成 3 个事件组（3 选 1）：**

**A 组｜巡逻组**：普 + 探 + 随 + 随
> 1 次普通敌对（可战可谈）、1 次探索、2 次意外随机。适合：想稳定推进、能接受变数。

**B 组｜强敌组**：强 + 探 + 随 + 遗
> 1 次强大敌对（可献食 / 绕行）、1 次探索、1 次随机、1 次遗迹。适合：军力够、想赌稀有掉落。

**C 组｜遗迹组**：普 + 遗 + 探 + 随
> 1 次普通敌对、1 次遗迹、1 次探索、1 次随机。适合：想拿成长，但不想碰强敌。

玩家当前巢穴完整度 40，选 A：三组都有敌对，A 的普通敌对可以谈判，强度最低但变数最多。
注意：没有完全安全的一组；C 也有普通敌对。

## 9. 反馈与复盘

- 保留**事件组日志**：第几回合、出现了几组、分别是什么、选了什么、结果如何。
- 结算页标出 3 个关键事件组，回答"哪一次选择改变了这局"。
- 复盘不是感觉，而是有记录可查。
