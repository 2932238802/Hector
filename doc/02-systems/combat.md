# 战斗系统（草案 v0.1，暂缓）

> **2026-11-08 再次暂缓。**
> 下面的 v0.1 方案是**草稿提案**，保留备查，不代表定稿。
> 等其它系统稳定后再回来设计。
> 原则：**不做独立战斗画面**；用"战前预测 + 派兵布阵 + 自动结算 + 战报"让玩家有迹可循。
> 战斗是**组合解谜**，不是纯数值对撞。

## 1. 设计目标

- 省略战斗画面：省美术、控时长，符合 15–40 分钟。
- 玩家能清楚看到：**部署、兵种、天赋、天气、虫珀各自起了什么作用**。
- 单场战斗结算 **< 10 秒**，不打断节奏。
- 强调 **combo 与克制**，让"精妙的组合"能被看见。

## 2. 流程

```
事件组中出现敌对事件
  → 战前情报：敌方组成 / 标签 / 地形 / 天气
  → 战前预测：胜率、关键克制、预计伤亡
  → 玩家派兵布阵（派谁 + 放哪个位置）
  → 自动结算
  → 战报：逐条归因
  → 结果：胜负 / 伤亡 / 战利品 / 巢穴完整度变化
```

## 3. 战前情报

- **敌方**：数量、兵种、标签（甲壳 / 飞行 / 群攻 / 毒 / 火 / 土）。
- **环境**：地形、天气、季节。
- **我方**：可用小队、人口、资源、已解锁兵种。

> 情报不是全知：未知敌人只显示部分标签，鼓励侦察蚁。

## 4. 派兵布阵

推荐 **3 槽位**，不做战棋网格：

| 槽位 | 定位 | 修正 |
|---|---|---|
| **前锋** | 先承伤、开路 | +攻 −防 |
| **中军** | 主力输出 | 无修正 |
| **后卫** | 支援 / 远程 / 撤退 | +防 −攻 |

- 每个槽位可放 1–3 支小队。
- 同一槽位的兵种会触发**组合技**。
- 玩家决定：派谁、放哪、留谁守家。

**备选方案**：不摆槽位，只选战术（冲锋 / 固守 / 包抄 / 消耗）。
→ 更简单，但"布阵感"弱，暂不推荐。

## 5. 结算公式（透明）

```
有效战力 = 基础战力
         × 标签克制
         × 阵型修正
         × 地形 / 天气
         × 天赋 / 虫珀
         × 随机浮动（0.9–1.1）
```

### 5.1 标签克制

| 敌方标签 | 被克制 | 克制 |
|---|---|---|
| 甲壳 | 爆炸 / 穿刺 | 普通攻击 |
| 飞行 | 网 / 风 | 地面近战 |
| 群攻 | 守卫 / 嘲讽 | 单体 |
| 毒 | 净化 / 火 | 轻甲 |
| 火 | 水 / 土 | 纤维系 |
| 土 | 飞行 / 穿刺 | 地面 |

### 5.2 组合技（combo）

| 组合 | 效果 |
|---|---|
| 守卫蚁 + 爆炸蚁 | 「诱爆」：守卫嘲讽聚怪，爆炸蚁范围翻倍 |
| 侦察蚁 + 突袭蚁 | 「先手」：第一波必先攻 |
| 蜜罐蚁 + 守卫蚁 | 「铁壁」：前排减伤，后排回血 |
| 织工蚁 + 采集蚁 | 「捷径」：战斗后资源采集 +1 |
| 行军蚁 + 任何 | 「嗜血」：击杀后下一波 +攻 |

> 组合技是玩家"看得见"的贡献点，战报必须高亮。

## 6. 战报（核心）

战斗结束后，逐条显示"谁起了作用"：

```
【战报 · 第 5 回合 · 暴雨】
敌方：6 只甲壳虫（甲壳）、2 只飞蚁（飞行）
我方：守卫蚁 ×2（前锋）、爆炸蚁 ×1（中军）、侦察蚁 ×1（后卫）

· 侦察蚁：提前发现伏兵，敌方先攻失效
· 守卫蚁：嘲讽 6 次，吸收 18 伤害
· 爆炸蚁：对甲壳目标伤害 ×2，击杀 4
· 组合技「诱爆」触发：爆炸范围翻倍
· 天气「暴雨」：敌方飞行单位 −2 战力
· 天赋「突袭」：第一波 +3 攻

结果：胜利
伤亡：守卫蚁 −1
战利品：+6 食物、+2 石头、虫珀「湿壳」
巢穴完整度：−0
```

- 战报按**贡献从高到低**排序。
- 克制、combo、天气、天赋、虫珀分别标注。
- 战报可回看，作为复盘依据。

## 7. 为什么能"有迹可循"

1. **战前预测**：决策有依据，不是盲打。
2. **战报归因**：结果可解释，知道输在哪。
3. **combo 高亮**：玩家看到自己的组合真的生效。
4. **复盘**：关键战斗可回看，失败原因明确。

## 8. 省略战斗画面的表现

- 不切场景，在事件面板内完成。
- 可选 **2–3 秒"推演条"**：双方战力条对冲，纯视觉反馈，不是必须。
- 战报用列表 / 时间线呈现，代替战斗动画。

## 9. 与其他系统的咬合

| 系统 | 作用 |
|---|---|
| 兵种标签 | 决定克制关系 |
| 天赋 | 改规则、加 combo、加修正 |
| 天气 / 季节 | 全局修正 |
| 虫珀 | 被动加成 / 特殊规则 |
| 巢穴完整度 | 战斗失败时扣减 |
| 资源 | 战利品 |
| 侦察蚁 | 解锁更多战前情报 |
