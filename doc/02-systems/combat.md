# 战斗系统（初稿 v0.3）

> 2026-11-08 用户初稿。
> 层级：**季节（大回合）→ 小回合（事件组，进度条）→ 事件（最小进度单元）**。
> 不做独立战斗画面；战斗在事件组面板内完成。

## 1. 层级与推进

```
季节（大回合）
  → 小回合（事件组，进度条）
      → 事件 A（最小进度单元）
      → 事件 B
      → 事件 C
      → 事件 D
  → 回合奖励
  → 下一小回合
```

- 每个事件 = 进度条上的一格。
- 点击 **「准备就绪」** → 结算当前事件 → 旗帜前进一格 → 进入下一个事件。
- 即：A 结算完 → 准备就绪 → 进入 B；B 结算完 → 准备就绪 → 进入 C；依此类推。
- 事件组结束后 → 回合奖励 → 下一小回合。
- 10 个小回合（回合）= 1 个季节（大回合）。

## 1.1 战斗发生地

- **蚁穴内**：经营、生产、孵化、防御准备。
- **蚁穴外**：默认的战斗发生地（巢穴入口 / 外围战场）。
- 战斗失败 → **巢穴完整度下降**；敌人突破到巢穴。
- **士兵不会因战斗消失，也不会饿死**：失败 → 士兵返场，损失的是巢穴完整度。
- **战斗会损耗食物**：每个出场单位按兵种消耗食物；下雨等恶劣天气会放大（Q-052 / Q-053）。
- 战斗胜利 → 默认不伤巢穴健康；奖励待定。
- 蚁穴内的环境布置如何影响蚁穴外的战斗，待确认（Q-033）。

## 2. 为什么需要「准备就绪」

准备阶段按事件类型不同：

| 事件类型 | 准备内容 |
|---|---|
| 天气事件 | 外围建立防护、内层保暖、通风等 |
| 敌对势力 | 兵种排放（前排 / 后排） |
| 其他事件 | 待定 |

- 时间不会自动走；玩家准备好再点。
- 这样玩家能看清每一步，也能复盘。

## 3. 前排 / 后排

| 排 | 容量 | 作用 |
|---|---|---|
| 前排 | **5 只** | 承伤、近战、阻挡 |
| 后排 | **4 只** | 输出、支援、远程 |

- 只有两排，不做三排 / 网格。
- **工蚁不能出战**，9 格只放兵种。
- 9 格是**上限**；早期填不满，空位允许。
- 准备阶段可以调整前后排。

## 4. 单位与行动点

- 每个兵种有对应的**行动点（AP）**和**行为**。
- 行为花费行动点，例如：攻击、防御、技能、移动。
- **战斗保持手动 AP**（2026-11-08 确定）；不做自动结算。
- 具体 AP 数值、行为列表、每场可用次数待定。

### 4.1 战斗道具（战粮）

- 生产单位除普通食物外，还会生产**给士兵增加属性的食物**（暂称“战粮”）。
- 战粮存放在**道具栏**（平面列表，不做背包网格）；战斗中可以消耗使用。
- 使用时机、是否消耗 AP、每场次数、效果类型待定（Q-071 ~ Q-074）。

## 5. 战斗结算（敌对势力）

- **玩家回合**：我方单位消耗行动点，行动 / 攻击；可使用**战粮**。
- **敌方回合**：敌方 AI 对我方发起攻击。
- **攻击是单向的**：我方攻击不对自己造成伤害；只有敌方回合才对我方造成伤害。
- 参考《月圆之夜》联机模式 / 《炉石传说》酒馆战棋的交替攻击节奏（仅参考，不照搬）。
- **推进规则**：当前事件结算完 → 点「准备就绪」→ 进入下一个事件（A → B → C → D）。战斗内部无论打几轮，都**不占用进度条**；进度条只表示事件。
- 胜负、战斗轮次待定。
- 无论胜负，战斗都会损耗食物：每个出场单位按兵种计算（Q-052）；这是“士兵不消失”的替代代价，下雨等恶劣天气会放大（Q-053）。

### 5.1 目标规则

- 敌人**优先攻击前排**。
- 具体目标选择、AOE、越过前排的条件待定（Q-030）。

### 5.2 关键词命名（候选，待确认）

> 不使用通用卡牌关键词名；全部改用蚁穴语汇。

| 旧名（不用） | 新名 | 规则 |
|---|---|---|
| 嘲讽 | **扼守** | 敌方必须优先攻击此单位 |
| 先手 | **先遣** | 结算顺序中先行动 / 先攻击 |
| 遗言 | **遗讯** | 死亡时触发一次效果 |
| 疯狂 | **负伤** | 受到伤害后触发一次效果 |
| 战斗成长 | **战蜕** | 战斗中满足条件时获得属性成长 |

- 命名原则：2 字为主；取自蚁穴、身体、信息素语汇；避免通用卡牌术语。
- 后续关键词（冲锋 / 圣盾 / 剧毒 / 复生等）按同一原则命名，待定。
- 正式采用哪套命名见 Q-034。

### 5.3 季节与天气修正

| 来源 | 战斗影响 |
|---|---|
| 春 | 敌对势力更强大 |
| 夏 | 敌我受到伤害增加一定百分比；遇到敌对势力可能性更小 |
| 秋 | 击败敌对势力可能额外掉落 |
| 冬 | 敌我伤害降低；巢穴更容易受伤 |
| 下雨 | 战斗食物损耗 ×1.5（暂定） |
| 多云 | 无额外加成 |
| 晴天 | 正向加成（具体待定） |

- 具体数值与叠加方式待定（Q-057 / Q-058）。
- 冬季“巢穴更容易受伤”覆盖哪些伤害来源待定（Q-059）。

## 6. 天气事件（非战斗）

- 准备阶段：外围防护、内层保暖、通风等。
- **全部在蚁穴内部完成**：外围圈层仍属于蚁穴内部，不是地表；相当于把生产 / 防御搬进蚁穴内。
- 外围防护落在外围圈层格子；内层保暖 / 通风的具体落点待细化（内圈格子或设施）。
- 用"准备项"对抗天气强度。
- 具体机制、判定、失败后果待定。

## 7. 环境布置（待重做）

- 外圈格现在统一用于**播种**（见 `nest-honeycomb.md`）。
- 原有的“在地势格上布置防护 / 陷阱 / 工事”是否保留、是否与种子共格，待定（Q-070）。
- 战斗默认在蚁穴外；环境布置与蚁穴外战斗如何衔接仍待定（Q-033）。
- 具体可布置项、消耗、上限待定。

## 8. 进度条

- 事件组级进度条。
- 每个事件一格。
- 点击「准备就绪」→ 旗帜前进一格。
- 不做细粒度时间刻度。
- 视觉表现待定。

## 9. 回合奖励

- 事件组结束后发放。
- 内容待定：食物 / 石头 / 纤维、虫珀、天赋点、兵种、巢穴完整度恢复等。
- 是否与事件结果挂钩（打得好奖励多）待定。

## 10. 补充建议（可选，未确认）

- 事件组结束后给一份简短**战报**，作为复盘依据。
- 战报只做总结，不替代准备 / 推进的操作感。
