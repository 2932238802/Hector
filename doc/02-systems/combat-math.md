# 战斗数学 v0（2026-11-09 提案）

> 目的：给所有兵种、敌人、技能一个共同的数值底座，避免每个条目各自"待平衡"。
> 本文只定**数值 / 状态两层、伤害公式、结算顺序、分档与目标节奏**；具体敌人条目放 `enemies.md`（未建），兵种数值以 `03-content/units.md` 为准。
> 所有数字是 **v0 提案**，等第一次 24 回合模拟 / 样例战报后再校准（Q-115）。

## 1. 战斗只有两层：数值与状态

- **数值**：HP / 攻击 / 行动点 / 护盾。都是可加减的数字，可用 1 位小数。
- **状态**：挂在单位身上的临时标记，**只通过修改数值起作用**（例：「削弱」= 造成的攻击 ×50%）。
- **没有「减伤」这一概念**（2026-11-09 定）：任何"少受伤害"都必须落成 **护盾（数值）** 或 **削弱攻击方（状态）**，不存在"受到伤害 −X / −X%"。
- **删除「防御」与「速度」属性**（2026-11-09 定）：兵种表里的"防御：待定""速度：待定"全部作废；速度不影响行动顺序（顺序由玩家自选）。

### 1.1 数值

| 数值 | 说明 |
|---|---|
| **生命 HP** | 唯一的生存资源 |
| **攻击** | 伤害基数；可被状态修正 |
| **行动点** | 默认 **1**；技能 / 虫珀 / 特性可提高（Q-028） |
| **护盾** | 一个数字池，先于 HP 被消耗；不叠加时取较高值，具体规则见来源条目 |

- 护盾是**数值**，不是状态；有来源才有（如干城的每轮护盾），用完即清零。
- **护盾只能在战斗内获得（2026-11-09 定）**：触发点必须在战斗轮次内（如每轮玩家阶段开始）。**布阵阶段 / 战斗开始前不能预先加护盾**，战斗外（巢穴、事件、种子、虫珀、虫种技能）也不能加。
- 护盾**不跨战斗保留**：本场结束即消失，战后不结算、不带入下一场。
- 多个护盾来源如何合并待定（Q-111）。

### 1.2 状态（初版）

| 状态 | 作用 | 时长 |
|---|---|---|
| **削弱** | 该单位**造成的攻击 ×50%**，**不随层数变化** | 每层 = 1 轮；每次施加 +1 层，每轮结束 −1 层，0 层移除（Q-117） |

- 状态**只改数值**：削弱改的是"攻击"，不改"最终伤害"，也不参与伤害公式之外的计算。
- 状态分两类：**数值修正型**（当前只有削弱）与**伤害型**（毒等，具体待定）。框架参考《杀戮尖塔》的机制，只借机制、不用其名称 / 文案。
- **同名多层不叠加效果**：削弱叠到多少层都只有 ×50%；层数只延长持续时间（每轮 −1 层）。

## 2. 伤害公式

```
攻击值 = 基础攻击 × 状态修正（如：削弱 ×0.5）
伤害   = 攻击值 × 技能倍率 × 浮动(0.90 ~ 1.10)
```

- 普攻倍率 = **1.0**；技能倍率按条目写死（例：焚卒爆炸 = 0.5）。
- 浮动按**每个目标**独立掷点：同一次 AOE 打多个目标，各自伤害可以不同。
- 结果保留 1 位小数，**最小 0.1**（避免出现 0 伤害卡住流程）。
- 双方通用，敌方攻击同样按此公式。

## 3. 结算顺序

1. 计算**攻击值**（套用状态，如削弱）
2. × 技能倍率 × 浮动 → **伤害**
3. **护盾抵扣**（护盾还有余量时不扣 HP）
4. 扣 HP
5. **「失去生命」类触发**（干城「受伤成长」等兵种自带效果）
6. HP ≤ 0 → **死亡**
7. **死亡触发**（不灭 → 不甘）
8. **击杀方触发**（兵种自带的击杀效果）

- 被护盾吸收的部分**不算失去生命**，不触发第 5 步。
- 一次伤害只结算一次"失去生命"；多段伤害按段分别结算。

## 4. 战斗轮数与时长

| 项 | v0 |
|---|---|
| 目标轮数 | **3–4 轮**结束 |
| 偏慢警戒 | 第 5 轮 |
| 最终裁决 | **第 6 轮结束仍未分胜负** |
| 单场时长 | 1.5–2 分钟 |
| 全场次 | 12–14 场 → **18–28 分钟** |

- 单局总预算 **45–60 分钟**（2026-11-09 定）；战斗约占三分之一，其余给 96 次事件结算与经营。
- `events.md` 里"战斗总时长 15–20 分钟"是按更短轮数估的，落地后按 3–4 轮实际会到 18–28 分钟，两者需统一（Q-115）。

### 4.1 战后状态（2026-11-09 定）

- 每场战斗结束，所有参战单位 HP **一律回满**——**包括本场阵亡、战后返场的单位**。
- HP **不跨场累积**，不需要战后治疗；下一场按当前最大生命满血开场。
- 干城「受伤成长」提高的是**最大生命**，所以它每场都是以"最新上限"满血开打。
- 耐久因此是可预期的：数值表里的 HP 就是每场能承受的总伤害，不需要再算"残血进下一场"。

## 5. 敌人分档（v0）

| 敌人阶级 | HP | 攻击 | 出现 |
|---|---|---|---|
| 一阶 | **4.0–8.0** | **1.5–2.5** | 春、夏 |
| 二阶 | **8.0–12.0** | **2.5–3.5** | 秋 |
| 三阶 | **12.0–18.0** | **3.0–4.5** | 冬 |
| 强敌（精英 / 强敌遭遇） | 同阶 **+20%–40%** | 同阶 **+20%–40%** | 全季，低概率 |

- 敌人数量：早期 **3–4 个**，中期 **4–5 个**，后期 **5–7 个**（受 7 格上限约束）。
- 敌人是否遵守前 4 / 后 3 阵型、是否总是满编，待定（与 Q-077 一起）。

## 6. 输出与耐久校验

### 6.1 早期（4 人队，无成长）

| 项 | 数值 |
|---|---|
| 我方每轮输出 | 锐士 3.0 + 弩手 3.0 + 斥候 2.0 + 采薇 1.5 ≈ **9.5**（连射期望 → ≈10.8） |
| 敌方总 HP | 4 × 6.0 = **24** |
| 清场轮数 | ≈ **2.5 轮** |
| 敌方每轮输出 | 4 × 2.0 = **8**（随敌人减员递减） |
| 我方前排 HP | 锐士 10 + 采薇 6 = **16** |
| 前线撑住 | 累计受伤 8 + 6 + 4 ≈ 18，≈ **3 轮** |

→ 早期 2–3 轮结束，偏"快打快杀"，符合目标。

### 6.2 后期（6–7 人队，锐士成长到攻击 5.0）

| 项 | 数值 |
|---|---|
| 我方每轮输出 | ≈ **18–20**（含连射） |
| 敌方总 HP | 6 × 15 = **90** |
| 清场轮数 | ≈ **4.5 轮** |
| 敌方每轮输出 | 6 × 3.5 = 21，减员后 17.5 / 14 / 10.5 … |
| 我方前排 HP | 干城 25 + 锐士 10 + 其他 ≈ **50–55** |
| 前线累计承受 | 4 轮内 ≈ **52–56** |

→ 后期**偏紧**：双方几乎同时见底，胜负取决于战果、植物、成长与技能。这是有意的难度上升；若实测过紧，优先下调三阶攻击下限，而不是加高兵种 HP。

### 6.3 兵种在体系中的位置（当前已定稿 6 个）

| 兵种 | HP | 攻击 | 期望每轮输出 | 备注 |
|---|---|---|---|---|
| 锐士 | 10.0 | 3.0 | 3.0 起，随战斗线性上涨 | 成长分摊到长战斗 |
| 干城 | 16.0 | 1.0 | 1.0 | 耐久位，不吃输出 |
| 斥候 | 7.0 | 2.0 | 2.0 | 低血，靠不甘换战果 |
| 采薇 | 6.0 | 1.5 | 1.5 | 低输出，结算位 |
| 焚卒 | 8.0 | 2.0 | 2.0 + 一次爆发（攻击 ×50% × 目标数） | 一次性 |
| 弩手 | 6.0 | 3.0 | **≈4.3**（1.43 次攻击） | 概率输出的期望值 |

> 表内数值来自 `03-content/units.md`；这里只看它们在同一个 DPS 轴上是否拉开差异。

## 7. 这个版本**没有**解决的事

- 敌人数值只是区间，没有具体敌人条目（`enemies.md` 未建）。
- 技能倍率体系未定：现在只有普攻 1.0 与焚卒 0.5 两个点。
- 战果的数值投放量未定：加攻击 +1 与加 HP +2 在哪个价位，要等经济侧。
- 状态表只定义了「削弱」；伤害型状态（毒等）的具体条目与数值未定（Q-117）。
- 治疗 / 回复：HP 每场重置后，v1 是否需要战斗内回血待定（Q-116）。
- 季节 / 天气倍率（Q-057 / Q-058）如何乘进公式，未定。
