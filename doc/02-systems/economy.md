# 经济系统 v0.2（草案）

> 时间尺度：**1 回合 = 3 天**（待确认，见 `time-and-seasons.md`）。
> 目标：**多资源约束 + 探索解锁**，让"限制中找最优解"更立体。
> 所有数值为首版占位，待平衡。

## 1. 资源种类

不做统一货币，资源各有用途：

| 资源 | 主要用途 |
|---|---|
| **食物** | 养蚁后、孵化、维持、修复巢穴 |
| **石头** | 建筑、防御工事、重甲兵种 |
| **植物纤维** | 建筑、轻甲兵种、侦察/织叶类 |
| （可选）水 / 树脂 / 孢子 | 后续按地形扩展 |

- 食物仍是**生存主线**，石头/纤维是**发展线**。
- 三种资源就够撑起取舍，暂不继续加。

## 2. 资源获取

| 资源 | 来源 |
|---|---|
| 食物 | 基础粮仓、采集、农场、战利品 |
| 石头 | 矿点、巢穴挖掘、地表探索 |
| 植物纤维 | 地表采集、特定地形、事件 |
| 稀有材料 | 探索新地形 / 击败强敌 / 中立交易 |

- 探索**新地形**会解锁新的资源点与材料。
- 材料本身也是"兵种解锁条件"。

## 3. 兵种招募与资源强相关

- 每个兵种有**资源配方**，不只是食物。
- 例（占位）：

| 兵种 | 配方 |
|---|---|
| 工蚁 | 3 食物 |
| 兵蚁 | 5 食物 + 2 石头 |
| 侦察蚁 | 3 食物 + 1 纤维 |
| 守卫蚁 | 5 食物 + 2 石头 |
| 爆炸蚁 | 4 食物 + 1 纤维 |

- 材料不足 → 该兵种**不进入招募候选**，或显示为"不可招募"。
- 这让"先采石头还是先采纤维"成为每局要做的决策。

## 4. 探索解锁新兵种

- 招募池不是一开始全开。
- 玩家探索到**新地形 / 新材料**后，对应兵种才有机会"刷出"。
- 例：
  - 发现"黏土坑" → 解锁需要黏土的建筑/兵种
  - 发现"树脂树" → 解锁树脂相关兵种
  - 发现"地下菌床" → 解锁真菌类兵种
- 因此**探索是招募的前置**，不是可选支线。

## 5. 维持

统一喂蚁后，不追踪每只蚂蚁的饥饿：

```
每回合食物消耗 = 1（蚁后基础） + ceil(当前人口 / 5)
```

- 食物不足：先饿死工蚁，再饿死兵蚁；蚁后停止产卵。
- 人口本身就是成本，扩张必须有收入支撑。

## 6. 一次性支出

| 项目 | 食物 | 石头 | 纤维 |
|---|---|---|---|
| 孵化工蚁 | 3 | — | — |
| 孵化兵蚁 | 5 | 2 | — |
| 孵化特殊蚁 | 6–8 | 2–4 | 1–3 |
| 挖一格 / 造房间 | 2–5 | 1–3 | 1–2 |
| 升级房间 | 4–8 | 3–6 | 2–4 |
| 修复巢穴完整度 | 按点数计 | — | — |

> 数值全是占位。

## 7. 无上限储存

- **食物、石头、纤维、虫珀、物品均不设上限**（2026-11-08 确定）。
- 不做"超过上限浪费"。
- 冬季前可自由囤粮，储备多少由玩家自己判断。
- 蜜罐蚁原"上限 +5/+10"因此失效，需要重做被动（见 Q-017）。

## 8. 节奏目标

- 前 5 分钟：玩家面对"先造工蚁还是先造兵蚁"的选择。
- 中期：单一食物不够，必须分兵去采石头/纤维。
- 后期：探索解锁的新兵种 + 囤积资源，准备终局。

## 9. 反馈与复盘

每回合结算显示：

- 食物 / 石头 / 纤维的收入与消耗明细
- 净变化
- 下回合预测
- 因材料不足而"未解锁"的兵种提示
