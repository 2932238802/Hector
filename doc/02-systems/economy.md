# 经济系统 v0.3（草案）

> 时间单位：**1 回合**（不绑定天数，见 `time-and-seasons.md`）。
> 目标：**单一硬通货下的取舍**——每一份食物都在抢同一批去向。
> 2026-11-09 定：**只保留食物一种基础资源**，取消石头 / 植物纤维。
> 所有数值为首版占位，待平衡。

## 1. 资源种类

**食物是唯一的基础资源。**

| 资源 | 用途 |
|---|---|
| **食物** | 招募、播种、修复巢穴、巢穴扩建 |
| **战果** | 食物派生的战斗道具（法术卡式），由生产单位产出，存道具栏；可直接加属性或挂 buff（Q-071 ~ Q-074 / Q-094） |

- 不做石头 / 纤维，也不做“材料”这一中间层。
- 理由：三种资源只是把同一份预算拆成三栏记账，没有产生新的决策类型；
  单一食物能让“现在吃 / 现在补兵 / 现在投资”变成直接冲突。
- 复杂度的出口放在**兵种、种子、虫珀、事件**上，而不是多币种。

## 1.5 开局状态（2026-11-09 定）

| 项目 | 初始值 |
|---|---|
| 巢穴等级 | **L1**（7 格，其中 3 个肥沃格） |
| 食物 | **15** |
| 种子 | **1 颗基础食物型种子** |
| 已解锁兵种 | 共享池基础项（待定） |

- 开局第一回合就有真实选择：播种、冒险、扩建或恢复。
- 不存在“必须先扩建才能生产”的强制开场。
- 起始种子按**基础食物型**：3 事件产出 2 食物（提案 v1）。

## 2. 资源获取

| 来源 | 说明 |
|---|---|
| **收获型种子（生产单位）** | 主要来源；播在肥沃格后每 N 个事件产出一次（Q-064 / Q-069） |
| **冒险** | 食物、虫珀、种子；风险由随机事件决定（Q-039） |
| **事件 / 战利品** | 击败敌对势力、完成事件组的奖励 |
| **商人** | 用食物交换虫珀 / 种子 / 招募机会（Q-068） |

- 不存在地表采集地图：食物来自**蚁穴内播种的收获型种子**。
- 冒险带回**新种子**会解锁新的生产单位与兵种。

## 2.4 生产单位与周期

- **生产单位 = 播种后的收获型种子**（2026-11-09 确定）；不另设建筑 / 设施。
- 每个收获型种子占 1 个**肥沃格**；肥沃格累计 3 / 6 / 9（见 `nest-honeycomb.md`）。
- **周期的最小时间单位 = 事件**；每个种子每 N 个事件产出一次，N 由种子类型决定。
- **主要取舍轴 = 产出大类**（2026-11-09 定）：食物 / 战果 / 工具；不是“快产 vs 慢产”。
- 同类型种子共享基础周期与产出预算；稀有变体只做小幅偏移，不做全面上位。

### 2.4.1 种子产出大类（2026-11-09 定，提案 v1）

> 术语：**种子**是播种后的生产单位；**果实**是它周期性产出的东西。
> 食物与战果以果实形式收获；工具种子可以产工具果实，也可以维持一个持续效果。

| 大类 | 产出 | 例子 | 经济角色 |
|---|---|---|---|
| **食物型** | 食物果实 | 基础谷种、丰产块根 | 主收入；数量决定其它种子能开多少 |
| **战果型** | 战果 | 树脂、毒液、甲壳 | 给兵种加属性 / 挂 buff / 战斗消耗；不直接产粮 |
| **工具型** | 工具果实或持续效果 | 愈合菌圃（恢复巢穴健康）、共生藤（增益其它种子）、羁绊型种子（组合增益，首批待定）、荆棘防线（战斗植物，不额外占格） | 用食物机会成本换功能 |

首版数值只定食物与战果；工具种子效果待定（Q-092 ~ Q-094）。

| 种子 | 周期 N（事件） | 每次产出 | 备注 |
|---|---|---|---|
| 食物型（基础） | 3 | 2 食物 | 经济主力 |
| 食物型（丰产） | 5 | 4 食物 | 空窗更长，前期不宜 |
| 战果型 | 3 | 1 份战果 | 每周期少 2 食物 |
| 工具型 | 待定 | 恢复 / 增益 / 羁绊 / 战斗植物 | 不直接产粮 |

- **食物型是主轴**：食物型种子的数量决定其它种子能开多少。
- **战果型 / 工具型用食物机会成本换收益**：每换掉 1 块食物田，按基础食物型计，约少 0.67 食物/事件。
- **羁绊**：指定种子组合在相邻肥沃格（共边，含同圈 / 跨圈）激活；**不是纯被动经济加成**，效果需结合植物 / 兵种 / 虫种特性，具体暂缓（Q-093 / Q-096）。
- 一局种子获取量建议控制在 **6–8 颗**（Q-067），避免 9 田全食物把紧经济冲垮。

> **全季口径（2026-11-11 校准）**：Q-067 限定一局 6–8 颗种子，其中食物型约 2–3 颗；加上开局 1 颗，**全季平均食物田按 3 块估**（旧基线按 5 块，明显高估收入）。切片按 1 → 2 → 3 块递进估；8.5 的基线据此重算。

### 2.4.2 生产结算（提案，Q-045）

- 种子播种后计数器从 0 开始；**每结算 1 个事件 +1**，达到 N 时在**该事件结算结束时**产出，然后归零。
- 播种窗口内种下的种子，从**下一个事件**开始计数。
- 多颗种子同事件成熟时**同时结算**，不额外占行动。
- 工具种子可以是**周期性触发**（每 N 事件一次）或**持续光环**，具体由种子条目决定（Q-092）。
- 回合开始的收入汇报只显示**本回合预计产出**；实际入账在事件结算时。
- 季节修正作用在**产量**上，不改 N，避免出现小数周期（具体数值 Q-057）。
- 种子能否升级 / 移除 / 替换待定（Q-065）。

## 2.5 回合收入

- **回合开始做收入汇报**：食物的产出与消耗。
- 收入只来自收获型种子；**没有人口 / 工蚁层**（2026-11-09 删除工蚁系统，Q-025）。
- 收入公式待定（Q-040）。

## 2.6 收入的主要去向（主观行动）

| 方向 | 做什么 | 风险 / 代价 | 收益 |
|---|---|---|---|
| **冒险** | 周边探索 | 消耗食物（数量由随机事件决定，恶劣天气与寄生虫会放大损失）；可能遇敌对势力 | 食物、虫珀、**种子** |
| **巢穴恢复** | 主动修复巢穴完整度 | 消耗食物 | 巢穴健康回升；**唯一可主动选择的修复行动**（战斗内另有守廪 / 堞垒蚁的少量回复） |
| **巢穴扩建** | 扩大巢穴，开放新的肥沃格 | **巢穴经验达到阈值**；食物可兑换经验 | 播种位增加（3 / 6 / 9）；额外基地空间；解锁植物携带数（0 / 1 / 2 次扩建 → 2 / 3 / 4 株） |
| **等** | 迁移、其他主观行动 | 待定 | 待定 |

- 默认只能选一个；部分虫珀 / 物品可解锁多选（Q-037）。
- 招募窗口在回合开始 + 事件触发；均可反复招募到「结束招募」，不占三选一（见第 3 节、Q-068）。
- **招募池按巢穴等级分批开放**（2026-11-09 定，Q-103）：阶级是**解锁层级**，不是数值升阶；名称统一为**一阶 / 二阶 / 三阶**，对应巢穴 **L1 / L2 / L3**。每虫种总池目标 **36 = 共享 12 + 专属 24**（当前实装 31 = 共享 12 + 廪实专属 19）；累计可用 **14 / 25 / 31**（目标 18 / 30 / 36）。招募时各阶出现率：L1 一阶 100%；L2 一阶 60% / 二阶 40%；L3 一阶 45% / 二阶 35% / 三阶 20%。升阶后第一次招募有**新阶级保底**，详见 `units.md` 4.0。
- 夏天的冒险回报更高，但探索的食物损失更多；春天冒险风险更高（Q-057）。

## 2.7 季节对经济的影响

- 春天：生产加速。
- 夏天：生产减速；冒险回报更高，但探索的食物损失更多。
- 秋天：生产加速。
- 冬天：食物消耗减少；巢穴更容易受伤。
- 具体百分比待定（Q-057）。

## 2.8 食物的压力结构

| 类型 | 去向 |
|---|---|
| 生存 | 修复巢穴 |
| 扩张 | 招募、孵化、解锁兵种 |
| 投资 | 巢穴扩建（解锁新肥沃格）/ 种子 |
| 转化 | 战果（占用生产周期） |

> 单一资源的价值在于：这四类去向**互相排斥**，玩家每回合只能照顾其中一部分。
> 2026-11-09 取消「战斗补给」与「每回合维持费」：出战不扣食物，战斗压力只通过阵亡后的修复与巢穴完整度体现。

## 3. 兵种招募

- **招募窗口在回合开始 + 事件触发**（2026-11-11 定）：不再占用三选一。
- 触发来源：回合开始的固定窗口、商人 / 中立生物 / 巢穴事件等（Q-068）。
- 每个招募窗口都是 **3 选 1**，且**可反复招募**，直到玩家点「结束招募」；**不设每窗口次数上限**。
- 刷新候选：优先消耗免费刷新（度支蚁等），否则 **1 食物 / 次**，可反复刷新；部分虫珀可提供免费刷新。
- **候选池按阶级概率抽取**（2026-11-09 定，Q-103）：L1 只出一阶；L2 一阶 60% / 二阶 40%；L3 一阶 45% / 二阶 35% / 三阶 20%；每个候选独立结算；升阶后第一次招募有**新阶级保底**（Q-103 / Q-106；待二/三阶实装）。
- **食物是唯一招募成本**（2026-11-09 确定）；不再使用单位转化。
- **统一成本（2026-11-11 定）**：所有兵种招募价 **4 食物**，不再逐兵种标价、不分阶级；原按身板 / 签名定价的公式与阶级成本带作废（`units.md` 4.0.6）。招募刷新 **1 食物**。
- **卖出（2026-11-11 新增）**：非战斗阶段可卖出任意单位，基础返还 **2 食物**；「质库蚁」每经历 1 场战斗额外 +1，**无上限**。卖出后单位离队，本局永久失去。
- **兵种池 31 个**（一阶 14 / 二阶 11 / 三阶 6，2026-11-11 实装）：3 选 1 的信息密度更高，刷新更有价值。
- 食物不足 → 该兵种**不可招募**（或显示为灰色）。
- 这让“食物优先养兵，还是修复巢穴 / 升级巢穴”成为每局要做的决策。
- **士兵是持久资产**：战斗不会让士兵消失，也不会饿死（见 `combat.md`、Q-036 / Q-049）。

## 3.5 战斗与食物（2026-11-09 改定：取消战斗补给）

- **士兵不会因战斗消失，也不会饿死。**
- **出战本身不扣食物**：取消原「战斗补给」，部署确认后不再有按单位支付的出战费（Q-052）。
- 战斗对经济的压力来自：
  - 战后修复（主动修巢、失败扣完整度后的恢复）；
  - 为出兵而少种田 / 少扩田的机会成本。
- **食物不能扣到 0 以下**：任何支付最多扣到 0；不足即为“付不起”，不会产生负数债务。
- **反向来源**：司农蚁参战并满足条件时，战斗结束后额外带回 **1–3 食物**（见 `units.md` 4.3，Q-110）。
- 设计意图：把食物压力从“打仗贵”移到“发展贵”，出兵规模不再受维持费约束。

## 3.6 种子与生产

- 种子是外圈格的主要产物（见 `nest-honeycomb.md`）。
- **收获型种子**：播种后**周期性产出食物 / 战果 / 工具效果**，每 N 个事件一次（2026-11-09 定，Q-064）。
- 收获型种子**就是生产单位本身**，不再另设建筑（Q-069）。
- 肥沃格累计 3 / 6 / 9，一局最多同时照料 9 颗种子。
- **共生昆虫**：战斗 buff，或增益其它生产单位（Q-066）。
- 种子由**冒险带回**；也可能来自商人 / 事件（Q-067）。
- 播种是否消耗食物、是否占行动待定（Q-065）。
- **产出大类**：食物型 / 战果型 / 工具型；主要取舍是“这块田产什么”，不是“产多快”（2026-11-09 定）。
- **战果型**的产出存入道具栏，战斗中使用（Q-071 ~ Q-074）。
- **工具型**提供恢复、增益、羁绊或**战斗植物**（战斗植物不额外占部署格 / 肥沃格，Q-092 / Q-095），本身不直接产食物。

## 4. 招募池的解锁（2026-11-09 改定）

- 招募池**按巢穴等级分批开放**（Q-103）：L1 只出一阶；L2 加入二阶；L3 加入三阶。
- 阶级是**解锁层级**，不是数值升阶；各阶出现率与升阶保底见第 3 节、`units.md` 4.0。
- 食物只承担“支付成本”（统一 4 食物 / 个），不承担解锁条件。
- 旧的“探索带回种子 → 解锁对应兵种”方案**已废止**：种子系统改为生产单位，不再承担兵种解锁。

## 5. 维持（2026-11-09 取消）

- **删除每回合维持费**：不再有 `1 + ceil(人口 / 5)` 的固定食物消耗，也没有人口 / 工蚁层（Q-025 / Q-055）。
- 食物只在**主动行动**时支出：招募、修复巢穴、扩建、播种等。
- 食物不足时士兵不会饿死（2026-11-08 确定）；也不存在“饿死工蚁”的结算。

## 6. 一次性支出

| 项目 | 食物 |
|---|---|
| 招募任一兵种（统一价） | 4 |
| 扩建到 L2 / L3（切片） | **12 / 18**（压缩阈值，1 食物 = 1 经验） |
| 扩建到 L2 / L3（全季提案） | **30 / 45**（1 食物 = 1 经验；经验阈值仍待定，Q-098 / Q-100） |
| 修复巢穴完整度 | **4 食物 → 18 完整度** |
| 招募刷新 | **1 食物 / 次** |
| 播种 | 切片 **0**；全季提案 **3 食物 / 颗**（Q-065） |

> 数值均为 **2026-11-11 校准 v1**；所有成本都以食物表达。切片与全季用不同扩建阈值，是因为切片只有 6 回合 / 24 次事件，全季有 96 次事件；两者不共用一张表。

## 7. 无上限储存

- **食物、虫珀、种子、物品均不设上限**（2026-11-08 定；2026-11-09 随单资源调整）。
- 例外：战果若采用有限格道具栏，则受容量限制，待定（Q-072）。
- 不做"超过上限浪费"。
- 冬季前可自由囤粮，储备多少由玩家自己判断。
- 蜜罐蚁原"上限 +5/+10"因此失效，需要重做被动（见 Q-017）。

## 8. 节奏目标

- 前 5 分钟：食物只够做一两件事——修复巢穴、招募第一个单位，还是攒着扩建。
- 中期：巢穴扩建、种子替换与招募开始抢食物，必须决定"滚雪球还是保命"。
- 后期：种子与兵种成型，食物从"稀缺"转为"分配效率"，准备终局。

## 8.5 全季经济基线 v1（2026-11-11 校准，待模拟）

- **平均食物田 3 块**（不是 5 块）：Q-067 限定一局 6–8 颗种子，食物型约 2–3 颗，加开局 1 颗；
- 兵种成本按 4.0.6 新表，平均约 **6.5 食物**。

- 这张表只用于检查数量级；具体单价跑模拟后再调（Q-052 / Q-064 / Q-057 / Q-135）。

## 8.6 春季切片经济基线 v1（6 回合，2026-11-11 校准）

按 **6 回合 / 24 次事件**估算；食物田从 1 块递进到 2–3 块。

| 项目 | 估算食物 | 说明 |
|---|---|---|
| 食物种子收入 | 42–54 | 1 田全季 24 + 第 2 田约 18 + 第 3 田约 12 |
| 战斗奖励 | 12–20 | 4 场普通 ×2–4 + 1 场强敌 ×4–6 |
| 探索 / 随机事件 | 6–12 | 含露水洼、春雨等 |
