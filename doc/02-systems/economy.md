# 经济系统 v0.2（草案）

> 时间单位：**1 回合**（不绑定天数，见 `time-and-seasons.md`）。
> 目标：**多资源约束 + 探索解锁**，让"限制中找最优解"更立体。
> 所有数值为首版占位，待平衡。

## 1. 资源种类

不做统一货币，资源各有用途：

| 资源 | 主要用途 |
|---|---|
| **食物** | 养蚁后、孵化、维持、修复巢穴、战斗补给 |
| **石头** | 建筑、防御工事、重甲兵种 |
| **植物纤维** | 建筑、轻甲兵种、侦察/织叶类 |
| （可选）水 / 树脂 / 孢子 | 后续按种子 / 事件扩展 |

- 食物仍是**生存主线**，石头/纤维是**发展线**。
- 三种资源就够撑起取舍，暂不继续加。

## 2. 资源获取

| 资源 | 来源 |
|---|---|
| 食物 | 基础粮仓、采集、农场、战利品 |
| 石头 | 矿点、巢穴挖掘、外围圈层探索 |
| 植物纤维 | 种子产出、事件 |
| 稀有材料 | 冒险带回种子 / 击败强敌 / 中立交易 |

- 不存在地表采集地图：资源来自**外圈播种的收获型种子**与生产单位，相当于把生产搬进蚁穴内。

- 冒险带回**新种子**会解锁新的资源与材料。
- 材料本身也是"兵种解锁条件"。

## 2.4 生产单位与周期

- 收入来自**生产单位**（建筑 / 设施 / 生产格，具体形态待定，Q-044）；也可能由**收获型种子**承担（Q-069）。
- 每个生产单位有等级；生产周期与等级有关。
- **周期的最小时间单位 = 事件**。
- 工蚁是否参与生产、如何分配到生产单位，待定（Q-044）。
- 例：某生产单位每 N 个事件产出一次；N 由等级决定（公式待定，Q-044）。
- 生产在事件结算时触发，还是回合开始汇总，待定（Q-045）。

## 2.5 回合收入与工蚁

- **回合开始做收入汇报**：食物 / 石头 / 纤维的产出与消耗。
- **蚁后每回合生成工蚁**；工蚁是巢穴的修复力，也是探索的消耗品。
- **工蚁数量 = 每回合巢穴健康恢复的基数**：工蚁越多，每回合恢复越多，但只是**少量被动恢复**（公式待定，Q-054）。
- 主动「基地恢复」的修复量显著高于工蚁被动恢复（Q-046）。
- 工蚁也可以被牺牲去冒险，换取高回报。
- 收入公式待定（Q-040）。

## 2.6 收入的主要去向（主观行动）

| 方向 | 做什么 | 风险 / 代价 | 收益 |
|---|---|---|---|
| **冒险** | 周边探索 | 牺牲工蚁；数量由随机事件决定，恶劣天气/气候与寄生虫等会放大牺牲；可能遇敌对势力 | 资源、虫珀、**种子** |
| **基地恢复** | 主动修复巢穴完整度 | 消耗资源 | 巢穴健康回升，数值显著高于工蚁被动恢复 |
| **建筑升级点数** | 投入建筑升级 | 消耗资源 / 点数 | 生产单位升级，缩短周期或提高产量 |
| **等** | 迁移、其他主观行动 | 待定 | 待定 |

- 默认只能选一个；部分虫珀 / 物品可解锁多选（Q-037）。
- 招募改为事件触发，不占三选一（见第 3 节、Q-047 / Q-068）。
- 夏天的冒险回报更高，但损失的工蚁更多；春天冒险风险更高（Q-057）。

## 2.7 季节对经济的影响

- 春天：生产加速。
- 夏天：生产减速；冒险回报更高，但损失工蚁更多。
- 秋天：生产加速。
- 冬天：食物消耗减少；巢穴更容易受伤。
- 具体百分比待定（Q-057）。

## 3. 兵种招募与资源强相关

- **招募改为事件触发**（2026-11-08 确定）：不再每回合固定出现。
- 触发来源：商人 / 中立生物 / 巢穴事件等（待定，Q-068）。
- 触发时仍是 **3 选 1**；可牺牲食物刷新一次；部分虫珀可刷新一次。
- **食物是招募的主要工具**；不再使用“工蚁转化”。
- 每个兵种的生成 = **食物为主 + 少量其他资源**；具体配方按兵种不同。
- 资源配方例（占位）：

| 兵种 | 配方 |
|---|---|
| 工蚁 | 3 食物（可选；主要靠蚁后生成） |
| 兵蚁 | 5 食物 + 2 石头 |
| 侦察蚁 | 3 食物 + 1 纤维 |
| 守卫蚁 | 5 食物 + 2 石头 |
| 爆炸蚁 | 4 食物 + 1 纤维 |

- 食物或材料不足 → 该兵种**不可生成**。
- 这让“食物优先养兵，还是留作战斗补给 / 修复巢穴”成为每局要做的决策。
- **士兵是持久资产**：战斗不会让士兵消失，也不会饿死（见 `combat.md`、Q-036 / Q-049）。
- 工蚁是否还能用食物孵化，待定（Q-025）。

## 3.5 战斗的食物损耗

- **士兵不会因战斗消失，也不会饿死。**
- 每次战斗都会**损耗食物**（补给 / 消耗），作为士兵参战的真实代价。
- **每个出场单位按兵种消耗一定食物**；不同兵种补给成本不同（数值见 `units.md`，Q-052）；空位不计。
- **恶劣天气与气候会放大每次战斗的食物损耗**；下雨暂按 ×1.5（Q-053）。
- 这是“士兵消失让玩家不舒服”的替代方案：损失落在食物上，而不是单位上。

## 3.6 种子与生产

- 种子是外圈格的主要产物（见 `nest-honeycomb.md`）。
- **收获型种子**：播种后产出资源；一次还是周期性待定（Q-064）。
- **共生昆虫**：战斗 buff，或增益其它生产单位（Q-066）。
- 种子由**冒险带回**；也可能来自商人 / 事件（Q-067）。
- 播种是否消耗资源、是否占行动待定（Q-065）。
- 生产单位除普通食物外，还会产出**强化食物（战粮）**，存入道具栏，战斗中使用（Q-071）。

## 4. 探索解锁新兵种

- 招募池不是一开始全开。
- 玩家冒险带回**新种子 / 新材料**后，对应兵种才有机会"刷出"。
- 例：
  - 发现"黏土坑" → 解锁需要黏土的建筑/兵种
  - 发现"树脂树" → 解锁树脂相关兵种
  - 发现"地下菌床" → 解锁真菌类兵种
- 因此**探索是招募的前置**，不是可选支线。

## 5. 维持

统一喂蚁后，不追踪每只蚂蚁的饥饿：

```
每回合食物消耗 = 1（蚁后基础） + ceil(当前人口 / 5)
```

- 食物不足：**士兵不会饿死**（2026-11-08 确定）；工蚁是否饿死 / 停止生成，待定（Q-055）；蚁后停止生成工蚁。
- 食物缺口是否改为扣巢穴健康，待定（Q-055）。
- 人口本身就是成本，扩张必须有收入支撑。

## 6. 一次性支出

| 项目 | 食物 | 石头 | 纤维 |
|---|---|---|---|
| 孵化工蚁 | 3 | — | — |
| 孵化兵蚁 | 5 | 2 | — |
| 孵化特殊蚁 | 6–8 | 2–4 | 1–3 |
| 挖一格 / 造房间 | 2–5 | 1–3 | 1–2 |
| 升级房间 | 4–8 | 3–6 | 2–4 |
| 修复巢穴完整度 | 按点数计 | — | — |

> 数值全是占位。

## 7. 无上限储存

- **食物、石头、纤维、虫珀、物品均不设上限**（2026-11-08 确定）。
- 例外：战粮若采用有限格道具栏，则受容量限制，待定（Q-072）。
- 不做"超过上限浪费"。
- 冬季前可自由囤粮，储备多少由玩家自己判断。
- 蜜罐蚁原"上限 +5/+10"因此失效，需要重做被动（见 Q-017）。

## 8. 节奏目标

- 前 5 分钟：玩家面对"保留工蚁修复巢穴 / 冒险，还是把食物投进招募与战斗补给"的选择。
- 中期：单一食物不够，必须分兵去采石头/纤维。
- 后期：探索解锁的新兵种 + 囤积资源，准备终局。

## 9. 反馈与复盘

每回合结算显示：

- 食物 / 石头 / 纤维的收入与消耗明细
- 净变化
- 下回合预测
- 因材料不足而"未解锁"的兵种提示
