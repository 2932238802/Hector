# 经济系统 v0.3（草案）

> 时间单位：**1 回合**（不绑定天数，见 `time-and-seasons.md`）。
> 目标：**单一硬通货下的取舍**——每一份食物都在抢同一批去向。
> 2026-11-09 定：**只保留食物一种基础资源**，取消石头 / 植物纤维。
> 所有数值为首版占位，待平衡。

## 1. 资源种类

**食物是唯一的基础资源。**

| 资源 | 用途 |
|---|---|
| **食物** | 招募、孵化、维持、修复巢穴、巢穴扩建、战斗补给 |
| **战果** | 食物派生的战斗道具（法术卡式），由生产单位产出，存道具栏；可直接加属性或挂 buff（Q-071 ~ Q-074 / Q-094） |

- 不做石头 / 纤维，也不做“材料”这一中间层。
- 理由：三种资源只是把同一份预算拆成三栏记账，没有产生新的决策类型；
  单一食物能让“现在吃 / 现在补兵 / 现在投资”变成直接冲突。
- 复杂度的出口放在**兵种、种子、虫珀、事件**上，而不是多币种。

## 1.5 开局状态（2026-11-09 定）

| 项目 | 初始值 |
|---|---|
| 巢穴等级 | **L2**（7 格，其中 3 个肥沃格） |
| 食物 | **15** |
| 种子 | **1 颗基础食物型种子** |
| 已解锁兵种 | 共享池基础项（待定） |

- 开局第一回合就有真实选择：播种、冒险、扩建或恢复。
- 不存在“必须先扩建才能生产”的强制开场。
- 起始种子按**基础食物型**：3 事件产出 2 食物（提案 v1）。

## 2. 资源获取

| 来源 | 说明 |
|---|---|
| **收获型种子（生产单位）** | 主要来源；播在肥沃格后每 N 个事件产出一次（Q-064 / Q-069） |
| **冒险** | 食物、虫珀、种子；风险由随机事件决定（Q-039） |
| **事件 / 战利品** | 击败敌对势力、完成事件组的奖励 |
| **商人** | 用食物交换虫珀 / 种子 / 招募机会（Q-068） |

- 不存在地表采集地图：食物来自**蚁穴内播种的收获型种子**。
- 冒险带回**新种子**会解锁新的生产单位与兵种。

## 2.4 生产单位与周期

- **生产单位 = 播种后的收获型种子**（2026-11-09 确定）；不另设建筑 / 设施。
- 每个收获型种子占 1 个**肥沃格**；肥沃格累计 3 / 6 / 9（见 `nest-honeycomb.md`）。
- **周期的最小时间单位 = 事件**；每个种子每 N 个事件产出一次，N 由种子类型决定。
- **主要取舍轴 = 产出大类**（2026-11-09 定）：食物 / 战果 / 工具；不是“快产 vs 慢产”。
- 同类型种子共享基础周期与产出预算；稀有变体只做小幅偏移，不做全面上位。

### 2.4.1 种子产出大类（2026-11-09 定，提案 v1）

> 术语：**种子**是播种后的生产单位；**果实**是它周期性产出的东西。
> 食物与战果以果实形式收获；工具种子可以产工具果实，也可以维持一个持续效果。

| 大类 | 产出 | 例子 | 经济角色 |
|---|---|---|---|
| **食物型** | 食物果实 | 基础谷种、丰产块根 | 主收入；数量决定其它种子能开多少 |
| **战果型** | 战果 | 树脂、毒液、甲壳 | 给兵种加属性 / 挂 buff / 战斗消耗；不直接产粮 |
| **工具型** | 工具果实或持续效果 | 愈合菌圃（恢复巢穴健康）、共生藤（增益其它种子）、羁绊型种子（组合增益，首批待定）、荆棘防线（战斗植物，不额外占格） | 用食物机会成本换功能 |

首版数值只定食物与战果；工具种子效果待定（Q-092 ~ Q-094）。

| 种子 | 周期 N（事件） | 每次产出 | 备注 |
|---|---|---|---|
| 食物型（基础） | 3 | 2 食物 | 经济主力 |
| 食物型（丰产） | 5 | 4 食物 | 空窗更长，前期不宜 |
| 战果型 | 3 | 1 份战果 | 每周期少 2 食物 |
| 工具型 | 待定 | 恢复 / 增益 / 羁绊 / 战斗植物 | 不直接产粮 |

- **食物型是主轴**：食物型种子的数量决定其它种子能开多少。
- **战果型 / 工具型用食物机会成本换收益**：每换掉 1 块食物田，按基础食物型计，约少 0.67 食物/事件。
- **羁绊**：指定种子组合在相邻肥沃格（共边，含同圈 / 跨圈）激活；**不是纯被动经济加成**，效果需结合植物 / 兵种 / 虫种特性，具体暂缓（Q-093 / Q-096）。
- 一局种子获取量建议控制在 **6–8 颗**（Q-067），避免 9 田全食物把紧经济冲垮。

### 2.4.2 生产结算（提案，Q-045）

- 种子播种后计数器从 0 开始；**每结算 1 个事件 +1**，达到 N 时在**该事件结算结束时**产出，然后归零。
- 播种窗口内种下的种子，从**下一个事件**开始计数。
- 多颗种子同事件成熟时**同时结算**，不额外占行动。
- 工具种子可以是**周期性触发**（每 N 事件一次）或**持续光环**，具体由种子条目决定（Q-092）。
- 回合开始的收入汇报只显示**本回合预计产出**；实际入账在事件结算时。
- 季节修正作用在**产量**上，不改 N，避免出现小数周期（具体数值 Q-057）。
- 种子能否升级 / 移除 / 替换待定（Q-065）。

## 2.5 回合收入与工蚁

- **回合开始做收入汇报**：食物的产出与消耗。
- **蚁后每回合生成工蚁**；工蚁是巢穴的修复力，也是探索的消耗品。
- **工蚁数量 = 每回合巢穴健康恢复的基数**：工蚁越多，恢复越多，但只是**少量被动恢复**（公式待定，Q-054）。
- 主动「巢穴恢复」的修复量显著高于工蚁被动恢复（Q-046）。
- 工蚁也可以被牺牲去冒险，换取高回报。
- 收入公式待定（Q-040）。

## 2.6 收入的主要去向（主观行动）

| 方向 | 做什么 | 风险 / 代价 | 收益 |
|---|---|---|---|
| **冒险** | 周边探索 | 牺牲工蚁；数量由随机事件决定，恶劣天气/气候与寄生虫等会放大牺牲；可能遇敌对势力 | 食物、虫珀、**种子** |
| **巢穴恢复** | 主动修复巢穴完整度 | 消耗食物 | 巢穴健康回升，数值显著高于工蚁被动恢复 |
| **巢穴扩建** | 扩大巢穴，开放新的肥沃格 | **巢穴经验达到阈值**；食物可兑换经验 | 播种位增加（3 / 6 / 9）；额外基地空间；解锁植物携带数（0 / 1 / 2 次扩建 → 2 / 3 / 4 株） |
| **等** | 迁移、其他主观行动 | 待定 | 待定 |

- 默认只能选一个；部分虫珀 / 物品可解锁多选（Q-037）。
- 招募改为事件触发，不占三选一（见第 3 节、Q-047 / Q-068）。
- **招募池按巢穴等级分批开放**（2026-11-09 定，Q-103）：阶级是**解锁层级**，不是数值升阶；名称统一为**一阶 / 二阶 / 三阶**，对应巢穴 **L2 / L3 / L4**。每虫种总池 **24 = 共享 12 + 专属 12**；累计可用 12 / 20 / 24。招募时各阶出现率：L2 一阶 100%；L3 一阶 60% / 二阶 40%；L4 一阶 45% / 二阶 35% / 三阶 20%。升阶后第一次招募有**新阶级保底**，详见 `units.md` 4.0。
- 夏天的冒险回报更高，但损失的工蚁更多；春天冒险风险更高（Q-057）。

## 2.7 季节对经济的影响

- 春天：生产加速。
- 夏天：生产减速；冒险回报更高，但损失工蚁更多。
- 秋天：生产加速。
- 冬天：食物消耗减少；巢穴更容易受伤。
- 具体百分比待定（Q-057）。

## 2.8 食物的压力结构

| 类型 | 去向 |
|---|---|
| 生存 | 每回合维持、修复巢穴 |
| 扩张 | 招募、孵化、解锁兵种 |
| 战斗 | 每个出场单位的补给（按兵种） |
| 投资 | 巢穴扩建（解锁新肥沃格）/ 种子 |
| 转化 | 战果（占用生产周期） |

> 单一资源的价值在于：这五类去向**互相排斥**，玩家每回合只能照顾其中一部分。

## 3. 兵种招募

- **招募改为事件触发**（2026-11-08 确定）：不再每回合固定出现。
- 触发来源：商人 / 中立生物 / 巢穴事件等（待定，Q-068）。
- 触发时仍是 **3 选 1**；可牺牲食物刷新一次；部分虫珀可刷新一次。
- **候选池按阶级概率抽取**（2026-11-09 定，Q-103）：L2 只出一阶；L3 一阶 60% / 二阶 40%；L4 一阶 45% / 二阶 35% / 三阶 20%；每个候选独立结算；升阶后第一次招募有**新阶级保底**（Q-103 / Q-106）。
- **食物是唯一招募成本**（2026-11-09 确定）；不再使用“工蚁转化”。
- 配方例（占位）：

| 兵种 | 食物成本 |
|---|---|
| 工蚁 | 3（可选；主要靠蚁后生成） |
| 锐士 | 8 |
| 斥候 | 5 |
| 采薇 | 6 |
| 干城 | 9 |
| 焚卒 | 6 |
| 弩手 | 7 |

- 食物不足 → 该兵种**不可招募**（或显示为灰色）。
- 这让“食物优先养兵，还是留作战斗补给 / 修复巢穴 / 升级”成为每局要做的决策。
- **士兵是持久资产**：战斗不会让士兵消失，也不会饿死（见 `combat.md`、Q-036 / Q-049）。
- 工蚁是否还能用食物孵化，待定（Q-025）。

## 3.5 战斗的食物损耗

- **士兵不会因战斗消失，也不会饿死。**
- 每次战斗都会**损耗食物**（补给 / 消耗），作为士兵参战的真实代价。
- **支付时点：开战前、部署确认后**（2026-11-09 定，Q-052）。
  - 按**实际出场单位**逐个计价；空位、后备、未出场单位不计。
  - 食物不足时，必须撤下单位直到付得起；**一个单位都派不出时，不能选择迎战**，只能谈判 / 回避。
  - 补给**不退还**；失败、撤退、最终裁决同样消耗，因为已经出兵。
- **补给是每场战斗的成本，不是每回合军费**；不打仗就不付。
- 首版单价（提案 v1，见 `units.md`）：「锐士 / 斥候 / 采薇 / 焚卒 / 弩手」各 1；「干城」2；专属兵种 2–3。
- **下雨：总补给 ×1.5，向上取整**（Q-053）；晴天 / 多云暂不改补给。
- **反向来源**：采薇参战并满足条件时，战斗结束后额外带回 **1–3 食物**（见 `units.md` 4.3，Q-110）；这是补给之外唯一与战斗直接挂钩的食物收入。
- 设计意图：让“带满 7 格”不是默认答案，出兵规模本身成为食物决策。

## 3.6 种子与生产

- 种子是外圈格的主要产物（见 `nest-honeycomb.md`）。
- **收获型种子**：播种后**周期性产出食物 / 战果 / 工具效果**，每 N 个事件一次（2026-11-09 定，Q-064）。
- 收获型种子**就是生产单位本身**，不再另设建筑（Q-069）。
- 肥沃格累计 3 / 6 / 9，一局最多同时照料 9 颗种子。
- **共生昆虫**：战斗 buff，或增益其它生产单位（Q-066）。
- 种子由**冒险带回**；也可能来自商人 / 事件（Q-067）。
- 播种是否消耗食物、是否占行动待定（Q-065）。
- **产出大类**：食物型 / 战果型 / 工具型；主要取舍是“这块田产什么”，不是“产多快”（2026-11-09 定）。
- **战果型**的产出存入道具栏，战斗中使用（Q-071 ~ Q-074）。
- **工具型**提供恢复、增益、羁绊或**战斗植物**（战斗植物不额外占部署格 / 肥沃格，Q-092 / Q-095），本身不直接产食物。

## 4. 探索解锁新兵种

- 招募池不是一开始全开。
- 玩家冒险带回**新种子**后，对应兵种才有机会"刷出"。
- 例：
  - 带回黏土共生种子 → 解锁黏土系兵种
  - 带回树脂共生种子 → 解锁树脂系兵种
  - 带回菌床种子 → 解锁真菌类兵种
- 因此**探索是招募的前置**，不是可选支线。
- 食物本身不承担“解锁条件”，只承担“支付成本”；解锁靠发现。

## 5. 维持

统一喂蚁后，不追踪每只蚂蚁的饥饿：

```
每回合食物消耗 = 1（蚁后基础） + ceil(当前人口 / 5)
```

- 食物不足：**士兵不会饿死**（2026-11-08 确定）；工蚁是否饿死 / 停止生成，待定（Q-055）；蚁后停止生成工蚁。
- 食物缺口是否改为扣巢穴健康，待定（Q-055）。
- 人口本身就是成本，扩张必须有收入支撑。

## 6. 一次性支出

| 项目 | 食物 |
|---|---|
| 孵化工蚁 | 3 |
| 招募「锐士」 | 8 |
| 招募专属兵种 | 10–14 |
| 扩建到 L3 / L4 | 20–30 / 30–40 **可兑换为经验**；经验阈值待定 |
| 修复巢穴完整度 | 按点数计 |

> 数值全是占位；所有成本都以食物表达。

## 7. 无上限储存

- **食物、虫珀、种子、物品均不设上限**（2026-11-08 定；2026-11-09 随单资源调整）。
- 例外：战果若采用有限格道具栏，则受容量限制，待定（Q-072）。
- 不做"超过上限浪费"。
- 冬季前可自由囤粮，储备多少由玩家自己判断。
- 蜜罐蚁原"上限 +5/+10"因此失效，需要重做被动（见 Q-017）。

## 8. 节奏目标

- 前 5 分钟：食物只够做一两件事——留作补给、修复巢穴、还是招募第一个单位。
- 中期：巢穴扩建、种子替换与战斗补给开始抢食物，必须决定"滚雪球还是保命"。
- 后期：种子与兵种成型，食物从"稀缺"转为"分配效率"，准备终局。

## 8.5 首版经济基线（占位，待模拟）

按以下假设估算一局 24 回合：

- 平均 **5 块食物田**（其余田位放战果 / 工具种子），基础食物型 2 食物 / 3 事件；
- **13 场手动战斗**，平均每场 6 个出场单位，平均补给 1.2 食物/单位；
- 招募 4–5 次，扩建 2 次（25 + 35 食物可兑换成经验；具体兑换率待定），播种 8 次。

| 项目 | 估算食物 | 说明 |
|---|---|---|
| 食物种子收入 | ≈ 320 | 5 田 × 2/3 × 96 事件 |
| 冒险 / 战利品 | 30–60 | 含战斗掉落、事件奖励 |
| **总收入** | **≈ 350–380** | |
| 维持 | ≈ 72 | 平均 3/回合 × 24 |
| 战斗补给 | ≈ 94 | 13 场 × 6 单位 × 1.2 |
| 招募 | 32–40 | 4–5 次 × 8 |
| 巢穴扩建 | 60 | 若用食物兑换经验，约 L2→L3 25、L3→L4 35；若靠植物受击积累，可省下这笔食物 |
| 修复 | 30–50 | 主动修复 + 战斗失败 |
| 播种 | 24 | 8 次 × 3（占位） |
| **总支出** | **≈ 312–340** | |

- 目标缓冲 **5–10%**；雨天、连续战斗、修复压力会吃掉缓冲。
- 如果玩家把 2 块食物田换成战果 / 工具种子，食物收入约少 **128**，必须靠降低军费或战斗收益补回。
- 这张表只用于检查数量级；具体单价跑模拟后再调（Q-052 / Q-064 / Q-057）。
