# 巢穴：中心六边形 + 外圈扩张（草案）

> 不做真实地下模拟。
> 就是：**一个中心六边形，升级后外面围一圈。**

## 1. 结构

- 开局：中心 **1 格**。
- **最内一格默认是蚁后室。**
- 每次升级：外面**新增一圈**六边形。
- 不区分房间类型，不画隧道，不模拟土层；但每格可以有**地势**（见第 3 节）。

| 等级 | 新增环 | 新增格数 | 总格数 |
|---|---|---|---|
| L1 | — | — | 1 |
| L2 | 第 1 圈 | +6 | 7 |
| L3 | 第 2 圈 | +12 | 19 |
| L4 | 第 3 圈 | +18 | 37 |

**最高 4 级。** 公式：第 n 圈新增 `6n` 格；L 级总数 = `1 + 3(L-1)L`。

## 2. 视觉

- 蜂巢六边形网格，俯视。
- **整体黑白、极简。**
- 中心格 = 蚁后室，放一个简单的黑白符号即可。
  - 参考 `doc/reference/gi-wrapping-star.png`（仅参考，不可直接复用）。
  - 正式图标之后用 AI 生成。
- **不需要画出蚁后。**
- 升级时，新一圈从中心向外"长"出来。
- 外圈颜色/亮度可以和中心不同，表示"新扩张的领地"。

## 3. 格子与地势

- 每个格子可以有一种**地势**。
- 每次升级开辟新一圈时，新格子**不保证都可用**：
  - 有些默认**不能移动 / 不能进入**（岩层、水囊、树根等）。
  - 有些可通行，可能带资源 / 防御 / 特殊效果。
- **地势探索**事件可以让玩家把一种地势**预置**到一个外围格子：
  - 探索 → 选择一个外围格 → 该格获得该地势。
  - 原文用"预言"，待确认是"预置"还是"预知"。
- 具体地势类型与效果待设计（见 Q-027）。
- 不可进入格 + 移动规则，可能成为织叶蚁"搭桥"的落点（见 Q-018）。

## 4. 升级方式（待定）

- A. 花食物
- B. 蚁后升级
- C. 每 N 天自动

## 5. 巢穴状态与位置

### 5.1 巢穴完整度（单一数值）

- 用一个数代表巢穴健康，暂定 **0–100**。
- 受敌对昆虫、天敌、灾害、断粮影响而下降。
- 可花食物修复。
- 归零 = 本局失败。
- **不做复杂结构**，就一条"血条"。
- 命名待定：巢穴完整度 / 城墙生命值 / 巢穴生命值。

### 5.2 巢穴位置

- 开局决定，候选：**河边 / 人类房屋边 / 沙漠 / 其他**。
- 位置影响：事件池、资源类型、天敌种类、灾害风险。
- 与"季节"共同决定每回合事件组的构成。
- 具体效果之后设计。
