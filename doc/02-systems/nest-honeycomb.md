# 巢穴：中心六边形 + 外圈扩张（草案 v0.2）

> 不做真实地下模拟。
> 就是：**一个中心六边形，升级后外面围一圈。**
> **所有格子都在蚁穴内部**；不存在地表地图。升级 = 在蚁穴内部向外开辟新的圈层。
> 2026-11-09 定：**收获型种子就是唯一的生产单位**；不做独立建筑系统。

## 1. 结构

- **开局即 L1**：中心蚁后室 + 第 1 圈，共 7 格，其中 **3 个肥沃格**（2026-11-09 定，Q-075）。
- **巢穴只有 L1–L3**（2026-11-09 定）：L1 是开局形态，L2 / L3 各扩建一次；等级与兵种阶级一一对齐（一阶 = L1 / 二阶 = L2 / 三阶 = L3）。
- 每次升级：外面**新增一圈**六边形。
- 不区分房间类型，不画隧道，不模拟土层。
- 外圈格中只有**肥沃格**可以播种；其余为结构格（v1 不承载玩法内容，Q-070）。
- 开局附带 **1 颗基础食物型种子 + 15 食物**（见 `economy.md`）。

| 等级 | 新增环 | 新增格数 | 总格数 | 累计播种位 |
|---|---|---|---|---|
| L1 | 第 1 圈 | +6 | 7 | **3** |
| L2 | 第 2 圈 | +12 | 19 | **6** |
| L3 | 第 3 圈 | +18 | 37 | **9** |

- **最高 3 级。** 公式：第 n 圈新增 `6n` 格；L 级总数 = `1 + 3L(L+1)`（1 / 7 / 19 / 37）。
- **每次扩建新增 3 个肥沃格**，累计 3 / 6 / 9；一局最多同时照料 9 颗种子。
- 肥沃格用高亮标识；升级动画里新一圈“长”出来后，其中 3 格亮起。

> 上表是**理论最大值**。河边等位置会阻断某一侧，实际格数与播种位可能更少（见 5.3）。

## 2. 视觉

- 蜂巢六边形网格，俯视。
- **整体黑白、极简。**
- **图形语言以六边形 / 八边形为主**（2026-11-09）：巢穴网格保持六边形；八边形可作为 UI 面板、图标底座、按钮边框的候选，具体分工待美术确认。
- 中心格 = 蚁后室，放一个简单的黑白符号即可。
  - 参考 `doc/reference/gi-wrapping-star.png`（仅参考，不可直接复用）。
  - 正式图标之后用 AI 生成。
- **不需要画出蚁后。**
- 升级时，新一圈从中心向外"长"出来。
- 肥沃格与结构格需有视觉区分（亮度 / 描边 / 小图标）。

## 3. 格子与种子

- 外圈格子**仍然在蚁穴内部**，不是地表。
- **取消地势系统与地势探索**（2026-11-08 确定）；外圈格用于**播种**。
- **可播种格 = 肥沃格**，不是全部格子；数量 3 / 6 / 9（见第 1 节）。
- 种子来源：**冒险带回**；后续可扩展商人 / 事件奖励（Q-067）。
- 种子类型：

| 类型 | 作用 |
|---|---|
| **食物型** | 生产食物果实：每 N 个事件产出一次（Q-064） |
| **战果型** | 生产战果：给兵种加属性 / 挂 buff / 战斗消耗（Q-071 / Q-094） |
| **工具型** | 恢复巢穴健康、增益其它种子、羁绊、战斗植物（Q-092 ~ Q-096） |
| **共生昆虫** | 战斗 buff，或对其它生产单位提供增益（Q-066） |

- **收获型种子 = 唯一生产单位**（2026-11-09 确定）；不另设建筑 / 设施。
- 每个种子有**固定产出大类**：食物 / 战果 / 工具；不混产（Q-071）。
- 每个种子占 1 个肥沃格；是否可移除 / 替换待定（Q-065）。
- 收获周期与产量提案 v1 见 `economy.md` 2.4.1；成长阶段待定（Q-064）。
- 被位置阻断的格子 + 移动规则，可能成为织叶蚁"搭桥"的落点（见 Q-018）。

### 3.1 相邻与羁绊

- 外圈是六边形网格，**共边即相邻**；同圈与跨圈都算（2026-11-09 定）。
- 肥沃格在每圈的位置固定（建议均匀分布），使相邻关系稳定可读；具体坐标留给技术 schema。
- 布局约束：肥沃格不能全部互不相邻；每圈至少保留 1 组可共边的肥沃格，保证羁绊有触发空间。
- **羁绊 = 指定种子组合位于相邻的肥沃格时激活**；被位置阻断的格子不存在，不能参与相邻。
- **羁绊不是纯被动经济加成**（2026-11-09 用户指正）：效果要结合**植物本身特性、兵种特性、虫种特性**，具体之后讨论（Q-096）。
- 旧方向（产量 / 周期 / 果实品质）暂停，不再作为定稿；丰产链明确不要。
- 若以后保留周期类效果，不能把 N 降到 0；下限至少 1 事件。
- 种子种下 / 移除 / 替换时重新计算；满足条件期间持续生效。
- 每颗种子可参与**多个羁绊**，数量取决于相邻肥沃格；六边形最多 **6 个方向**（2026-11-09 定）。叠加方式随新效果类型再定。
- 首批被动羁绊表暂停；`03-content/seeds.md` 3.4 只保留待讨论说明。羁绊花暂不列入首批。
- UI：相邻的羁绊种子之间显示连线 / 高亮，便于玩家规划。

## 4. 升级方式

- 升级 = **巢穴扩建**，只走一条**巢穴经验**线（2026-11-09 定，Q-098 / Q-100）：
  - **经验达到阈值 → 可升级**；
  - **食物可以兑换成经验**，是经验的来源之一，不另开第二条升级线。
- 经验来源候选：**植物受击 +1**；**食物兑换**（兑换率待定）。
- 升级后获得**额外基地空间**，并解锁更高的**植物携带数量**（L1 = 2 / L2 = 3 / L3 = 4）。
- 一局内实际发生的扩建：**L1 → L2 → L3**，共 2 次；肥沃格 3 → 6 → 9。
- 三选一中的“建筑升级”统一改称 **巢穴扩建**（2026-11-09）。
- 每次扩建后，新增的 3 个肥沃格开放**播种窗口**（Q-065）。
- 经验阈值、食物 → 经验兑换率、经验是否被消耗、是否占用三选一行动、额外基地空间是否等于新增 3 个肥沃格，待定（Q-098 / Q-100）。
- 扩建是否还要求回合数 / 其他条件，待定。

## 5. 巢穴状态与位置

### 5.1 巢穴完整度（单一数值）

- 用一个数代表巢穴健康，暂定 **0–100**。
- 受敌对昆虫、天敌、灾害、断粮影响而下降。
- 主要靠花食物**主动修复**；没有每回合被动恢复（工蚁系统已删除，2026-11-09）。
- 战斗内另有一次性回复：虫种技能**守廪**（最大完整度的 25%）、兵种**堞垒蚁「迅捷」**（每场开始 +2）；它们不属于被动恢复。
- **冬天巢穴更容易受到伤害**；是否覆盖所有伤害来源待定（Q-059）。
- 归零 = 本局失败。
- **不做复杂结构**，就一条"血条"。
- 命名待定：巢穴完整度 / 城墙生命值 / 巢穴生命值。

### 5.2 巢穴位置

- 开局决定，候选：**河边 / 人类房屋边 / 沙漠 / 其他**。
- 位置影响：事件池、可获得的种子、天敌种类、灾害风险。
- 位置还会**改变蜂巢的实际形状**，见 5.3。
- 与"季节"共同决定每回合事件组的构成。
- 具体效果之后设计。

### 5.3 位置对蜂巢形状的限制

- 巢穴位置不只影响事件池，还会限制扩展方向。
- 例：巢穴在**河边** → 靠河的一侧无法继续开辟；每次升级，那一侧可能整边缺格。
- 因此同一等级的**实际格数 = 理论格数 − 被位置阻断的格子**。
- 若被阻断的格子包含肥沃格，该级的**播种位也会减少**（具体规则待定，Q-010）。
- 蜂巢可能不是完整圆环，而是缺一边 / 缺几格。
- 沙漠、人类房屋边等位置的阻断方式待设计（见 Q-010）。

### 5.4 巢穴经验（植物成长线）

- 巢穴有一条**独立经验条**，是升级的**唯一进度线**；食物可兑换经验，不是第二条线（2026-11-09 定，Q-098）。
- 经验用于**升级巢穴**：达到阈值可升级；升级后获得额外基地空间，并解锁植物携带数。
- 经验来源：部分植物受击 **+1**；**食物兑换**（兑换率待定）。
- 经验只服务**植物成长线**，不作用于其它系统。
- 经验是否被消耗、阈值多少、兑换率、是否有其它来源、是否跨局保留，待定（Q-098）。
