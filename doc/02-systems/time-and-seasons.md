# 时间与季节（草案 v0.4）

> **1 小回合 = 3 天**（待确认）。
> **1 大回合 = 10 个决策 = 1 个季节。**
> **一局 = 4 个大回合 = 四季连玩（春 → 夏 → 秋 → 冬）。**
> **全局 40 个决策。**

## 1. 时间尺度

| 单位 | 含义 |
|---|---|
| 1 小回合 | 3 天 |
| 1 大回合 | 10 个小回合 = 10 个决策 = **1 个季节** |
| 一局 | **4 个大回合 = 40 个决策 = 四季连玩** |
| 单局时长 | 15–40 分钟 |

> 若 1 小回合 = 3 天，则一局 = 120 天、40 次决策。
> 平均每个决策约 22–60 秒（15–40 分钟 ÷ 40）。

## 2. 四季

| 大回合 | 季节 | 主题 / 压力 |
|---|---|---|
| 第 1 大回合 | **春** | 建立、繁衍、雨水 |
| 第 2 大回合 | **夏** | 扩张、竞争、干旱 / 高温 |
| 第 3 大回合 | **秋** | 储备、收获、敌巢活跃 |
| 第 4 大回合 | **冬** | 生存、寒潮、终局 |

- 四季连着玩，不是四选一，也不是分开的四局。
- 每个季节有独立的事件池、灾害、资源、兵种倾向。
- 季节推进 = 一局的主轴。
- **季节的具体影响（事件池、灾害、资源）稍后设计。**

## 3. 一局结构

```
春（10 决策） → 夏（10 决策） → 秋（10 决策） → 冬（10 决策） → 终局
```

- 每个季节 = 1 个大回合 = 10 个决策。
- 季节之间可以有**过渡事件 / 结算 / 天气转折**。
- 玩家要跨季规划：春天铺经济、夏天扩张、秋天储备、冬天决战。

## 4. 回合流程（3 天）

```
回合开始（第 1 天）
  → 玩家阶段：分配蚂蚁、建造、采集、探索、派兵
  → 3 天结算：食物/石头/纤维收支、人口成长、建筑完成
  → 回合结束：事件组 N 选 1（N = 3~5）
  → 结算所选事件组
  → 下一回合
```

## 5. 天气

- 回合开始时预报本回合天气。
- 天气影响产出、移动、消耗、巢穴完整度。
- 极端天气在对应季节更常见。

## 6. 生长时间

| 项目 | 所需天数 |
|---|---|
| 卵 → 幼虫 | 1 天 |
| 幼虫 → 成虫 | 1–2 天 |
| 挖掘一格 | 1 天 |
| 建造房间 | 1–3 天 |
| 天赋 / 变异 | 立即或次日生效 |

> 1 回合 = 3 天：1 天的项目回合内完成；3 天的项目刚好占满一回合。

## 7. 终局

- 冬季第 10 个决策后触发**总终局**。
- 候选：初霜 / 大洪水 / 敌巢总攻 / 越冬。
- 终局应检验玩家四季的积累：经济、军力、巢穴完整度、虫珀、天赋。
