# 时间与季节（草案 v0.5）

> 时间单位：**1 回合**（不绑定天数）。
> **1 季 = 10 回合。**
> **一局 = 4 季 = 40 回合。**
> 四季：春 → 夏 → 秋 → 冬。

## 1. 时间尺度

| 单位 | 含义 |
|---|---|
| 1 回合 | 抽象时间单位，**不换算天数** |
| 1 大回合 | 1 个季节 = 10 回合 |
| 一局 | 4 个季节 = 40 回合 |
| 单局时长 | 15–40 分钟 |

- 不再使用"天"作为单位；所有旧的天数换算作废。

## 2. 四季

| 大回合 | 季节 | 回合区间 | 主题 / 压力 |
|---|---|---|---|
| 第 1 大回合 | 春 | 1–10 | 建立、繁衍、雨水 |
| 第 2 大回合 | 夏 | 11–20 | 扩张、竞争、干旱 / 高温 |
| 第 3 大回合 | 秋 | 21–30 | 储备、收获、敌巢活跃 |
| 第 4 大回合 | 冬 | 31–40 | 生存、寒潮、终局 |

- 四季连着玩。
- 每个季节有独立的事件池、灾害、资源、兵种倾向。
- 季节推进 = 一局的主轴。

### 2.1 默认季节特性（2026-11-08）

| 季节 | 生产 | 战斗伤害 | 食物消耗 | 巢穴受伤 | 冒险 | 敌对势力 |
|---|---|---|---|---|---|---|
| 春 | 加速 | — | — | — | 风险增加 | 更强大 |
| 夏 | 减速 | 敌我受到伤害增加一定百分比 | — | — | 回报更高；遇到敌对可能性更小；损失工蚁增加 | 遇到可能性更小 |
| 秋 | 加速 | — | — | — | — | 击败可能额外掉落 |
| 冬 | — | 敌我伤害降低 | 减少 | 更容易受伤 | — | — |

- 以上为定性规则；具体百分比 / 倍率待定（Q-057）。
- “城堡”即巢穴；冬季巢穴更容易受伤是否覆盖所有伤害来源，待定（Q-059）。

## 3. 一局结构

```
春（回合 1–10） → 夏（11–20） → 秋（21–30） → 冬（31–40） → 终局
```

## 4. 回合流程

```
回合开始
  → 收入汇报
  → 蚁后生成工蚁
  → 工蚁数量 → 巢穴健康恢复
  → 三选一：冒险 / 基地恢复 / 建筑升级等
  → 选事件组（N 选 1，N = 3~5）
  → 组内 A → B → C → D（准备 → 准备就绪 → 结算）
  → 回合奖励
  → 下一回合
```

> 详细流程见 `01-loop/turn-flow.md`。

## 5. 天气

- 回合开始时预报本回合天气。
- **默认天气三种：晴天 / 下雨 / 多云**（2026-11-08 确定）。
  - **多云**：无额外加成。
  - **晴天**：正向加成（具体内容待定）。
  - **下雨**：负向加成；暂按战斗食物损耗 ×1.5、冒险工蚁损失增加处理（Q-053）。
- 天气影响产出、移动、消耗、巢穴完整度。
- **恶劣天气 / 气候与寄生虫等事件会增加冒险牺牲的工蚁数量**。
- 极端天气在对应季节更常见。
- 天气与季节效果如何叠加，待定（Q-058）。

## 6. 生长时间

| 项目 | 所需回合 |
|---|---|
| 卵 → 幼虫 | 1 回合 |
| 幼虫 → 成虫 | 1–2 回合 |
| 挖掘一格 | 1 回合 |
| 建造房间 | 1–3 回合 |
| 天赋 / 变异 | 立即或下回合生效 |

## 7. 终局

- 冬季第 10 回合（一局第 40 回合）后触发**总终局**。
- 候选：初霜 / 大洪水 / 敌巢总攻 / 越冬。
- 终局检验玩家四季积累：经济、军力、巢穴完整度、虫珀、天赋。
